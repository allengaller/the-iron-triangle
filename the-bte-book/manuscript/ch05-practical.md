# 第 5+ 章　机会评估实战

> 本章把第 5 章的机会判断落成六步操作：建清单、过硬门槛、做评分、定档位、设止损、开评审。配套[BTE-01 机会评分卡](../templates/bte-01-opportunity-scorecard.md)。

## 5+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 商机清单 | 客户、阶段、金额、负责人齐全 | 先补清单 |
| 评分卡 | BTE-01 可用 | 先补模板 |
| 数据来源 | CRM、招标公告、客户公开信息 | 先补数据 |
| 评审机制 | 周会或双周会已排期 | 先定节奏 |
| 决策人 | 谁批准资源、谁批准退出 | 先明确 |

完成标志有四项：每个活跃商机有评分；硬门槛有证据；资源档位已分配；止损条件已写明。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 机会可见 | 所有活跃商机在清单内 | 商机清单 |
| 门槛清晰 | 五道硬门槛逐项判定 | BTE-01 第 1 节 |
| 资源匹配 | A/B/C/D 档位与投入一致 | 资源分配表 |
| 退出有序 | 止损条件与决策人明确 | BTE-01 第 4 节 |

## 5+.2 操作一：建立机会清单

### 步骤

1. 从 CRM、邮箱、会议纪要收集活跃商机；
2. 每条商机填八个字段：编号、客户、阶段、预计 TCV/ACV、负责人、下一步、下一节点日期、来源；
3. 合并重复条目，同一客户多产品线可拆子商机；
4. 标记超过 30 天无进展的商机；
5. 每周更新一次，不追求实时。

### 预期结果

团队能看到全部活跃商机，没有“影子商机”。超过 30 天无进展的条目进入复核。

### 常见错误

- 只登记已立项商机，漏掉早期线索；
- 金额拍脑袋，没有依据；
- 清单只给管理者看，BTE 自己不维护。

## 5+.3 操作二：过硬门槛

### 步骤

1. 逐条判定 G1–G5：合规准入、预算立项、决策人可及、交付能力、承诺边界；
2. 每条判定写证据，不写“应该可以”；
3. 任一为否，标记“补条件”或“no-bid”；
4. 补条件的写清动作、Owner、期限；
5. no-bid 的写清原因，进入观察池或关闭。

### 预期结果

每个商机都有明确的门槛结论。没有“先跟跟看”的模糊状态。

### 常见错误

- 把“客户说有兴趣”当成预算证据；
- 把友好接口人当成决策人；
- 明知交付不了，仍先立项。

## 5+.4 操作三：六维评分

### 步骤

1. 按 BTE-01 六个维度逐项打分；
2. 每个分数写一条证据，证据放评分项右侧；
3. 没有证据的分数改成 0；
4. 算总分，记录评分日期与评分人；
5. 与上次评分对比，变化超过 10 分要写原因。

### 预期结果

评分可追溯、可比较、可复核。团队能说出每个分数的依据。

### 常见错误

- 先定级，再凑分；
- 所有商机都打 80 分，失去区分度；
- 只打分，不写证据，复核时无法解释。

## 5+.5 操作四：定档位与资源

### 步骤

1. 按总分定 A/B/C/D；
2. A 级配三角全员与优先资源；
3. B 级配标准资源，不定制 POC；
4. C 级先做低成本证明，不投深度方案；
5. D 级用标准材料，不投定制资源；
6. 跨档上调要写理由，销售负责人签字。

### 预期结果

资源与机会价值匹配。团队知道每个档位该投多少。

### 常见错误

- 所有单都按 A 级投，团队过载；
- 战略客户无条件升 A，挤占其他商机；
- 定档后不复查，商机变坏仍按原档投入。

## 5+.6 操作五：设里程碑与止损

### 步骤

1. 为每个 A/B 级商机设 3–5 个里程碑；
2. 每个里程碑写清交付物、日期、验证人；
3. 立项时写止损条件，至少覆盖第 5 章六种信号；
4. 指定止损决策人，不能由商机负责人单独决定；
5. 每次评审检查里程碑与止损条件。

### 预期结果

商机推进有节奏，退出有依据。团队不会因为沉没成本一直投入。

### 常见错误

- 里程碑只写日期，不写交付物；
- 止损条件写“视情况而定”；
- 止损决策人就是商机负责人，没人敢退。

## 5+.7 操作六：开机会评审会

### 步骤

1. 每两周一次，30 分钟；
2. 只看三类商机：新进 A/B、分数变化大、触发止损；
3. 每个商机三分钟：变化、证据、请求；
4. 会议只做三个决定：继续、降级、退出；
5. 会后 24 小时内发纪要，更新 BTE-01。

### 预期结果

评审会不是汇报会，是决策会。每个商机都有下一步。

### 常见错误

- 逐个念清单，没有重点；
- 只汇报好消息，坏消息会后说；
- 会议开完没有决定，下次再议。

## 5+.8 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 清单完整 | 活跃商机 100% 在册 | 抽查 CRM 与清单 |
| 门槛证据 | 五道门槛均有证据 | 抽查 BTE-01 |
| 评分可追溯 | 每个分数有证据 | 抽查评分卡 |
| 档位匹配 | 资源投入与档位一致 | 核对资源表 |
| 止损明确 | 每个 A/B 商机有止损条件 | 抽查评分卡 |
| 评审有效 | 每次评审有决定与 Owner | 抽查纪要 |

关键项是门槛证据、评分可追溯、止损明确。任一未过，机会评估不算合格。

## 5+.9 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 清单越做越乱 | 字段太多，没人维护 | 砍到八个字段，固定周更 |
| 所有单都是 A | 评分没有区分度 | 重设权重，强制写证据 |
| 评分没人信 | 分数拍脑袋 | 无证据按 0 计，双人复核 |
| 资源分配吵架 | 档位规则不清 | 先定档位规则，再分资源 |
| 该退不退 | 沉没成本 | 止损决策人独立，按条件执行 |
| 评审会变汇报 | 议程没有决策项 | 只留继续/降级/退出三选一 |

## 5+.10 执行检查清单

- [ ] 活跃商机全部在清单内
- [ ] 每个商机过了五道硬门槛
- [ ] 每个评分项有证据
- [ ] 每个商机有 A/B/C/D 档位
- [ ] 资源投入与档位一致
- [ ] 每个 A/B 商机有止损条件与决策人
- [ ] 最近一次评审有决定与 Owner
- [ ] 超过 30 天无进展的商机已复核

---

**本章要点回顾**

1. 六步：建清单、过硬门槛、做评分、定档位、设止损、开评审。
2. 清单只要八个字段，能周更才有用。
3. 硬门槛先于总分，证据先于分数。
4. 档位决定资源，跨档上调要写理由。
5. 止损条件立项时写，决策人不能是商机负责人。
6. 评审会只做三个决定：继续、降级、退出。
