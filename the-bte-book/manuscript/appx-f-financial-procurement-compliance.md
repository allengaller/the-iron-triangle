# 附录 F　金融采购与合规速查

> 本附录是 BTE 在金融客户处的采购与合规速查表，不构成法律意见。具体规则以官方最新发布为准。监管与标准口径引[《The TAM Book》附录 W](../../the-tam-book/manuscript/appx-w-financial-ops-standards.md)与[第 24 章](../../the-tam-book/manuscript/ch24-ai-risk-governance.md)。

> 时效说明：本附录关键法规名称与状态已联网复核，时点 2026-11-03；具体条文以官方最新发布为准。发布前须刷新。

## F.1 采购流程速查

| 阶段 | 客户动作 | BTE 要准备 | 常见卡点 |
| --- | --- | --- | --- |
| 立项 | 可研、预算 | 价值案例、方案轮廓 | 价值算不清 |
| 预算 | 排优先级 | 优先级论证 | 没进预算 |
| 入围 | 筛供应商 | 资质、案例、准入材料 | 资格不符 |
| 招标 | 发标、评标 | 评分点应答、承诺清单 | 标书不按要求 |
| 评标 | 技术、商务、价格 | 答疑、澄清 | 现场新增承诺 |
| 合同 | 条款、审批 | 风险分配、法务协同 | 条款留到最后 |
| 上线 | 交付、验收 | 交接、首批价值 | 签完失联 |

## F.2 供应商准入材料

| 类别 | 材料 | 维护人 |
| --- | --- | --- |
| 公司资质 | 营业执照、行业资质、认证 | 法务/合规 |
| 财务能力 | 审计报告、经营稳定性 | 财务 |
| 案例参考 | 同类客户、同类场景 | BTE |
| 安全合规 | 数据安全、供应链安全、审计配合 | 安全/合规 |
| 服务能力 | 本地团队、响应机制、灾备 | 交付/TAM |

准入材料平时维护，不临时拼。

## F.3 合规评审清单

### F.3.1 数据

- [ ] 数据分类分级清楚；
- [ ] 数据出域路径可解释；
- [ ] 数据留存与删除有规则；
- [ ] 跨境数据传输合规；
- [ ] 客户授权与告知完整。

### F.3.2 安全

- [ ] 访问权限最小化；
- [ ] 日志可审计；
- [ ] 供应链安全评估完成；
- [ ] 漏洞响应机制明确；
- [ ] 灾备与退出路径清楚。

### F.3.3 AI 专项

- [ ] 模型用途与边界清楚；
- [ ] 训练数据来源合法；
- [ ] 幻觉、漂移、偏见有处置；
- [ ] 人工复核与退出机制明确；
- [ ] 模型版本变更条款写入合同。

## F.4 合同条款清单

| 条款 | 要写清什么 | 常见风险 |
| --- | --- | --- |
| 服务范围 | 做什么、不做什么 | 范围蔓延 |
| SLA 与 Credit | 指标、口径、赔偿 | 口径不清 |
| 责任上限 | 封顶与例外 | 无限责任 |
| 数据条款 | 使用、留存、删除、出域 | 合规事故 |
| 模型版本 | 升级、验收、责任 | 效果变化扯皮 |
| 价格保护 | 调价触发条件 | 成本上涨 |
| 终止权 | 什么情况可终止 | 退出困难 |
| 审计权 | 客户审计范围 | 配合成本 |

## F.5 常见风险

| 风险 | 表现 | 前置动作 |
| --- | --- | --- |
| 资格风险 | 资质过期、案例不足 | 建准入台账 |
| 预算风险 | 未立项、预算削减 | 早参与立项 |
| 合规风险 | 数据出域、跨境 | 早做边界表 |
| 条款风险 | 责任上限、退出 | 法务早进场 |
| 交付风险 | 承诺接不住 | TAM 一票关注 |
| 模型风险 | 效果漂移、版本变更 | 写模型条款 |
