# 第 6+ 章　决策链地图实战

> 本章把第 6 章的决策链洞察落成六步操作：列角色、画三链、评属性、找空白、定接触、勤更新。配套 [BTE-02 决策链地图](../templates/bte-02-decision-chain-map.md)。

## 6+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 客户组织信息 | 组织图、汇报线、关键部门 | 先补公开信息 |
| 商机基本信息 | 项目范围、预算、阶段 | 先补商机卡 |
| 接触记录 | 已见的人、聊过什么 | 先补会议纪要 |
| 内部支持 | SA、TAM、销售接口 | 先定协作人 |
| 更新节奏 | 周更或双周更 | 先定节奏 |

完成标志有四项：关键角色齐全；三链图有空白标记；每个关键角色有接触计划；单点依赖已识别。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 角色可见 | 八类角色均有名单 | 角色清单 |
| 三链清楚 | 决策、影响、防线三张图 | 三链图 |
| 属性可评 | 五个属性有评分与证据 | 评估表 |
| 行动明确 | 每个空白有 Owner 与日期 | 接触计划 |

## 6+.2 操作一：列角色

### 步骤

1. 按八类角色列名单：经济买家、技术买家、用户买家、教练、blocker、采购、法务、安全；
2. AI 项目补三类：CAIO、数据治理、模型风险；
3. 每个角色填五个字段：姓名、职位、汇报线、关心什么、当前态度；
4. 不知道的字段标“未知”，不要猜；
5. 每两周补一次未知项。

### 预期结果

关键角色有名单，未知项有清单。团队知道还缺谁。

### 常见错误

- 只列见过的人，漏掉没见过的决策人；
- 用职位代替态度，不知道对方支持还是反对；
- 名单只存在个人脑子里，不共享。

## 6+.3 操作二：画三链

### 步骤

1. 画决策链：谁拍板、谁签字、谁有否决权；
2. 画影响链：谁影响谁，内部专家、外部顾问、同业标杆各是谁；
3. 画防线：技术、安全、采购、法务四道评审，各由谁把关；
4. 用实线表示强影响，虚线表示弱影响；
5. 标出空白：没有接触、态度未知、影响不明。

### 预期结果

三张图能回答三个问题：谁决定买，谁影响决定，谁能挡下决定。

### 常见错误

- 把组织图当决策链；
- 忽略外部顾问与同业影响；
- 防线只画技术评审，漏掉安全、采购、法务。

## 6+.4 操作三：评五个属性

### 步骤

1. 每个关键角色按五个属性打分：权力、态度、触达、覆盖、冗余；
2. 每项 0–2 分：0 = 不明或不利，1 = 部分，2 = 明确且有利；
3. 分数旁写证据，例如“见过两次，能调动预算”；
4. 总分低于 6 分的角色标红；
5. 标红角色进入接触计划优先项。

### 预期结果

团队能一眼看出哪条线强、哪条线弱、哪条线随时会断。

### 常见错误

- 只评权力，不评态度；
- 把“见过一次”当成触达 2 分；
- 不评冗余，支持者一走才发现断线。

## 6+.5 操作四：找空白与单点

### 步骤

1. 列出三链上的空白：没接触、态度未知、影响不明；
2. 列出单点依赖：只有一个接口人的关键角色；
3. 每个空白与单点写补线动作、Owner、期限；
4. 优先补两类：能否决的角色、唯一支持者；
5. 补线后更新三链图。

### 预期结果

空白有补线计划，单点有备份。商机不再依赖一个人。

### 常见错误

- 空白太多，不知道先补哪个；
- 只补支持者，不补 blocker；
- 补线只加微信，不交换信息。

## 6+.6 操作五：定接触计划

### 步骤

1. 为每个关键角色设计一次“有价值”的接触；
2. 接触内容按角色定制：业务看价值，技术看架构，采购看条款，法务看风险，安全看边界；
3. 每次接触带一个证据或一个问题，不空聊；
4. 定节奏：A 级商机每两周一次，B 级每月一次；
5. 记录态度变化与下一步。

### 预期结果

每个关键角色都能在自己的语言里得到答案。接触有目的，不是刷脸。

### 常见错误

- 所有人发同一份材料；
- 只约技术口，业务与采购不见；
- 接触后不记录，下次重新开始。

## 6+.7 操作六：验证与更新

### 步骤

1. 每次会议后更新角色态度与三链图；
2. 每月做一次完整复核；
3. 六种信号出现时 48 小时内更新：支持者变动、组织重组、预算削减、新监管、竞对进场、采购规则变化；
4. 更新后重评机会等级；
5. 关键变化写入商机记录。

### 预期结果

三链图是最新版本，不是三个月前的快照。

### 常见错误

- 图画完就归档；
- 组织变了，图没变；
- 支持者走了，团队还在按原计划推进。

## 6+.8 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 角色齐全 | 八类角色均有名单或“未知”标记 | 抽查角色清单 |
| 三链完整 | 决策、影响、防线三图齐备 | 抽查三链图 |
| 属性有证据 | 每个评分有证据 | 抽查评估表 |
| 空白有 Owner | 每个空白有补线动作与日期 | 抽查接触计划 |
| 单点有备份 | 关键角色至少两条线 | 抽查冗余评估 |
| 更新及时 | 关键变化 48 小时内更新 | 抽查更新记录 |

关键项是角色齐全、三链完整、单点有备份。任一未过，决策链地图不算合格。

## 6+.9 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 图画得很漂亮，没人用 | 只画图，不链接触计划 | 每个空白配 Owner 与日期 |
| 只见技术口 | 接触路径依赖 | 强制补业务、采购、法务、安全 |
| 支持者一走就断线 | 没有冗余 | 每个关键角色补第二条线 |
| 态度判断总错 | 把客气当支持 | 用行动验证：是否引荐、是否给信息 |
| 组织变了图没变 | 没有更新触发 | 六种信号 48 小时更新 |
| 采购阶段判断错 | 没问流程 | 直接问采购：现在到哪一步 |

## 6+.10 执行检查清单

- [ ] 八类角色均有名单或“未知”标记
- [ ] 决策链、影响链、防线三图齐备
- [ ] 每个关键角色有五个属性评分与证据
- [ ] 每个空白有 Owner 与补线日期
- [ ] 每个关键角色至少两条线
- [ ] 每个关键角色有定制接触内容
- [ ] 最近一次更新在 30 天内
- [ ] 关键变化已重评机会等级

---

**本章要点回顾**

1. 六步：列角色、画三链、评属性、找空白、定接触、勤更新。
2. 角色按八类列，AI 项目补 CAIO、数据治理、模型风险。
3. 三链是决策链、影响链、防线，不是一张组织图。
4. 五个属性：权力、态度、触达、覆盖、冗余。单点依赖最危险。
5. 接触要按角色定制，每次带证据或问题。
6. 三链图随商机更新，关键变化 48 小时内重画。
