# 第 10+ 章　谈判实战

> 本章把第 10 章的谈判方法落成八步操作：定目标、算 BATNA、列议题、设交换、排角色、跑谈判、破僵局、做记录。配套 [BTE-06 商业结构与让步阶梯](../templates/bte-06-commercial-structure.md)。

## 10+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 商业结构 | 价格、条款、风险分配已定 | 先过第 9+ 章 |
| 授权 | 目标价、底线价、审批人 | 先拿授权 |
| 客户信息 | 决策链、预算、采购阶段 | 先补决策链 |
| 竞争信息 | 对手报价与方案 | 先补竞争卡 |
| 团队 | 主谈、记录、技术支援 | 先定分工 |

完成标志有五项：目标与底线清楚；BATNA 明确；议题有优先级；交换方案有备选；记录与交接完整。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 底线清楚 | 目标、保留价、退出价三档 | 谈判简报 |
| 筹码清楚 | BATNA 与 ZOPA 有判断 | 谈判简报 |
| 议题清楚 | 可谈与不可谈分开 | 议题清单 |
| 交换清楚 | 每个让步有换回条件 | 交换表 |
| 结果可执行 | 共识写入纪要并签认 | 谈判纪要 |

## 10+.2 操作一：定目标与底线

### 步骤

1. 写理想目标：价格、期限、范围、付款、风险；
2. 写保留价：低于什么条件不签；
3. 写退出价：什么情况下离桌；
4. 三档价格与第 9+ 章授权表对齐；
5. 让团队每个人知道三档，不现场即兴。

### 预期结果

团队口径一致，不会一个人唱红脸、一个人唱白脸唱过头。

### 常见错误

- 只有目标，没有底线；
- 底线只有主谈知道；
- 客户一压，现场就破线。

## 10+.3 操作二：算 BATNA 与 ZOPA

### 步骤

1. 写自己的 BATNA：谈不成，我们做什么；
2. 写客户的 BATNA：谈不成，客户做什么；
3. 估双方保留价；
4. 找 ZOPA：双方保留价是否重叠；
5. 没有 ZOPA 的，先改方案或换议题，不硬谈。

### 预期结果

知道自己有多少筹码，也知道客户有多少。

### 常见错误

- 不评估客户替代方案，误以为自己不可替代；
- 把“客户很想买”当成没有 BATNA；
- 没有 ZOPA 还硬谈，浪费时间。

## 10+.4 操作三：列议题与优先级

### 步骤

1. 列全部议题：价格、期限、范围、付款、风险、服务、参考、时间；
2. 每个议题标：必须拿、可以让、不可谈；
3. 排优先级：哪些先谈，哪些后谈；
4. 标出可交换组合；
5. 与内部团队对齐，不各自报价。

### 预期结果

谈判有路线图，不东一榔头西一棒子。

### 常见错误

- 只列价格；
- 所有议题都“必须拿”；
- 先谈最难的，谈崩了没退路。

## 10+.5 操作四：设计交换方案

### 步骤

1. 为每个可以让的议题写换回条件；
2. 设计三套组合：保守、基准、进取；
3. 每套算毛利与风险；
4. 标出不可交换的红线：承诺边界、合规、安全；
5. 让财务与法务预审。

### 预期结果

每次让步都有对应收获，不白让。

### 常见错误

- 单向让步；
- 交换条件不可执行；
- 用承诺边界换价格。

## 10+.6 操作五：排角色与议程

### 步骤

1. 定主谈、记录、技术支援、商务支援；
2. 主谈负责节奏与交换，技术支援只答技术；
3. 记录员记共识、分歧、行动项；
4. 排议程：开场、议题顺序、休息、收尾；
5. 预演客户可能的三类反对。

### 预期结果

桌上一个声音，后台一个团队。

### 常见错误

- 多人抢话；
- 技术支援现场承诺；
- 没有议程，客户带着走。

## 10+.7 操作六：执行谈判

### 步骤

1. 开场确认议程与目标；
2. 先问利益，不急着报价；
3. 用复述确认理解；
4. 提出组合方案，不单点让步；
5. 每次让步换条件，记录在案；
6. 收尾复述共识与例外。

### 预期结果

双方知道谈成了什么，还有什么没谈。

### 常见错误

- 一上来报底价；
- 只说自己方案，不听客户；
- 口头共识不记录。

## 10+.8 操作七：处理僵局

### 步骤

1. 暂停，回到利益层；
2. 换议题，先易后难；
3. 提条件交换，不单方退让；
4. 引入高层或第三方；
5. 明确谈不成的后果，陈述不威胁；
6. 仍僵持的，休会，给双方内部空间。

### 预期结果

僵局不升级为人身冲突，保留继续谈的空间。

### 常见错误

- 硬扛到底；
- 用威胁代替方案；
- 当场破底线。

## 10+.9 操作八：记录与交接

### 步骤

1. 24 小时内发纪要：共识、分歧、行动项、下一步；
2. 双方确认，不默认；
3. 让步与交换写入谈判日志；
4. 签约前核对纪要与合同；
5. 签约后向交付与 TAM 交底商业结构。

### 预期结果

谈判结果可追溯，交付知道承诺从哪来。

### 常见错误

- 纪要不发或晚发；
- 纪要与合同不一致；
- 交付不知道谈判承诺。

## 10+.10 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 三档价格 | 目标、保留、退出明确 | 核对谈判简报 |
| BATNA | 双方 BATNA 有判断 | 核对简报 |
| 议题清单 | 必须拿、可以让、不可谈分开 | 核对议题表 |
| 交换方案 | 每个让步有换回条件 | 核对交换表 |
| 角色分工 | 主谈、记录、支援明确 | 核对分工表 |
| 纪要完整 | 共识、分歧、行动项齐全 | 核对纪要 |
| 交接完成 | 交付与 TAM 已知承诺 | 核对交底记录 |

关键项是三档价格、交换方案、纪要完整。任一未过，谈判不算合格。

## 10+.11 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 一上桌客户就压价 | 没有底线与 BATNA | 先补谈判简报 |
| 让步停不下来 | 没有交换方案 | 每个让步写换回条件 |
| 客户只谈价格 | 议题太窄 | 主动引入期限、付款、范围 |
| 谈崩了 | 先谈最难议题 | 改议程，先易后难 |
| 纪要吵架 | 口头共识没记录 | 当场复述，24 小时发纪要 |
| 交付不知道承诺 | 没交底 | 签约即移交商业结构 |

**本章要点回顾**

1. 八步：定目标、算 BATNA、列议题、设交换、排角色、跑谈判、破僵局、做记录。
2. 三档价格：目标、保留、退出。团队口径一致。
3. BATNA 决定筹码，ZOPA 决定可谈区间。
4. 议题分三类：必须拿、可以让、不可谈。
5. 每个让步都要换回条件，不用承诺边界换价格。
6. 桌上一个声音，后台一个团队。
7. 纪要 24 小时内发，签约后向交付交底。
