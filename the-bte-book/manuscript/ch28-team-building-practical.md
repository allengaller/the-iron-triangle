# 第 28+ 章　团队建设动作

> 本章把第 28 章的团队设计落成六步操作：建矩阵、做招聘、跑 90 天、配结构、落绩效、经营出口。每步配步骤、预期结果与常见错误。

## 28+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 业务目标 | 明年打什么行业、什么单 | 先定目标 |
| 现有人才 | 级别、技能、绩效 | 先盘点 |
| 编制预算 | 招几人、什么级别 | 先批预算 |
| 带教资源 | 谁带、带多久 | 先定导师 |
| 考核口径 | 金额、毛利、质量 | 先对口径 |

完成标志有五项：矩阵清楚；招聘有画像；培养有节奏；结构有梯队；绩效有配对。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 矩阵清楚 | 每人每维有级别 | 技能矩阵 |
| 招聘有画像 | 三要素与反向信号 | 招聘标准 |
| 培养有节奏 | 90 天三段有里程碑 | 培养计划 |
| 结构有梯队 | 每级有备份 | 梯队表 |
| 绩效有配对 | 金额配质量 | 考核表 |

## 28+.2 操作一：建技能矩阵

### 步骤

1. 列六维：机会、客户、价值、技术、结构、谈判；
2. 每人每维标 B1–B5；
3. 标证据：项目、合同、客户确认；
4. 找三类缺口：低于当前级别、团队无人、单点依赖；
5. 每季度更新一次。

### 预期结果

团队能力看得见，培养有靶子。

### 常见错误

- 只评印象，不写证据；
- 所有人都是 B3，没有区分度；
- 矩阵建完不更新。

## 28+.3 操作二：执行招聘

### 步骤

1. 写画像：判断力、沟通结构、技术锚点；
2. 写反向信号：只会关系、只会技术；
3. 设计面试：案例判断、角色演练、技术追问；
4. 至少两人交叉面试；
5. 录用后 90 天复盘画像准不准。

### 预期结果

招进来的人能判断，不只是能说。

### 常见错误

- 只看行业关系；
- 面试只问知识，不问判断；
- 录用后不复盘。

## 28+.4 操作三：跑 90 天培养

### 步骤

1. 0–30 天：跟会、读案例、学产品、跑机会评估；
2. 31–60 天：做副手、独立客户研究、参与报价；
3. 61–90 天：独立跟小单、完成一次交接；
4. 每阶段设里程碑与验收人；
5. 90 天结束做认证，未过延长或转岗。

### 预期结果

新人 90 天能独立跟小单。

### 常见错误

- 只上课，不上项目；
- 没人带，新人自学；
- 未过认证就上大单。

## 28+.5 操作四：配团队结构

### 步骤

1. 按业务目标定级别配比：B2/B3/B4 各几人；
2. 每级至少两人，避免单点；
3. 行业纵深与产品广度搭配；
4. 设一个“大单小组”：B4 + B3 + SA + TAM；
5. 每半年复盘结构。

### 预期结果

团队有梯队，大单有人打，小单有人接。

### 常见错误

- 全是 B2，没人打大单；
- 只有一个 B4，单点依赖；
- 结构不随业务变。

## 28+.6 操作五：落绩效与激励

### 步骤

1. 定三类指标：金额、毛利、质量；
2. 质量含承诺偏差、续约率、POC 转化；
3. 主管考核加团队健康：流失、梯队、带教；
4. 指标配对，防异化；
5. 每季度校准一次。

### 预期结果

绩效引导长期行为，不诱导短期造假。

### 常见错误

- 只看金额；
- 指标不配对；
- 考核结果不反馈。

## 28+.7 操作六：经营出口与沉淀

### 步骤

1. 识别四类出口：管理、产品、创业、咨询；
2. 为每人做一次发展对话；
3. 离任前做知识交接：案例、客户、方法；
4. 建方法库：模板、复盘、案例；
5. 每年回看出口数据。

### 预期结果

人走了，方法论留下；人回来了，经验带回来。

### 常见错误

- 把人当私有资产；
- 离任不交接；
- 方法只在个人脑子里。

## 28+.8 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 矩阵有证据 | 每人每维有级别与证据 | 抽查矩阵 |
| 招聘有画像 | 三要素与反向信号 | 核对标准 |
| 培养有里程碑 | 90 天三段有验收 | 核对计划 |
| 结构有梯队 | 每级至少两人 | 核对梯队表 |
| 绩效有配对 | 金额、毛利、质量 | 核对考核表 |
| 出口有沉淀 | 方法库有更新 | 抽查方法库 |

关键项是矩阵有证据、结构有梯队、绩效有配对。任一未过，团队建设不算合格。

## 28+.9 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 矩阵没区分度 | 只凭印象 | 强制写证据 |
| 招错人 | 画像不清 | 补三要素与反向信号 |
| 新人上不了手 | 没带教 | 定导师与 90 天计划 |
| 大单没人打 | 缺 B3/B4 | 补高级别或外部引进 |
| 绩效造假 | 指标单一 | 加质量指标与抽查 |
| 人走方法丢 | 没沉淀 | 建方法库与离任交接 |

## 28+.10 执行检查清单

- [ ] 六维技能矩阵每人有级别与证据
- [ ] 招聘画像三要素与反向信号明确
- [ ] 90 天培养三段有里程碑
- [ ] 每级至少两人，无单点
- [ ] 大单小组已组建
- [ ] 绩效含金额、毛利、质量
- [ ] 主管考核含团队健康
- [ ] 方法库每季度更新
- [ ] 离任交接有清单

---

**本章要点回顾**

1. 六步：建矩阵、做招聘、跑 90 天、配结构、落绩效、经营出口。
2. 矩阵要证据，不要印象。
3. 招聘看判断力、沟通结构、技术锚点。
4. 90 天：看懂、上手、独立。未过认证不上岗。
5. 结构看梯队，每级至少两人。
6. 绩效金额配质量，出口当生态，方法要沉淀。
