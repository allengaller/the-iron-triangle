# 附录 E　开源贡献指南

> 本书按 CC BY-NC-SA 4.0 发布。欢迎三类贡献：勘误、案例、模板。先 Issue 后 PR，脱敏是硬门槛。

## E.1 贡献类型

| 类型 | 内容 | 入口 |
| --- | --- | --- |
| 勘误 | 事实错误、链接失效、术语不一致 | Issue 标“勘误” |
| 案例 | 脱敏的赢单、丢单、大单治理案例 | Issue 标“案例” |
| 模板 | 机会、价值、证明、商业结构、交接模板 | Issue 标“模板” |

不收录四类内容。产品广告，未脱敏客户信息。无法核实的行业数据，纯销售话术。

## E.2 提交前准备

1. 读[AGENTS.md](../../the-tam-book/AGENTS.md)与本书目录；
2. 确认内容不在现有章节；
3. 确认术语与[附录 A](appx-a-glossary.md)一致；
4. 确认引用有来源与时点；
5. 确认案例已脱敏。

## E.3 脱敏自查

| # | 检查项 | 是/否 |
| --- | --- | --- |
| 1 | 无真实客户名、项目名、合同号 | □ |
| 2 | 无真实人名、联系方式、组织架构 | □ |
| 3 | 无真实报价、折扣、成本、毛利 | □ |
| 4 | 无未公开的监管沟通与处罚信息 | □ |
| 5 | 数字已做比例化或区间化处理 | □ |
| 6 | 案例已声明“虚构化/脱敏” | □ |

任一为“否”，不提交。

## E.4 编号避让

本书已用编号：

| 前缀 | 用途 |
| --- | --- |
| BTE-01–10 | 模板 |
| OP1–OP8 | 机会流程 |
| B1–B5 | BTE 成熟度 |
| CM-xxx | 承诺清单条目 |
| HR-xxx | 风险清单条目 |
| SG-xxx | 信号回流条目 |

新增编号先查本表，避免冲突。

## E.5 提交流程

1. 开 Issue：写清类型、位置、问题、建议；
2. 等维护者确认范围；
3. Fork 仓库，建分支；
4. 按章节体例修改，保持 Diátaxis 单类型；
5. 提交 PR：写清改了什么、为什么、影响哪些章节；
6. 通过链接审计、长句检查与主动语态检查；
7. 维护者评审，合并。

## E.6 写作要求

- 中文正文用全角标点；
- 技术术语首现展开：中文（English，缩写）；
- 单句 ≤25 字，主动语态；
- 每条建议落成清单、模板或可观察行为；
- 时效性内容标来源与时点；
- 案例虚构化，数字不指向真实客户。

## E.7 常见退回原因

| 原因 | 处理 |
| --- | --- |
| 未脱敏 | 按 E.3 重做 |
| 无来源 | 补来源与时点，或删掉 |
| 与现有章节重复 | 改为引用，不重写 |
| 类型混合 | 拆成 Explanation/How-to |
| 话术化 | 改成决策、证据、动作 |
| 编号冲突 | 按 E.4 改名 |
