# 第 11 章　线索与资格

> 线索不是商机。线索只是“可能有机会”。本章给六个动作：收线索、过四问、验门槛、定归属、设下一步、做记录。目标是把线索变成可管理的商机，或尽早放掉。

## 11.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 线索来源 | 活动、转介绍、招标公告、存量客户 | 先标来源 |
| 客户基本信息 | 行业、规模、组织、预算线索 | 先补公开信息 |
| 资格标准 | 四问与硬门槛 | 先用[BTE-01](../templates/bte-01-opportunity-scorecard.md) |
| 归属规则 | 谁跟、谁支持、怎么分 | 先定规则 |
| 记录工具 | CRM 或商机清单 | 先建台账 |

完成标志有四项：线索有来源；四问有答案；门槛有判定；下一步有 Owner 与日期。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 线索可见 | 每条线索在册 | 线索台账 |
| 资格清楚 | 四问与硬门槛有结论 | 资格记录 |
| 归属明确 | 负责人与支持人确定 | 归属记录 |
| 动作明确 | 下一步有 Owner 与日期 | 跟进记录 |

## 11.2 操作一：收线索

### 步骤

1. 从活动、转介绍、招标公告、存量客户、伙伴五个渠道收集；
2. 每条线索填八个字段：来源、客户、联系人、场景、预算线索、时间窗、竞争信息、下一步；
3. 标出来源可信度：客户直接、伙伴转介、公开信息、陌生线索；
4. 重复线索合并，同一客户多场景可拆；
5. 每周汇总一次，不追求实时。

### 预期结果

线索有统一入口，不散落在个人邮箱与微信里。

### 常见错误

- 只收“热线索”，漏掉早期信号；
- 来源不标，后续无法判断质量；
- 线索只在个人手里，团队看不见。

## 11.3 操作二：过四问

### 步骤

1. 问问题：客户有没有真实业务问题；
2. 问预算：有没有预算或立项路径；
3. 问人：能不能触达决策人；
4. 问时间：有没有时间窗；
5. 四问至少三问有明确答案，才进入资格评估。

### 预期结果

线索从“听说有机会”变成“知道机会在哪”。

### 常见错误

- 把客户客气当需求；
- 把“明年有预算”当今年机会；
- 只见接口人，就认为能触达决策人。

## 11.4 操作三：验门槛

### 步骤

1. 用 BTE-01 五道硬门槛：合规、预算、决策人、交付、承诺；
2. 每条判定写证据；
3. 任一为否，标“补条件”或“放观察池”；
4. 补条件的写动作、Owner、期限；
5. 不放观察池的，写清关闭原因。

### 预期结果

线索有明确去向：进入商机、补条件、观察、关闭。

### 常见错误

- 所有线索都进商机，资源稀释；
- 门槛只凭感觉，不写证据；
- 关闭不记录，下次重复跟。

## 11.5 操作四：定归属

### 步骤

1. 按行业、区域、客户关系或产品线定负责人；
2. 明确支持角色：SA、TAM、售前支持；
3. 跨区或跨部门线索，先定主责再分工；
4. 归属争议由销售负责人裁决；
5. 归属写进 CRM，口头不算。

### 预期结果

每条线索有人负责，不出现“大家都觉得别人跟”。

### 常见错误

- 归属不清，线索放凉；
- 多人同时跟，客户收到不同口径；
- 归属只口头说，事后争功。

## 11.6 操作五：设下一步

### 步骤

1. 每条线索写一个下一步动作；
2. 动作要具体：约谁、问什么、带什么材料；
3. 写日期与 Owner；
4. 超过 14 天无进展，降级或关闭；
5. 下一步完成后更新线索状态。

### 预期结果

线索有节奏，不会“加了微信就没了”。

### 常见错误

- 下一步写“保持联系”；
- 没有日期，永远不跟进；
- 只跟进不记录，团队不知道进展。

## 11.7 操作六：做记录

### 步骤

1. 线索记录与商机记录分开；
2. 记录关键事实：客户原话、预算线索、时间窗、竞争信息；
3. 不记录主观判断，判断另写；
4. 每周更新状态；
5. 转商机时，把线索记录带入商机卡。

### 预期结果

线索可追溯，转商机不丢信息。

### 常见错误

- 记录写成日记；
- 只记结论，不记事实；
- 转商机时重新问一遍，客户反感。

## 11.8 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 线索在册 | 新增线索 100% 登记 | 抽查台账 |
| 四问有答案 | 至少三问明确 | 抽查资格记录 |
| 门槛有判定 | 五道门槛有是/否与证据 | 抽查 BTE-01 |
| 归属明确 | 每条线索有负责人 | 核对 CRM |
| 下一步具体 | 有动作、Owner、日期 | 抽查跟进记录 |
| 关闭有原因 | 关闭线索有记录 | 抽查台账 |

关键项是门槛判定、归属明确、下一步具体。任一未过，线索管理不算合格。

## 11.9 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 线索很多，商机很少 | 四问没过就投入 | 先过四问，再配资源 |
| 线索没人跟 | 归属不清 | 先定主责，再分工 |
| 跟进断档 | 下一步不具体 | 写清约谁、问什么、何时 |
| 多人打扰客户 | 归属冲突 | 一个客户一个主接口 |
| 线索质量差 | 来源不标 | 按来源统计转化率 |
| 转商机丢信息 | 记录不完整 | 线索记录带入商机卡 |

## 11.10 执行检查清单

- [ ] 每条线索有来源与八个字段
- [ ] 四问至少三问有明确答案
- [ ] 五道硬门槛有判定与证据
- [ ] 每条线索有负责人与支持人
- [ ] 下一步有具体动作、Owner、日期
- [ ] 超过 14 天无进展的线索已复核
- [ ] 关闭线索有原因记录
- [ ] 转商机时线索记录已带入

---

**本章要点回顾**

1. 线索不是商机。先过四问，再谈资源。
2. 四问：问题、预算、人、时间。至少三问明确。
3. 五道硬门槛：合规、预算、决策人、交付、承诺。
4. 归属先定主责，再谈协作。一个客户一个主接口。
5. 下一步要具体：约谁、问什么、何时。
6. 线索记录带事实，不带日记。转商机不丢信息。
