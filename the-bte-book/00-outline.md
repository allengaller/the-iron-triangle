# The BTE Book of AI Era｜AI 时代的技术销售白皮书 — 书稿骨架

> **状态**：v1.0（Phase 0–4 初稿与构建完成，2026-11-03）。七部分、28 章 + 8 个配套章、10 件模板、7 个附录全部落盘；HTML/EPUB/PDF 已生成。待决策门试读与正式发布。
> **定位**：BTE（技术销售，Business Technology Executive）的岗位方法书。核心命题：**把技术变成生意，把承诺变成可交付的合同。**
> **姊妹书关系**：《The TAM Book of AI Era》管签单后，《The SA Book of AI Era》管签单前方案。本书管商机与商业结构，补完铁三角第三角。
> **三不是**：不是销售话术书，不是产品白皮书合集，不是标书模板库。每条建议应落成清单、模板或可观察行为。

## 命名与别名

- 书名：The BTE Book of AI Era
- 中文书名：AI 时代的技术销售白皮书
- 适用岗位别名：BTE（默认）、SE（Sales Engineer）、Presales、Solutions Consultant、Technical Sales、Customer Engineer。
- 与 AE（Account Executive）的关系：有的组织合并，有的组织分设。分设时，BTE 管技术可信与承诺的商务合理性，AE 管合同与回款。

## 与 SA 书的边界协议

**核心规则：按决策权切，不按阶段切。**

| 关键决策 | BTE | SA | TAM |
| --- | --- | --- | --- |
| 跟不跟这个商机 | A/R | C | C |
| 客户决策链与切入点 | A/R | C | C |
| 价值假设与业务案例 | A/R | C | C |
| 方案架构与技术路线 | C | A/R | C |
| POC 业务成功标准 | A | R（技术执行） | C |
| POC 技术结论 | C | A/R | C |
| 报价、合同结构、让步 | A/R | C | C |
| 承诺的商务合理性 | A/R | C（技术承诺） | C（可运营性一票） |
| 交付交接 | R（发起） | C | A（签收） |
| 续约与增购 | A/R | C | R（信号源） |

四条执行规则：

1. 流程章只写 BTE 的决策、证据与交接；
2. 需要 SA 细节时给链接，不重写；
3. 定义冲突以定义方为准；
4. 除第 2 章边界章外，每章与 SA 书重复段落 ≤15%。

## 写作约定

- Diátaxis 单类型标注，首行 `<!-- Diátaxis: ... -->`；混合即拆分（+ 章模式）。
- 中文正文用全角标点；技术术语、产品名保留英文。
- 术语首现格式：中文（English，Abbreviation）；后续用缩写或中文。
- 单句 ≤25 个汉字；不用被动“被”；主动语态优先。
- 每条建议落成清单、模板或可观察行为。
- 时效性内容标注来源与时点；发布前刷新，未刷新加注。
- 案例一律虚构化脱敏，不使用真实客户名。
- 模板引用统一“BTE-01”格式；共用 TAM/SA 模板时写“模板 19”“SA-02”。
