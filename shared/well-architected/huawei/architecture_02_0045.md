# 概述

高可用性系统必须具有完善的故障检测能力，以确保能够快速发现那些可能导致故障的事件、显示正在发展的故障、激活的故障，以及潜在的故障的事件。

在几乎所有情况下，故障检测能力都是故障恢复的前提。
