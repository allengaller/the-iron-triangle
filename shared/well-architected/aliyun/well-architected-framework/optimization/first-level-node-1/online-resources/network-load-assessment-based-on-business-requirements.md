# 根据业务需求进行网络负载评估

网络负载评估是指对阿里云整个云网络产品体系（包括VPC、云企业网CEN、负载均衡、弹性公网IP、NAT网关、高速通道等）在不同业务场景下的流量承载能力、性能表现和资源利用率进行系统性分析与量化评价的过程。网络负载评估可以提前识别潜在瓶颈，避免因突发流量导致的服务中断，基于实际负载需求精准配置网络产品规格，在确保网络产品组合能够应对业务增长和突发流量，维持业务连续性的前提下，避免资源浪费或不足，从而降低云计算成本支出。

## 优先级

高

## 不推荐做法

- 使用有限制规格的产品却未提前进行资源评估，如专线规格过大或者过小，导致业务超限或者资源浪费。
- 未正确评估业务的增长空间和弹性需求，导致后续业务流量出现上涨时，业务超限。

## 期望结果

网络负载评估应形成一份全面的评估报告，根据业务实际运行状态和未来增长情况，包含可量化的带宽、性能、并发等网络指标，为后续架构设计提供约束条件 。

## 实施指南

1. 业务场景分类：区分相关业务场景，明确不同场景的性能优先级 。
2. 了解各个产品的性能，规格，计费模式，并采用分层评估方法：基础网络层：评估VPC、高速通道、云企业网等产品的带宽和连接能力负载分发层：评估网络型负载均衡NLB和应用型负载均衡ALB的性能表现业务接入层：评估弹性公网IP、NAT网关等产品的公网接入能力
3. 量化网络核心指标量化，例如：网络时延，业务响应时延，并发，带宽等，将业务需求转化为网络性能指标
4. 业务量与扩展分析：结合业务峰值需求及增长趋势（年增长率）估算资源需求 。
5. 确定最终系统需要的网络能力
