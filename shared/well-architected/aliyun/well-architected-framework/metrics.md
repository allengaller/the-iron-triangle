# 度量

阿里云卓越架构的度量阶段是连接学习与优化的核心环节，旨在通过系统化的评估工具和模型，量化当前云架构设计与业务目标之间的差距，识别潜在风险并明确改进方向。该阶段结合客观度量与主观度量两种方式，帮助客户全面掌握架构成熟度，为后续优化提供数据支撑和决策依据。

## 客观度量

客观度量依托于云治理中心免费的治理成熟度检测功能，提供了云治理成熟度的全面检测。目前覆盖了260多项检测指标，基于阿里云实时数据，自动识别云上架构中的潜在风险，并支持生成可视化评估报告，标注问题优先级，并提供修复建议与最佳实践参考。具体操作，请参见[治理成熟度检测](https://help.aliyun.com/zh/cgc/user-guide/cloud-governance-maturity-detection/)。

客观度量适用于快速并持续的定位架构中的硬性缺陷，并为团队提供可操作的改进清单，降低人工排查成本。

## 主观度量

云卓越架构提供了免费自助问答工具 Well-Architected Tool，帮助客户实现主观度量。Well-Architected Tool 通过架构化的问卷形式，引导客户从战略层面梳理架构的治理现状。并支持记录关键决策、风险项及改进计划，形成治理进程的“数字档案”，便于定期复盘与迭代。团队成员可共同参与评估，确保治理目标与业务需求对齐。具体操作，请参见 [Well-Architected Tool](https://help.aliyun.com/zh/cgc/user-guide/well-architected-tool)。

主观度量适用于客户评估架构设计的合理性，比如是否遵循最小权限原则、是否支持弹性扩展等。并跟踪跨部门协作中的治理进展，确保优化措施落地。
