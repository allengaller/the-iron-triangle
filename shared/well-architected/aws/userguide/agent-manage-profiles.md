# Agent profiles

AWS Well-Architected Agent is in preview release and is subject to change.


After you create an agent profile, you can manage it from the AWS WA Agent console in
 **Agent profiles**. You can update goals, pillars, accounts, and application
 context at any time. If you have multiple profiles, you can switch between them to view
 profile-scoped recommendations and reviews.

###### Note

This section describes how to manage existing agent profiles. If you have not created an agent
 profile yet, see [Step 1: Create an agent profile](./agent-getting-started.html#agent-create-profile)
 in the **Getting started** section for instructions.

You can also manage profiles programmatically using the AWS CLI or SDK. For the complete
 list of operations, see the [AWS Well-Architected API
 Reference](https://docs.aws.amazon.com/wellarchitected/latest/APIReference/Welcome.html).
