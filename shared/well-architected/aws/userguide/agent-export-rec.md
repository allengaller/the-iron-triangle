# Export recommendations in AWS Well-Architected Agent

AWS Well-Architected Agent is in preview release and is subject to change.


Export your recommendations in AWS WA Agent to share with stakeholders or integrate with external
 systems for tracking and implementation planning. Recommendations are exported in the CSV file
 format.

###### To export recommendations for a profile

1. Open the profile dashboard in **Agent profiles** and choose
 **Export**.
2. Select which recommendations you want to export between Prioritized, Archived, or All
 recommendations.
3. Choose **Export** to download the CSV file.

The export includes all visible recommendation details and guided actions to implement the
 recommendation.
