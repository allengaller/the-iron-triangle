# Prescheduled remediations for recommendations in AWS Well-Architected Agent

AWS Well-Architected Agent is in preview release and is subject to change.


Prescheduled remediations automate the implementation of recommendations at predetermined
 times using AWS Systems Manager Runbooks. This feature applies recommendations consistently without
 manual intervention.

In the recommendation details page, choose **View Details** to go to
 AWS Systems Manager and change the remediation schedule for a recommendation.
