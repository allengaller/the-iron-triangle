## Webhook 回调请求参数

### 支持的报告类型

| ReportType | 报告类型 | 说明 |
| --- | --- | --- |
| 0 | 日常巡检报告 | 账号级维度的云资源风险状况。 |
| 1 | 架构巡检报告 | 架构级维度的资源风险及变化趋势。 |
| 2 | 架构负载报告 | 架构级维度的资源性能与负载压力。 |
| 6 | 架构负载多维报告 | 架构级维度的多周期、多算法分析下资源容量水位与负载趋势。 |

### 回调配置

### 核心参数

| 字段 | 说明 |
| --- | --- |
| SubId | 订阅记录 ID |
| SubName | 订阅名称 |
| AppId / Uin | 客户账号信息 |
| ReportType | 报告类型枚举 |
| ReportTaskId | 报告任务 UUID |
| ReportCreatedAt | 报告生成时间（Unix 时间戳） |
| ReportData | 报告数据（结构因类型而异） |

### 响应规则

| 场景 | 规则 |
| --- | --- |
| HTTP 200 | 视为投递成功 |
| 5xx / 429 / 网络错误 | 自动重试，最多 3 次 |
| 4xx 错误 | 不重试 |

### 注意事项

### 特殊值说明

| 值 | 含义 |
| --- | --- |
| 9223372036854775807 | 第一天/第一个周的数据 |
| -- 或 - | 无数据 |
| riskLevel: -1 | 不支持评估 |
