# 功能概述

## 产品概述

### 核心定位

| 维度 | 说明 |
| --- | --- |
| **全渠道 ChatOps** | 既可在 WorkBuddy、Qclaw、LightClaw 等 AI 工作台使用，也可直连企业微信、QQ、飞书、钉钉、Slack、个人微信等 IM 渠道，将 DevOps 能力无缝嵌入日常协作链路。 |
| **全天候 AIOps** | 7×24 小时主动巡检、主动诊断、主动播报，从被动响应到主动决策的智能运维新范式。 |
| **全方位 CloudOps** | 一只“龙虾”统一纳管腾讯云、阿里云、AWS、Azure、GCP 等主流云服务（相关能力陆续开放中）。 |

| 角色 | 主要价值 |
