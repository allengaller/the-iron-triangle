# 完成状态口径

> 三书共用的状态页。口径自 2026-11-17 起生效。

三本书统一用四级状态。状态只看证据，不看声称。

| 状态 | 判定条件 | 读者可以怎么用 |
| --- | --- | --- |
| **草稿** | 结构未齐，章节仍在大幅调整 | 不要引用 |
| **初稿** | 文件齐备，形式门禁通过 | 可以试读，观点可能变 |
| **成稿** | 内容完成，内部质化审计通过 | 可以引用，欢迎试读挑错 |
| **定稿** | 试读通过、发布检查表全过、时效性内容时点刷新 | 可以正式引用，标注版本号 |

形式门禁与质化审计的执行方式见仓库根 [`shared/tooling/`](../shared/tooling/README.md)（口径三书通用），规范见 [QUALITY-GATE](governance/QUALITY-GATE.md)。

## 状态怎么改

升一级要拿出判定证据，证据跟着状态走。状态变更时同步三处：本书 README 首段、根 README 状态表、本页。三处不一致视为门禁失败。

## 状态不等于质量

成稿不等于完美，初稿不等于不能用。状态只回答一个问题：这本书现在适合怎么用，引用时该带什么限定。
