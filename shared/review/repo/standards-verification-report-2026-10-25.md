## 一、校验范围、口径与方法

### 1.1 覆盖范围

| 目录 | 内容文件 | 索引 | 采集脚本（不校验） |

说明：3 个 `.py` 文件为采集脚本，不属于标准/法规文本，不在本次校验范围；两个 `README.md` 虽非标准文本，但承担索引与状态声明功能，其错误会直接误导引用，故单列校验（见第三、四章末节）。

### 1.2 校验维度

1. **文件身份与元数据**：标准号/文号、名称、发布机构、发布日期、实施日期、版本年份、代替/被代替关系。
2. **正文归属**：正文是否确属该文件，有无标题与正文不符、张冠李戴、抓到其他文件。
3. **条款完整性**：条款缺失、截断、重复、错位、网页导航污染，条号连续性与正确性。
4. **条款准确性**：条文表述、数字、期限、金额、比例、责任主体、适用范围与官方文本的一致性。
5. **时效性**：是否被修订、替代、废止；废止文件的替代关系与依据。
6. **引用与交叉引用**：文中引用的标准号、条款号、文件名称是否真实存在且指向正确。

### 1.3 结论与问题分级口径

**总体结论**（仅使用用户指定的三类）：

- **通过**：文件身份可确认、正文归属正确、未发现事实性错误；允许存在字段缺失、模板措辞等非实质性“一般/提示”问题。
- **存在问题**：存在事实性错误（张冠李戴、文号/日期/名称/状态错误）或关键内容缺失。
- **无法核验**：正文缺失且身份要素无法确认，或关键事实缺乏可依据的权威来源。

**问题严重程度**：

- **严重**：正文张冠李戴、关键条款缺失、关键文号/日期/数字错误（足以导致引用失效或合规判断错误）。
- **一般**：元数据字段错误或缺失、标准类别/编号写法错误、正文污染、错字漏字、条号笔误。
- **提示**：版本与时效性需关注（新版已发布、过渡期、状态待复核）、来源层级偏低。

> 特别说明：按用户口径“时效性”原则上归入“提示”；但若文件把**已废止/已被全部代替**的标准标注为“现行”，属事实性状态错误，本报告标为“一般”，并同时给出“提示”说明。

**计数规则**：各文件“问题清单”中**带序号**的条目计入“问题数”；另起“**提示**：”段落的观察性说明不计入，仅作版本关注。

### 1.4 方法与局限（不得臆造的边界）

- **全文类文件（13 份）**：逐条阅读，核对条号连续性、首末条、章节结构、关键数值（罚款额度、期限、比例、责任主体、适用范围），并对关键条文与官方/权威转载逐句比对。
- **元数据类文件（84 份）**：核对标题、标准号/文号、名称、类别、状态、来源链接；条款维度标注“不适用（无正文）”。
- **外部核验**：优先采用发布机构官网、国家法律法规数据库、国家标准全文公开系统、全国标准信息公共服务平台、金融标准全文公开系统、中国政府网；行业媒体与百科仅用于交叉验证。
- **局限**：官方平台普遍反爬，未能取得全部标准的机读官方全文，故**未做全文字符级 diff**；对未能确认的日期、条数、链接归属，一律标注“未核实”，不据推测判定对错。凡标注“未核实”的结论，均不参与“严重问题”计数。

### 5.3 元数据字段系统性缺失

### 5.8 官方链接未做可达性校验

- 现象：`gov.cn/zhengce/2024-03/19/content_6939768.htm`（计算机条例）与 `gov.cn/zhengce/2021-09/01/content_5631671.htm`（CII 条例）本次访问均返回 **404**，前者还挂着“2024 年最新版”的虚构版本标注。 另有 `gov.cn/gongbao/content/2010/content_1641235.htm`（银监办发〔2010〕114 号）本次亦返回 404，且金融监管总局站内无该文，直接导致该文件无法补齐全文（见 6.7）。
- 影响：链接是唯一的外部可追溯入口，失效后读者既无法核对正文，也无法发现版本标注错误。
- 成因：采集脚本只做“写入 URL”，未做“URL 可达 + 标题匹配”复核（与 5.7 同源）。
- 建议：采集与季度对账时对全部外链做 HEAD/GET 探测，状态码非 200 或页面标题不含文件名的，标记“链接失效”并回退到 `flk.npc.gov.cn` / 发布机构官网重新定位。

### 5.9 建议的最小整改机制

1. 每个文件增加必填字段：发布日期、实施日期、发布机构、文号/公告号、代替关系、废止日期（若适用）。
2. 采集流程增加 6 条硬断言（上述 5.7），任一不通过则状态不得标“✅”。
3. 链接去重检查：同一 URL 出现在两份以上文件时告警。
4. 季度对账：以 `std.samr.gov.cn`、`flk.npc.gov.cn`、`cfstc.pbc.gov.cn` 为基准，比对状态字段。
5. README 的统计数字由脚本生成，不手写。
6. 外链可达性纳入季度对账（5.8），失效链接一律降级为“待重取”。
