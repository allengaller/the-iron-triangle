## 这本书讲什么

技术销售的岗位方法书。核心命题：**把技术变成生意，把承诺变成可交付的合同。**

三句话概括：

- BTE 设计承诺；
- SA 证明承诺；
- TAM 兑现承诺。

卷首内容（版权与许可、承诺链、声明与脱敏、引用格式、完成状态口径）与姊妹书共用一套，源仓库位于 `shared/`（仓库根）。

## 已知限制

1. 读者试读与 BTE-01 实测尚未完成；决策门仍待执行。
2. 第 19 章采购流程描述未逐条核对法规；附录 F 已核对关键法规名称与状态。
3. EPUB 的跨书与公用卷链接指向仓库路径，阅读器内不保证跳转。
4. 案例全部虚构，数字仅用于演示。
5. 本书为方法实践汇编，不构成法律、财务或合规意见。
