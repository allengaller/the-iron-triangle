# BTE-01 模板实测包

> 用途：验证机会评分卡能否在真实或已关闭商机上使用，作为决策门的模板证据。
> 用法：3 名 BTE/SE 各测一个商机；按第 3–6 节执行；第 7 节汇总。
> 时点：v0.1，2026-11-03。

## 1. 目标

- 3 名测试者：在职 BTE 或 SE；
- 3 个商机：真实在跟、刚关闭、或已丢单均可；
- 目标：30 分钟内完成，评分有证据，能改变资源投入或退出决定。

## 2. 测试材料

- [BTE-01 机会评分卡](../../../books/the-bte-book/tpl-01-opportunity-scorecard.md)；
- [第 5 章](../../../books/the-bte-book/ch05-opportunity-judgment.md)；
- [第 11 章](../../../books/the-bte-book/ch11-lead-qualification.md)；
- 一个真实或已关闭商机的基本信息。

## 3. 任务说明

发给测试者：

> 请用 BTE-01 给你手上的一个商机打分。不要查书，不要问人，按你自己的判断填。限时 30 分钟。填完告诉我三件事：哪一栏最难填、哪一栏没用、你的决定有没有变化。

测试时不要提示答案，不要解释表格。观察真实使用。

## 5. 测试后访谈

1. 哪一栏最难填？为什么？
2. 哪一栏你觉得没用？删掉会怎样？
3. 五道硬门槛，有没有哪道判不了？
4. 评分结果和你原来的判断一致吗？不一致时你信哪个？
5. 如果只能保留三栏，你保留哪三栏？
6. 你会把这个表推荐给同事吗？为什么？

## 6. 评分标准

| 项 | 通过标准 |
| --- | --- |
| 完成时间 | ≤30 分钟 |
| 硬门槛判定 | 5 项均给出是/否与证据 |
| 评分证据 | 至少 80% 评分项有证据 |
| 决策变化 | 至少 1/3 测试者改变资源投入或退出决定 |
| 缺失字段 | 无阻断性缺失；新增字段 ≤3 个 |
| 可用性 | 至少 2/3 测试者愿意继续使用 |

## 10. 隐私与伦理

- 商机信息脱敏后使用；
- 不记录客户名、合同金额、报价；
- 测试记录只用于模板改进；
- 引用测试者原话先征得同意。
