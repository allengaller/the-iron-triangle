# 第 27+ 章　SA 团队建设动作

> 本章是[第 27 章](ch27-career-team.md)的 How-to 配套。四个动作：梯队盘点、分工配置、复盘喂回、沉淀入库。标尺用[第 26 章](ch26-sa-maturity-model.md) S1–S5。对标[《The TAM Book》第 38 章](../../the-tam-book/manuscript/ch38-career-team-building-howto.md)的团队建设模式。

## 27+.2 操作一：梯队盘点

### 操作步骤

1. 全员按 S1–S5 评定。证据口径照第 26 章，不看年头。
2. 画像三看：梯队分布、断层维度、备份真空（对标 TAM 技能矩阵读法）。
3. 断层补位计划：外训、招聘或带教，三选一写明。
4. 每半年刷新。与度量指标（第 25 章）同周期。

### 预期结果

画像三看齐。补位计划到人到时。

### 常见错误

- 评人凭印象。证据栏空着。
- 盘点不补位。断层年年在。

## 27+.3 操作二：分工配置

### 操作步骤

1. 单型分级：战略单、重点单、中小单。与 S 级匹配：S4 带战略，S2–S3 扛中小。
2. 主设计双备份。每个战略单有第二主设计。
3. 成长通道：S1–S2 挂带教。带教工作量计入带教人考核。

### 预期结果

单型匹配。战略单双备份。带教有考核。

### 常见错误

- 明星垄断战略单。断档风险。
- 带教算帮忙。没人愿意带。

## 27+.4 操作三：复盘喂回

### 操作步骤

1. 赢单输单都复盘。复盘模板走[《The TAM Book》附录 R](../../the-tam-book/manuscript/appx-r-problem-retrospective-standard.md)。
2. 规律抽象成打法条目。对标第 20 章跨案例规律。
3. 打法进库前过评审。与既有条目去重。
4. 每季度回顾打法库。用不上的条目标注退休。

### 预期结果

复盘零缺。打法条目化。库有新陈代谢。

### 常见错误

- 只复盘输单。赢单的运气成分没人拆。
- 复盘不成文。规律留在会议室。

## 27+.5 操作四：沉淀入库

### 操作步骤

1. 三类沉淀：提示词模板（22 章）、案例（第 20 章五段体例）、检查表（SA-01–05）。
2. 入库三要素：出处、适用场景、版本。
3. 入库即共享。个人收藏不算沉淀。
4. 年度归档。旧版本封存不删。

### 预期结果

三类沉淀入库。要素齐备。共享可用。

### 常见错误

- 沉淀在个人盘。人走技失。
- 无版本管理。新旧混用。

## 27+.6 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 梯队画像 | 三看齐、证据在案 | 核对画像 |
| 补位计划 | 到人到时 | 核对计划 |
| 分工匹配 | 单型与 S 级对应 | 核对分工表 |
| 双备份 | 战略单第二主设计在 | 核对台账 |
| 复盘率 | 赢单输单全覆盖 | 核对复盘记录 |
| 沉淀入库 | 三要素齐、共享可用 | 核对入库清单 |

关键项是梯队画像、双备份和沉淀入库。缺任何一项，团队建设这一项都先记为未达标。

## 27+.7 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 评定起争议 | 凭印象不凭证据 | 回第 26 章证据口径 |
| 明星垄断 | 分工不匹配 | 强制双备份 |
| 复盘断档 | 只记输单 | 赢单输单全覆盖 |
| 打法库没人用 | 条目不可执行 | 补适用场景再入库 |
| 沉淀流失 | 个人收藏 | 入库三要素强制 |

反复出现的问题进入复盘流程（[《The TAM Book》附录 R](../../the-tam-book/manuscript/appx-r-problem-retrospective-standard.md)）。

## 27+.8 执行检查清单

- [ ] 全员 S 级评定，证据在案
- [ ] 画像三看齐，补位计划到人到时
- [ ] 单型与 S 级匹配，战略单双备份
- [ ] 带教工作量计入考核
- [ ] 赢单输单复盘零缺
- [ ] 打法条目过评审、有退休机制
- [ ] 三类沉淀入库，三要素齐
- [ ] 年度归档，旧版封存

---

**本章要点回顾**

1. 梯队盘点照 S 级证据口径。断层补位到人到时。
2. 分工按单型。战略单双备份，带教算工作量。
3. 赢单输单都复盘。规律条目化，库有新陈代谢。
4. 沉淀入库才算数。人走技留，团队才立得住。
