# 第 15 章　POC 与评测

> 流程篇第五步。POC（Proof of Concept，概念验证）是把方案跑给客户看的一步。核心纪律只有两条：**成功标准事前量化，退出条件命中即停**。计划书用[模板 SA-02](../templates/sa-02-poc-plan.md)。上游是[第 13 章](ch13-design-review.md)冻结基线。POC 不承诺生产可用性（承诺纪律见[第 9 章](ch09-commitment-engineering.md)）。

## 15.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 方案基线 | 已冻结 | 回第 13 章 |
| 成功标准 | 来自需求基线验收标准 | 回第 12 章 |
| 环境责任 | 资源、数据、账号分工明确 | 先签环境清单 |
| 合规 | 数据脱敏与授权就绪 | 先过合规审 |

完成标志有三项：标准事前签、退出有红线、结论三选一。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 标准事前签 | 量化达标线双方签认 | SA-02 第一节 |
| 退出有红线 | 命中即停条款书面化 | SA-02 第六节 |
| 结论三选一 | 转方案/延期复测/终止 | 验收签认 |

## 15.2 操作一：POC 立项

### 操作步骤

1. 目标一句话。写清“POC 要证明什么”。写不清就不开。
2. 范围与非目标分开写。范围收窄，验证才有力。
3. 环境清单责任到人。谁出资源、谁出数据、谁开账号，白纸黑字。
4. 计划书双方签认（SA-02）。未签认不开环境。

### 预期结果

目标一句话。范围与非目标分明。环境责任签认。

### 常见错误

- 目标写成“验证一下方案”。不可测，等于没写。
- 范围贪大。什么都验，什么都验不深。
- 环境责任含糊。开跑当天卡在账号上。

## 15.3 操作二：成功标准事前量化

### 操作步骤

1. 标准从需求基线的验收标准来（[第 12 章](ch12-requirements-research.md)）。不新造标准。
2. 每条标准三件套：测量方法、达标线、数据源。
3. 场景与用例对应标准。跑不到标准的用例不上表。
4. 标准双方书面确认。未确认不进场。

### 预期结果

每条标准可测。用例对应标准。签认在案。

### 常见错误

- 标准写“效果良好”。不可测。
- 用例跑偏。测的不是承诺的东西。
- 标准事后定。结论永远是“基本达成”。

## 15.4 操作三：执行与风险控制

### 操作步骤

1. 时间表四节点：环境就绪、执行窗口、结论汇报、复测（如有）。
2. 现场纪律：只测清单内场景。现场新增需求记入需求变更，不顺手做。
3. 退出条件命中即停（SA-02 第六节）。三类红线：标准无法量化、环境两周未就绪、数据合规未解。
4. 风险控制：POC 环境与生产隔离。数据脱敏。结论不外推生产表现。

### 预期结果

按清单执行。退出红线守住。风险控制留痕。

### 常见错误

- 现场顺手加需求。POC 变成免费项目。
- 退出拖泥带水。环境两周开不起来还在等。
- 结论外推生产。POC 达标等于生产可用，是误读。

## 15.5 操作四：验收与结论

### 操作步骤

1. 对照成功标准逐条填实测值。不带形容词。
2. 结论三选一：转方案、延期复测（上限一次）、终止。
3. 双方签认结论。签认后归档。
4. 结论喂回上游：转方案进第 16 章报价，终止进第 11 章止损复盘。

### 预期结果

实测值逐条在案。结论签认。去向清晰。

### 常见错误

- 实测填形容词。结论无法复核。
- 复测无限延期。资源吊在半空。
- 结论不签认。事后各执一词。

## 15.6 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 目标与范围 | 一句话目标、非目标分明 | 核对 SA-02 |
| 环境签认 | 责任到人 | 核对环境清单 |
| 成功标准 | 测量方法、达标线、数据源齐 | 核对 SA-02 |
| 标准签认 | 双方书面确认 | 核对签认 |
| 退出红线 | 三类红线书面化 | 核对 SA-02 |
| 执行纪律 | 只测清单内场景 | 核对执行记录 |
| 结论签认 | 三选一、双方签认 | 核对验收签认 |

关键项是成功标准签认、退出红线和结论签认。任一关键项未通过，POC 不得视为合格。

## 15.7 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| POC 无结论 | 标准不可测 | 退回重定三件套 |
| 环境拖两周 | 责任没签认 | 按清单追责或退出 |
| 现场需求膨胀 | 边界没守住 | 记入变更，不顺手做 |
| 结论扯皮 | 标准事后定 | 事前签认流程重跑 |
| 复测无限期 | 无上限约定 | 复测上限一次 |
| 生产误读 | 结论外推 | 补“不外推生产”声明 |

反复出现的问题进入复盘流程（[《The TAM Book》附录 R](../../the-tam-book/manuscript/appx-r-problem-retrospective-standard.md)）。

## 15.8 执行检查清单

- [ ] 目标一句话，范围与非目标分明
- [ ] 环境清单责任到人，双方签认
- [ ] 成功标准三件套齐（测量方法、达标线、数据源）
- [ ] 标准书面确认后才进场
- [ ] 退出三红线书面化
- [ ] 只测清单内场景，新增需求走变更
- [ ] 实测值逐条填写，无形容词
- [ ] 结论三选一并双方签认
- [ ] 结论去向清晰：转报价或进止损复盘

---

**本章要点回顾**

1. POC 目标一句话。写不清就不开。
2. 成功标准三件套事前签：测量方法、达标线、数据源。
3. 退出三红线命中即停。POC 不承诺生产可用性。
4. 实测不带形容词。结论三选一签认，去向清晰。
