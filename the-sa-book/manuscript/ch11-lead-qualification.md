# 第 11 章　线索评估与立项

> 流程篇从售前生命周期第一步开始。线索阶段的判断决定后面所有投入。跟错一个单，团队白干三个月。本章三个动作：线索四问判定、资源投入决策。里程碑复核与止损。分工先立住：线索主责在 BTE（技术销售）。SA 负责技术面判定。角色边界见[第 2 章](ch02-triangle-boundary.md)。

## 11.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 线索信息 | 客户、场景、时点三要素已知 | 退回 BTE 补信息 |
| 竞争位置 | 初步竞品情报 | 补 SA-04 事实行 |
| 履约预判 | 交付与 TAM 初步意见 | 开预沟通 |
| 台账 | 售前台账可登记 | 先建台账 |

完成标志有三项：四问有判定、投入有分档、节点有复核。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 四问有判定 | 跟进/缓跟/放弃三态 | 判定表 |
| 投入有分档 | 投入档与判定挂钩 | 立项登记 |
| 节点有复核 | 里程碑复核与止损条件 | 复核记录 |

## 11.2 操作一：线索四问判定

### 四问

| 问 | 判定问题 | 证据 |
| --- | --- | --- |
| 需求真不真 | 痛点是业务级还是随口提 | 冰山探过吗（[第 6 章](ch06-insight-translation.md)） |
| 预算有没有 | 钱在哪、谁批 | 决策口接触过吗 |
| 赢面多大 | 差异化讲得出吗 | 竞争位置初判（SA-04） |
| 交付接得住吗 | 履约成本可算吗 | 可运营性预判（[第 7 章](ch07-solution-engineering.md)） |

### 判定三态

- **跟进**：四问全过。进资源投入决策（11.3）；
- **缓跟**：一问答不上。限期补齐再判。不投实质资源；
- **放弃**：两问以上答不上。书面记录原因，礼貌退出。

### 操作步骤

1. BTE 提供线索三要素。缺要素先补。
2. SA 过四问。每问写明证据，不写感觉。
3. 出判定三态。缓跟限期，放弃留因。
4. 判定进售前台账。月度复盘判定准确率。

### 预期结果

每条线索有三态判定。判定有证据。台账可复盘。

### 常见错误

- 感觉好就跟。四问空着，投入全靠热情。
- 什么单都跟。资源摊薄，好单做不深。
- 放弃不留因。同样的坑再掉一次。

## 11.3 操作二：资源投入决策

### 投入三档

| 档 | 投入 | 适用 |
| --- | --- | --- |
| 小 | 一次技术交流 | 缓跟、验证需求 |
| 中 | 方案加 POC | 跟进、赢面中等 |
| 大 | 定制方案加现场 | 跟进、战略单 |

### 操作步骤

1. 投入档与判定挂钩。缓跟只给小投入。
2. 大投入要双签。SA 与 BTE 共同确认。
3. 立项登记进台账。写明投入档与预期时点。
4. 投入超档要复盘。谁批的、为什么。

### 预期结果

投入与判定一致。大投入有双签。台账记录完整。

### 常见错误

- 缓跟单配大投入。资源错配。
- 大投入一人拍。风险单点。
- 台账不记投入。季度复盘对不上账。

## 11.4 操作三：里程碑复核与止损

### 复核点

| 节点 | 复核内容 | 出口 |
| --- | --- | --- |
| 需求调研后 | 四问答案变没变 | 续投/降档/退出 |
| 方案启动前 | 预算与竞争位置 | 续投/退出 |
| POC 结束 | 赢面与履约预判 | 续投/退出 |

### 止损条件

- 四问任一答案恶化且不可逆；
- 预算冻结或决策人变动；
- 对手锁定已成定局。

### 操作步骤

1. 里程碑强制复核。不复核不续投。
2. 止损条件命中即退出。退出书面留因。
3. 退出复盘归档。喂回四问清单。

### 预期结果

复核点零跳过。退出有记录。四问清单越用越准。

### 常见错误

- 沉没成本绑架。“都投这么多了”不是续投理由。
- 退出拖泥带水。资源耗在救不回的单上。
- 复核变过场。答案恶化没人看。

## 11.5 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 四问判定 | 三态齐全、证据在案 | 核对判定表 |
| 投入分档 | 与判定一致 | 核对台账 |
| 大投入双签 | SA 与 BTE 签认 | 核对签认 |
| 里程碑复核 | 节点零跳过 | 核对复核记录 |
| 止损执行 | 命中即退、书面留因 | 核对退出记录 |
| 复盘归档 | 退出复盘进四问清单 | 核对清单版本 |

关键项是四问判定、投入分档和止损执行。任一关键项未通过，线索立项不得视为合格。

## 11.6 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 跟错单浪费三个月 | 四问没过就投 | 补判定再投入 |
| 资源摊薄 | 什么单都跟 | 按三态收口 |
| 大投入爆雷 | 无双签 | 补双签机制 |
| 救不回的单拖着 | 沉没成本绑架 | 止损条件硬执行 |
| 判定准确率低 | 判定写感觉 | 强制写证据 |
| 台账对不上 | 立项不登记 | 立项即登记 |

反复出现的问题进入复盘流程（[《The TAM Book》附录 R](../../the-tam-book/manuscript/appx-r-problem-retrospective-standard.md)）。

## 11.7 执行检查清单

- [ ] 线索三要素齐全（客户、场景、时点）
- [ ] 四问逐条有证据，判定三态在案
- [ ] 投入档与判定一致
- [ ] 大投入有 SA 与 BTE 双签
- [ ] 立项已登记售前台账
- [ ] 里程碑复核点已排期
- [ ] 止损条件书面化
- [ ] 退出复盘归档并喂回四问清单

---

**本章要点回顾**

1. 线索四问：需求真不真、预算有没有、赢面多大、交付接得住。问要证据，不问感觉。
2. 判定三态收口。缓跟限期，放弃留因，跟进才配资源。
3. 投入三档挂钩判定。大投入双签，投入超档要复盘。
4. 里程碑强制复核，止损命中即退。沉没成本不是续投理由。
