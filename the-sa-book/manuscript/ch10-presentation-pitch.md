# 第 10 章　呈现与讲标

> 讲标是方案的临门一脚。呈现不是表演，是把判断讲到客户敢拍板。本章四个动作：讲标四原则、六十秒口头版。Demo 与 PPT 叙事分工、答疑攻防。讲标全程用[模板 SA-05](../templates/sa-05-pitch-checklist.md)过检查表。对标[《The TAM Book》高层对话四原则](../../the-tam-book/manuscript/ch07-practical.md)，场景换成售前。

## 10.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 方案定稿 | 过第 7+ 章评审与五维 | 先补评审 |
| 叙事线 | 一句话差异已定 | 先过 SA-04 |
| 分工表 | 答疑四域应答人已定 | 先填 SA-05 |
| 环境 | Demo 双备份就绪 | 先录兜底屏 |

完成标志有四项：六十秒版背熟、叙事顺序不乱。答疑零裸奔、会后 24 小时纪要。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 六十秒版 | 开场即价值 | 现场实测 |
| 叙事顺序 | 业务层先行 | 讲稿结构 |
| 答疑零裸奔 | 每域有应答人 | SA-05 分工表 |
| 会后闭环 | 24 小时纪要 | 纪要签认 |

## 10.2 操作一：讲标四原则

对标高层对话四原则（TAM 书），售前版四条：

1. **价值先行**：开场六十秒讲清客户买的是什么。技术细节备而不报，问到再展开；
2. **一图到底**：三层图走全程（[第 7+ 章](ch07-practical.md)）。第二页是附件，不是正文；
3. **给选择题**：两案带代价让客户拍板（[第 7 章](ch07-solution-engineering.md)）。单案汇报等于把决定权收回来；
4. **会后闭环**：24 小时内书面纪要。行动项责任到人、时间到日。

### 预期结果

开场即价值。全程一张图。客户拿到选择题。会后有纪要。

### 常见错误

- 开场铺垫十分钟。客户注意力在第 2 分钟就散了。
- 技术细节当正文。业务决策者提前退场。
- 只带一个方案。名为汇报，实为通牒。

## 10.3 操作二：六十秒口头版

### 写法

三句结构：**痛点一句、方案一句、差异一句**。

- 痛点句：客户最疼的那个点（第 6 章反向翻译的头号痛点）；
- 方案句：用一句话说清怎么解；
- 差异句：为什么是我们（SA-04 一句话差异）。

### 操作步骤

1. 写三句。每句不超过两口气。
2. 念出来计时。超 60 秒删词，不删意思。
3. 找非技术同事听。听懂了才算熟。
4. 把三句背到张口就来。开场不看稿。

### 预期结果

六十秒内说清痛点、方案、差异。非技术听众能复述。

### 常见错误

- 三句写成三段。时间爆掉。
- 差异句写成自夸。客户记不住。
- 背不熟。开场看稿，气场先输一半。

## 10.4 操作三：Demo 与 PPT 的叙事分工

| 载体 | 讲什么 | 不讲什么 |
| --- | --- | --- |
| PPT | 价值、结构、证据 | 界面操作细节 |
| Demo | 真实跑通的关键旅程 | 全功能巡礼 |
| 录屏 | 兜底（Demo 环境故障时） | 代替现场 |

### 操作步骤

1. PPT 只承载三层图与证据。界面截图不超过三张。
2. Demo 只跑关键旅程。跑通两三个场景，胜过巡礼二十个功能。
3. Demo 环境双备份。现场故障切录屏，不修现场。
4. 讲序：PPT 铺垫 → Demo 证真 → PPT 收尾请求。

### 预期结果

Demo 跑通关键旅程。故障时无缝切录屏。叙事不中断。

### 常见错误

- Demo 变功能巡礼。客户记不住重点。
- 现场修环境。三分钟冷场，信任掉一半。
- PPT 塞满截图。看图找不到主线。

## 10.5 操作四：答疑攻防

### 问题四类与应答

| 类型 | 特征 | 应答策略 |
| --- | --- | --- |
| 技术深挖 | 追实现细节 | 深锚点领域正面答；跨界问题引专家 |
| 商务压价 | 追价格与折扣 | 回 BTE；技术侧守报价底座（第 8 章） |
| 竞品挑衅 | “X 家比你强” | 按对比叙事答，不贬损（第 8 章） |
| 刁钻假设 | “如果……怎么办” | 回翻盘条件与风险清单（第 7 章） |

### 纪律

- **标准话术**：拿不准就说“我记下来，核实后今天内回复”。然后把“今天内”兑现掉；
- **不新增承诺**：现场答问不构成承诺。承诺一律走四问入清单（[第 9 章](ch09-commitment-engineering.md)）；
- **分工表上桌**：四域应答人写在 SA-05。抛问题前先看表。

### 预期结果

四类问题都有应答人。现场零新增承诺。标准话术用得出手。

### 常见错误

- 全场一人扛。冷场在不熟的领域。
- 现场随口承诺。会后清单对不上账。
- 竞品问题上头。贬损一句，人品折价三分。

## 10.6 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 六十秒版 | 60 秒内讲清痛点、方案、差异 | 计时实测 |
| 非技术验证 | 听众能复述 | 会后抽问 |
| 叙事顺序 | 业务层先行，PPT-Demo-PPT | 讲稿核对 |
| Demo 备份 | 双备份，可切录屏 | 现场检查 |
| 答疑分工 | 四域有应答人 | 核对 SA-05 |
| 现场承诺 | 零新增 | 核对承诺清单 |
| 会后纪要 | 24 小时内，责任到人 | 核对纪要 |

关键项是六十秒版、答疑分工和现场承诺零新增。任一关键项未通过，讲标不得视为合格。

## 10.7 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 开场冷场 | 没讲价值先铺垫 | 重写六十秒版 |
| 客户听不懂 | 从技术层开讲 | 重排业务层先行 |
| Demo 翻车 | 单环境无备份 | 补录屏双备份 |
| 答疑当场卡壳 | 分工表没填 | 补 SA-05 应答人 |
| 现场承诺失控 | 口头顺手答应 | 走四问入清单 |
| 竞品问题失态 | 情绪上头 | 回对比叙事口径 |
| 会后无下文 | 纪要拖延 | 24 小时硬时限 |

反复出现的问题进入复盘流程（[《The TAM Book》附录 R](../../the-tam-book/manuscript/appx-r-problem-retrospective-standard.md)）。

- [ ] Demo 双备份（环境 + 录屏）

---

**本章要点回顾**

1. 讲标四原则：价值先行、一图到底、给选择题、会后闭环。
2. 六十秒版三句：痛点、方案、差异。背到不看稿。
3. PPT 讲价值，Demo 讲真实，录屏兜底。现场不修环境。
4. 答疑四类四策略。现场零新增承诺，拿不准用标准话术。
