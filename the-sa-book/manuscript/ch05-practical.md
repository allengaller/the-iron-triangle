# 第 5+ 章　架构估算实战

> 本章是[第 5 章](ch05-technical-breadth.md)的 How-to 配套。三个动作：参考架构选型、信封背面估算、架构权衡记录。权衡记录三段定义见[第 7+ 章](ch07-practical.md)，本章补架构维度字段。

## 5+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 需求已知 | 场景、规模、约束白纸黑字 | 先补需求调研 |
| 技术栈面 | 候选产品面已列全 | 先建技术雷达 |
| 标尺 | 六维评审口径可用 | 引 TAM 书第 6 章 |
| 模板 | 权衡记录模板可用 | 先建模板 |

完成标志有三项：选型有对照、估算有量级、权衡有留痕。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 选型有对照 | 候选不少于两案 | 选型对照表 |
| 估算有量级 | 2 分钟内出量级 | 估算底稿 |
| 权衡有留痕 | 差异点零遗漏 | 权衡记录 |

## 5+.2 操作一：参考架构选型

### 操作步骤

1. 列候选：厂商参考架构加自研惯用架构。候选不少于两案。
2. 六维初筛：可用性、扩展性、安全、可运维、成本、合规。口径引[《The TAM Book》第 6 章](../../the-tam-book/manuscript/ch06-technical-depth-practical.md)。
3. 跨厂商统一标尺。对照表见[《The TAM Book》附录 Z](../../the-tam-book/manuscript/appx-z-well-architected-framework.md)。
4. 差异点逐条进权衡记录（5+.4）。

### 预期结果

候选不少于两案。差异点全部留痕。初筛有六维结论。

### 常见错误

- 只列一案。名为选型，实为指定。
- 照抄参考架构不改。差异点没进记录。
- 标尺不统一。拿 A 家的优点比 B 家的缺点。

## 5+.3 操作二：信封背面估算

### 容量三步

1. **量级基线**：用户量或交易量 × 峰值系数；
2. **单次开销**：响应时间、吞吐、资源水位的量级；
3. **乘出来**：QPS、存储、带宽的量级。

### 成本三步

1. **资源量级**：来自容量估算；
2. **单价量级**：官网牌价，不议价；
3. **三年乘出来**：输出回填 SA-03（TCO 模型）。

### 判据

2 分钟内出量级。偏差一个数量级内可接受。量级错了才是事故。

### 预期结果

容量与成本都有量级底稿。底稿含假设与出处。

### 常见错误

- 追求精算。区间输入算不出精确输出。
- 只算平均不算峰值。峰值期翻车。
- 成本漏隐性项：迁移、培训、闲置。

## 5+.4 操作三：架构权衡记录

### 架构维度四字段

三段（选择、放弃、翻盘）定义见[第 7+ 章](ch07-practical.md)。架构记录补四字段：

| 字段 | 回答的问题 |
| --- | --- |
| 候选案 | 还考虑过谁 |
| 关键差异 | 赢在哪、输在哪 |
| 依赖假设 | 什么前提下成立 |
| 回退路径 | 假设崩了怎么退 |

### 操作步骤

1. 每个差异点一条记录。不合并、不省略。
2. 四字段与三段齐全。缺字段的记录返工。
3. 记录随方案基线移交（模板 19，两书共用）。
4. 翻盘条件可执行。不写“视情况而定”。

### 预期结果

差异点零遗漏。翻盘条件可执行。记录随基线移交。

### 常见错误

- 事后补记录。记忆美化了判断。
- 差异点口头带过。交接时对不上账。
- 依赖假设不写。假设崩了没人知道为什么。

## 5+.5 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 选型对照 | 候选不少于两案、六维初筛齐 | 核对对照表 |
| 统一标尺 | 跨厂商同一把尺 | 抽查对照表 |
| 估算量级 | 2 分钟内出量级 | 现场实测 |
| 估算底稿 | 含假设与出处 | 核对底稿 |
| 权衡记录 | 三段加四字段齐全 | 抽查记录 |
| 翻盘条件 | 可执行，非“视情况” | 抽查记录 |
| 移交随行 | 记录随基线移交 | 核对模板 19 |

关键项是估算量级、权衡记录和翻盘条件。任一关键项未通过，架构估算不得视为合格。

## 5+.6 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 客户质疑选型 | 标尺不统一 | 重跑六维对照 |
| 估算评审翻车 | 量级算错数量级 | 重做信封背面估算 |
| 评审推翻权衡记录 | 事后补写 | 改为决策当刻留痕 |
| 翻盘扯皮 | 条件写“视情况” | 补可执行信号 |
| 交接对不上账 | 差异点口头带过 | 全量补记录 |
| 成本超出预算 | 隐性项漏算 | 补迁移培训闲置三项 |

反复出现的问题进入复盘流程（[《The TAM Book》附录 R](../../the-tam-book/manuscript/appx-r-problem-retrospective-standard.md)）。

## 5+.7 执行检查清单

- [ ] 候选不少于两案，六维初筛有结论
- [ ] 跨厂商对照用统一标尺
- [ ] 容量与成本 2 分钟内出量级
- [ ] 估算底稿含假设与出处
- [ ] 权衡记录三段四字段齐全
- [ ] 翻盘条件可执行
- [ ] 记录随方案基线移交

---

**本章要点回顾**

1. 选型三步：列候选、六维初筛、差异留痕。标尺统一是底线。
2. 估算六步：量级基线、单次开销、乘出来；资源量级、单价量级、三年乘出来。
3. 权衡记录三段四字段。差异点零遗漏，翻盘条件可执行。
4. 判据就一条：量级正确。精算是伪专业。
