# 第 8+ 章　TCO 与竞争实战

## 8+.2 操作一：TCO 建模

### 操作步骤

1. 先写假设表。折现率、人力单价、增长率，逐条列出出处。
2. 按成本项填三年对比。一次性与经常性分开（字段见 SA-03）。
3. 隐性成本三件套入表：迁移、培训、闲置。
4. 跑敏感性三档：业务量、人力单价、增长率各取低/基准/高。
5. 输出摘要回填 SA-01 第七节。口径与 SA-03 一致。

### 预期结果

三年 TCO 对比可复算。假设逐条可挑战。敏感性结论一句话说得清。

### 常见错误

- 假设不写。客户只能怀疑，不能讨论。
- 只比首单价。三年视角才是 TCO。
- 隐性成本漏算。签单后迁移费打爆预算。

## 8+.3 操作二：竞争对比

### 操作步骤

1. 维度对齐客户需求。权重由需求定，不撒胡椒面。
2. 事实行逐格填出处。没有出处的格子留空，不硬填。
3. 判断行单独写。判断依据列出来。
4. 写对比叙事：一句话差异 + 三条支撑 + 承认边界。
5. 版本注明日期。竞品迭代快，旧表不复用。

### 预期结果

事实行零裸奔。对比叙事上得了桌。竞品优势如实呈现。

### 常见错误

- 事实判断混写。客户追问出处当场崩。
- 全优对比表。一眼识破，全表作废。
- 贬损对手。折价的是自己人品。

## 8+.4 操作三：报价与让步

### 报价结构三段

| 段 | 内容 | 映射 |
| --- | --- | --- |
| 平台段 | 许可、订阅 | 方案基础层 |
| 服务段 | 实施、培训、运维 | 方案服务层 |
| 弹性段 | 扩容、POC、专项 | 方案可选项 |

### 让步阶梯

| 阶梯 | 让什么 | 换什么 |
| --- | --- | --- |
| 一 | 付款节奏 | 签约时间 |
| 二 | 服务范围分期 | 首期金额 |
| 三 | 价格小幅 | 多年期或增购承诺 |

### 操作步骤

1. 报价按三段出。每段对应方案结构（第 7 章）。
2. 让步逐级走阶梯。每让一步，换回一条件。
3. 让步留痕：让了什么、换了什么，进谈判记录。
4. 承诺边界不进让步池。边界问题回第 9 章四问。

### 预期结果

报价分层可谈。让步成对出现。边界零让渡。

### 常见错误

- 一口价。客户没得谈，只能压总价。
- 单向让步。教客户继续压价。
- 边界进让步池。价格赢了，交付输了。

## 8+.5 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 假设表 | 显式列出、有出处 | 核对 SA-03 |
| 三年对比 | 一次性/经常性/隐性分列 | 核对 SA-03 |
| 敏感性 | 三档跑完 | 核对 SA-03 |
| 事实行 | 零裸奔、有出处 | 核对 SA-04 |
| 对比叙事 | 差异+支撑+承认边界 | 评审实测 |
| 报价三段 | 映射方案结构 | 核对报价单 |
| 让步记录 | 成对出现 | 核对谈判记录 |

关键项是假设表、事实行和让步记录。任一关键项未通过，商务竞争不得视为合格。

## 8+.6 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 客户质疑价格构成 | 报价不分层 | 改三段报价 |
| 客户推翻 TCO | 假设没写 | 补假设表重算 |
| 客户识破对比表 | 全优或裸奔 | 补出处、如实承认 |
| 让步越让越多 | 无交换原则 | 走让步阶梯 |
| 竞争失单 | 叙事没差异 | 重写一句话差异 |
| 交付期爆预算 | 隐性成本漏算 | 补迁移培训闲置 |

反复出现的问题进入复盘流程（[《The TAM Book》附录 R](../../the-tam-book/manuscript/appx-r-problem-retrospective-standard.md)）。

- [ ] 三年 TCO 一次性、经常性、隐性分列
- [ ] 敏感性三档跑完，结论一句话说得清
- [ ] 竞争事实行零裸奔

---

**本章要点回顾**

1. TCO 建模先写假设。假设显式化才有说服力。
2. 竞争三纪律落到操作：出处、分栏、承认。全优表等于全作废。
3. 报价三段映射方案结构。让步走阶梯，步步换条件。
4. 承诺边界不进让步池。价格的账可以算，交付的账不能欠。
