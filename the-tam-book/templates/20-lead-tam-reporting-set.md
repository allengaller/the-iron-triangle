# 模板 20　主 TAM 报告四件套（日／周／季／年）

> 用途：主 TAM 的例行报告填写件，含日报（RP1）、周报（RP2）、季报（RP3）、年报（RP4）四份。配套附录 AA（AA.5–AA.6 定位与判定线）、第 28 章（AI 辅助流水线与复核边界）、第 34 章（指标口径）、第 37 章（团队与绩效）、模板 08（QBR/EBR，同源不同面）。
> 用法：四份报告共用一张事实底稿（工单、变更、风险三源），上层引用下层编号，不复制原文（附录 AA.8）。日报连跑两周、稳定在 10 分钟内，再上其余三份；每份发出前过一遍对应自查。
> 时点：v0.1，2026-10 随书拟稿。

---

## 0. 报告抬头（每份必填）

| 字段 | 内容 | 填写要求 |
| --- | --- | --- |
| report_id | | 代号 + 周期，如 RP2-2026-W43 |
| cadence | | 日／周／季／年 |
| owner | | 具名（判断责任人），不写"团队" |
| period | | 覆盖区间，写到日 |
| audience | | 读者与层级 |
| status | | 在轨／预警／失控 |
| metrics_snapshot | | 关键指标 + 口径出处 |
| evidence_links | | 证据编号清单（工单／风险／承诺／复盘） |
| reviewed_by | | 复核人；AI 辅助稿必填 |

纪律：字段可以为空，但空字段必须写"无"——空着代表没想过，写"无"代表想过并判定没有。

时点基准（按组织作息调整，不得晚于它服务的决策）：日报当日 20:00 前、周报周一 12:00 前、季报季度结束后 7 个工作日内、年报次年 1 月 15 日前。报告随客户档案归档（附录 B.3.3），权限最小化，版本只增不删。
