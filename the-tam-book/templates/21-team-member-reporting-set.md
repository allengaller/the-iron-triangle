# 模板 21　TAM 团队成员报告四件套（日／周／季／年）

> 用途：TAM 团队成员的例行报告填写件，含日报（RP5）、周报（RP6）、季报（RP7）、年报（RP8）四份。配套附录 AA（AA.5、AA.7 定位与判定线）、附录 G（L1／L2／L3 评估证据）、附录 O（证据纪律：述职不算证据）、第 28 章（AI 辅助边界）、第 36 章（M1–M5 成熟度）、模板 12（能力自检）。
> 用法：日报只写 5 行，周报只算一笔账（承诺兑现），季报攒证据，年报做索引。四份报告的事实必须可回链到工单号、变更单号、风险编号或复盘编号；没有来源的表述删掉，不凑数。
> 时点：v0.1，2026-10 随书拟稿。

---

## 0. 报告抬头（每份必填）

| 字段 | 内容 | 填写要求 |
| --- | --- | --- |
| report_id | | 代号 + 周期，如 RP6-2026-W43 |
| cadence | | 日／周／季／年 |
| owner | | 本人姓名（判断责任人） |
| period | | 覆盖区间，写到日 |
| audience | | 主 TAM／服务经理／评审团 |
| status | | 在轨／预警／失控 |
| metrics_snapshot | | 关键指标 + 口径出处 |
| evidence_links | | 证据编号清单 |
| reviewed_by | | 复核人；AI 辅助稿必填 |

纪律：字段可以为空，但空字段必须写"无"。

时点基准（按组织作息调整，不得晚于它服务的决策）：日报当日下班前 30 分钟、周报周五 16:00 前、季报季度结束后 5 个工作日内、年报 12 月 31 日前。报告随客户档案归档（附录 B.3.3），默认可见范围为主 TAM + 服务经理。
