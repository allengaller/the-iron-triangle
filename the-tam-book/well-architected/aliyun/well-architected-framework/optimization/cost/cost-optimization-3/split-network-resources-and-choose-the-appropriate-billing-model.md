# 拆分网络资源并选择合适的计费模式

网络资源拆分是指将网络资源按照使用模式和业务需求进行分类管理，下面一种简单的网络资源拆分模式可供参考：

- 稳态资源：长期稳定运行的网络资源，如核心业务系统的固定带宽需求
- 弹性资源：流量波动较大的网络资源，如应对促销活动的临时带宽
- 备份资源：用于灾难恢复和冗余的网络资源

将网络资源拆分，将稳态流量使用预留容量，弹性流量使用按需资源，避免过度配置。客户根据其具体业务需求、流量特征和预算考虑，对网络资源进行拆分后，每个不同的网络单元从阿里云提供的网络计费方式中选择最经济、最适合的一种计费方案。

阿里云根据产品的不同，提供了多种计费模式，提供了如下计费模式

| 付费模式 | 公网计费方式 | 适用场景 |
| --- | --- | --- |
| 按量计费 | 按带宽计费 | 流量峰值比较稳定。资源使用有临时性和突发性。 |
| 按增强型95计费 | 业务流量峰值较大。流量峰值波动较大，且波动比较频繁。 |  |
| 按主流量计费 | 流量峰值波动较大。例如游戏、视频等行业。资源使用有临时性和突发性。如您无法预估流量使用情况时，建议选择按使用流量计费。 |  |
| 包年包月 | 按固定带宽计费 | 可预估资源使用周期。流量峰值比较稳定。需要长期使用资源（价格比按量付费更优惠）。 |
| CDT | 公网流量和专线私网流量进行统一汇总并统一计费 | 支持公网流量累计阶梯计费，每月按[地域](https://www.aliyun.com/getting-started/what-is/what-is-a-region)累计阶梯，用量越大单价越低。支持跨地域流量按流量计费，这种计费方式更加灵活，方便按需使用。支持FinOps：资源创建与账单分离提升交付效率，同时提供跨产品的统一流量账单和标签分账能力，提升业务、IT、财务协同效率，获得更多的财务控制和可预测性。 |

在选择前请详细评估您的业务流量模型，进行网络负载评估和资源拆分，然后使用阿里云提供的成本计算器进行预估，或咨询阿里云专业服务团队获取针对您业务场景的最佳建议。

## 优先级

中

## 不推荐做法

- 备份资源长期闲置：灾难恢复资源长期保持全量运行状态，而非按需激活
- 公网带宽计费模式选择不当：流量波动极大的业务（如秒杀活动）选择了预付费按固定带宽计费，导致活动期间带宽不足影响用户体验，活动结束后带宽大量闲置造成浪费。

## 实施指南

1. **流量分析与分类**：使用智能网络服务，流日志，云监控等产品分析网络流量模式，区分稳态和弹性流量。
2. **资源标记策略：**为不同类型的网络资源实施一致的标记策略，便于成本追踪。
3. **稳态资源优化**：为稳定流量模式配置预留容量，选择合适的计费模式。
4. **弹性资源配置**：为波动流量设置自动扩展策略和适当的缩放规则，选择合适的计费模式。
5. **备份资源管理**：实现按需激活的备份网络架构，避免长期全量运行。
6. **持续监控与优化**：定期审查网络资源使用情况，调整资源配置。
