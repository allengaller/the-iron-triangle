# Definitions

The AWS Well-Architected
 Framework is based on six pillars: operational excellence, security, reliability,
 performance efficiency, cost optimization, and sustainability. For serverless workloads, AWS
 provides multiple core components (serverless and non-serverless) that allow you to design
 robust architectures for your serverless applications. In this section, we will present an
 overview of the services that will be used throughout this document. There are eight areas that you
 should consider when building a serverless workload:

- [Compute layer](./compute-layer.html)

- [Systems monitoring and deployment](./systems-monitoring-and-deployment.html)
