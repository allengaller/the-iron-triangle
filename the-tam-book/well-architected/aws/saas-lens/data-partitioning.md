# Data Partitioning

As you look at different architecture patterns for representing
 multi-tenant data, you must make choices about how that data is
 organized. Will the data be stored in separate database, for
 example, or will it be comingled in a shared construct? These
 multi-tenant storage mechanisms and patterns are typically
 referred to as data partitioning.
