# Workload security

Securing Microsoft workloads requires a comprehensive approach that addresses the
 operating system, applications, databases, and underlying infrastructure. This focus area
 explores how to implement security hardening, patch management, and protective measures across
 each component of your Microsoft environment on AWS, verifying that each layer contributes
 to an overall robust security posture.

It's important to harden Microsoft applications and their underlying components,
 including operating systems, databases, cloud services, and infrastructure. This hardening
 should be applied to Microsoft environments, both production and non-production, at levels
 appropriate to your organization's needs.
