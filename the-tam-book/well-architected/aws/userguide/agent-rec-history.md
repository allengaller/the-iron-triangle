# View archived recommendations in AWS Well-Architected Agent

AWS Well-Architected Agent is in preview release and is subject to change.


To view recommendations that were completed or suppressed, choose **View archived
 recommendations** in the AWS WA Agent dashboard. Each archived recommendation contains
 information about the status, type, pillars, and closed date.

When you view an archived recommendation, you see a snapshot of the recommendation from
 before it was implemented. If the recommendation was suppressed, the reason for suppression is
 listed on the page.
