This section describes the AWS Well-Architected Container Build Lens in the context of
 the six pillars of the Well-Architected Framework. Each pillar describes a set of definitions,

 applications in the cloud. These include design principles, definitions, best practices,
 evaluation questions, considerations, key services, and useful links.
