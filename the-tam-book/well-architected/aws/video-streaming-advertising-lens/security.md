# Security

The security pillar encompasses the ability to protect data,
 systems, and assets to take advantage of cloud technologies to
 improve your security.

The security pillar provides an overview of design principles and
 questions. You can find implementation guidance in
 the
 [Security
 Pillar whitepaper](https://docs.aws.amazon.com/wellarchitected/latest/security-pillar/welcome.html).

## Design principles

- **Protect the advertising
 pipeline:** Control access to and from your DSP
 (demand-side platform) using identity management and network
 access control. Protect data in transit using encryption.
