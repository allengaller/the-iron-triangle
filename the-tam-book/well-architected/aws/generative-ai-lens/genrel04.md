# Prompt management

Prompts differentiate model performance from one workload to
 another. Curating prompts can be a time-consuming process, and it
 is important to have a reliable store for prompts. Foundation
 model performance differs from version to version, as does the
 impact of inference hyperparameters on model performance.
 Standardize and version these variations to create a more reliable
 experience.
