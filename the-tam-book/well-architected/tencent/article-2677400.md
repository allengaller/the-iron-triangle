### 第四章：方法论说明

• **评估体系**：云顾问卓越指数评估采用**加权平均计算方式**。

```
• **层级划分**：资源层（权重40%）、架构层（权重40%）、应用层（权重20%）。
```

```
• **计分逻辑**：各层级得分 = 满足的评估项总分 / 该层级所有评估项总分（标准化为0-100分）。
```

```
• **公式**：卓越指数 = (资源层得分 × 40% + 架构层得分 × 40% + 应用层得分 × 20%) / (40% + 40% + 20%)。
```

```
• **示例**：若资源层60分、架构层85分、应用层70分，则卓越指数为 **72分**。
```
