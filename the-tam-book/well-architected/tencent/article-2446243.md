## 一、概述

### 1.1云顾问卓越架构框架简介

随着云计算技术的快速发展，企业上云已成为推动业务创新和发展的重要手段。在这个过程中，构建一个高效、稳定、安全的云上架构成为企业面临的关键挑战。腾讯云卓越架构框架（Tencent Cloud Well-Architected Framework）旨在为企业提供一套全面的设计理念，帮助客户解决业务上云后的关键问题。

腾讯云解决方案架构师凭多年积累的垂直业务与用例经验，为众多客户提供腾讯云架构设计与审查服务。藉由深厚的行业经验和技术储备，提供多元化的业务场景和架构解决方案。未来也将持续发展，通过不断与客户协作，将实践经验融入卓越架构框架定义的改进过程。白皮书面向CTO、架构师、开发人员及运维成员等。通过阅读本白皮书，您将了解云架构设计与运维在腾讯云的实践和策略。

云顾问作为一款腾讯云提供的卓越架构评估及治理工具，能够帮助客户发现当前架构设计与最佳状态之间的差距，并给出改善建议。此外，在架构设计和实施阶段，云顾问能够提供专业的技术支持，以确保客户在架构演进过程中得到全方位的指导和协助。腾讯云卓越架构框架，基于三层模型、六大支柱，为客户提供一流的云服务规范和行业解决方案，实现云上业务的稳健发展。

### 1.2云顾问三层模型应用

- **资源层**

展示计算、存储和网络等实例资源，帮助IT 运维、网络管理员等管理底层资源，例如资源自动拓展、备份、故障恢复和安全保障等工作。资源层在整个卓越架构框架中确保硬件资源的稳定性和高效性，为业务连续性和数据安全提供坚实基础。

- **架构层**

主要描述应用服务的功能组件，面向产品、架构师和开发人员，旨在构建独立的功能单元，从而实现组件的高度复用、拓展和维护。在架构层，组件设计和实现遵循模块化的原则，保证架构的稳定和可扩展性。架构层在整个卓越架构框架中为灵活、高效、可维护的应用程序提供坚实基础，从而支持软件的持续发展和敏捷迭代。

- **应用层**

位于卓越架构框架顶层，主要关注一个完整的应用程序服务。面向所有人员，包括客户高层、业务方和产品经理等。在应用层中，需求与架构设计紧密相连，以实现有效的业务解决方案及满足客户需求。应用层专注于应用程序的功能、稳定性、性能优化等方面，强调对业务需求和目标的实现。在整个卓越架构框架中，应用层反映了资源层和架构层提供基础的投入如何融合实际应用，以满足客户和市场需求。

### 1.3云顾问六大支柱理念

- **安全**

致力于保护云系统、资产和数据的机密性、完整性、可用性，确保数据合法、合规的使用，并维护用户隐私。该支柱提供全面的网络、身份、主机和数据安全策略与实施，持续进行威胁检测与即时响应，实现风险的有效评估与降低。

- **可靠**

通过降低单个组件故障对业务的影响以增强系统稳定性。侧重于设计高可用、具备容灾能力的业务系统，对应用变更流程、部署架构等进行规范审定，并提高系统在异常情境下的服务稳定性。有效增强故障恢复速度与系统适应性。

- **性能**

专注于设计和优化高性能架构，提供技术方法和手段进行软件性能工程和性能调整。实现高效利用计算资源、自动触发弹性伸缩、应对流量高峰、定位性能瓶颈并建立性能基线。面对需求变更与技术演进，性能支柱保持系统效率水平。

- **成本**

关注高效利用云服务，避免不必要的开支和资源浪费。通过技术手段帮助企业理解云资源成本分布，平衡业务目标与云成本，提升云环境和业务需求的契合度。持续优化，旨在降低云服务开支，提高运营效率，实现最佳的成本效益。

- **卓越运营**

致力于构建和运维高效软件，并持续提供卓越客户体验。包括组织团队、优化工作负载设计、扩展大规模运营，并持续改进。构建和利用与应用研发、运行相关的工具和系统，同时定义周全的响应流程和日常操作，引导企业构建独特的运营模型，从而有效支持业务价值的持续提升。

- **可持续**

关注可持续发展。通过降低能源消耗、减少碳排放、灵活定价、关注社会责任、引入创新技术和保障服务稳定性等措施，可持续支柱致力于在促进技术进步的同时，降低环境影响，为未来创造积极价值。

## 二、绘制架构图

通过将 IT 系统架构可视化，能够提升团队成员对系统结构的直观理解，从而显著提高沟通效率。这种可视化方法不仅有助于促进跨职能团队之间的协同工作，还为卓越架构框架的持续优化和演进奠定了坚实基础。

1. 对于企业管理者，清晰的架构视图有助于快速获取信息以及做出明智的战略决策；

2. 对于运维团队，它提供了系统监控和维护的直观参考，如帮助故障定位与诊断、性能优化以及容量规划；

3. 对于业务团队，它则有助于更好地理解和满足业务需求，如它可以作为业务团队与运维团队之间的共同语言，提高协作效率，保障业务需求按时上线。

梳理并绘制架构图对于提升组织的整体运营效率和创新能力具有深远的正向意义。云顾问现推出三种定制化的架构图绘制方法，旨在适配多样化的应用场景，以满足不同用户的专业需求。

1. 腾讯云产品：包含云服务 CVM、轻量应用服务器 Lighthouse、容器服务 TKE、云数据库 MySQL 在内的主流 80+ 款云产品，覆盖系统的接入层至存储层。

- **资源绑定**

1. 资源选择：手动勾选需要关联的实例以完成静态绑定，当资源变化时需要手动进行维护。

2. 关键字动态绑定：根据关键字动态匹配实例 ID 或实例名称，当资源变化时会自动更新实例列表。

3. 标签动态绑定：根据标签条件动态匹配实例，当资源变化时会自动更新实例列表。

2. 对于已有架构图的风险项，您可以一键直接进入架构图云巡检应用查看并治理风险，简化了操作流程，提高了治理效率。

3. 对于没有架构图的风险项，您可以按地域一键自动生成架构图，并在云巡检应用中查看和治理风险。

## 三、卓越指数评估

### 3.1评估说明

当用户访问架构图时，默认将进入卓越架构评估模块。该模块采用先进的评估体系，对架构进行全面而深入的分析，涵盖资源层、架构层、应用层三个核心层级，以及安全、可靠性、性能、成本、卓越运营和可持续性这六个卓越架构框架关键维度。

通过这一立体的评估流程，系统能够精准计算出架构的卓越指数，并提供针对性的治理建议。用户可根据每条治理建议的指引，轻松点击跳转至相应的应用界面，执行云上治理操作，从而不断优化并提高架构的卓越指数。

![](https://developer.qcloudimg.com/http-save/yehe-9555918/f91ede60da8254630abd0d94e7152fd9.png)

### 3.2评估规则

云顾问卓越指数采用加权平均的计算方式，综合考虑了多个评估维度，以确保指数的全面性和准确性。具体的计算逻辑如下所示：

最终计算卓越指数时，将对各个层级得分进行加权平均计算。其中资源层(I)权重Wi为 40%，架构层(F)权重Wf 为 40%，应用层(A)权重Wa为 20%。因此卓越指数计算公式为：

![](https://developer.qcloudimg.com/http-save/yehe-9555918/79f6059815a099711aa9fb527a37f986.png)

示例：

在资源层的 30 个评估项中满足了 15 个，标准化分数为 60 分；

在架构层的 25 个评估项中满足了 20 个，标准化分数为 85 分；

在应用层的 15 个评估项中满足了 10 个，标准化分数为 70 分；

则架构卓越指数 =

((60 * 40%)+(85 * 40%)+(70 * 20%))/(40% + 40% + 20%)=72

## 四、云顾问多应用治理

### 4.1云顾问-云巡检

云巡检持续为客户提供安全、性能、成本、可靠、服务限制五大类型的风险巡检能力，在云架构一个平台的基础上，全面升级为可视化云上隐患风险评估治理垂直应用，帮助客户及时发现、高效治理云上资源与架构隐患，提升系统安全性和业务连续性。

![](https://developer.qcloudimg.com/http-save/yehe-9555918/215f859c1c9fbd47ee16749c0a480fee.png)

- **巡检策略**

云巡检当前已覆盖超过60款腾讯云头部自研产品超过310项的巡检策略，分别从安全、性能、成本、可靠、服务限制五个角度为客户云上架构与资源提供自动化巡检能力。持续基于腾讯云卓越架构治理实践与海量运维服务能力经验，以各个云产品特性能力和客户应用场景为依托，不断丰富巡检策略定义和优化指引。

![](https://developer.qcloudimg.com/http-save/yehe-9555918/5aa8dfb6f68e067a67b0b66cd195fe8d.png)

- **巡检垂直应用**

**1.垂直应用**

基于“一个平台，N个应用”的产品设计理念，结合云架构绑定云上资源的能力，云巡检作为首个垂直应用升级集成到云架构中，为客户提供架构可视化的风险巡检和治理能力。客户可以在已绘制并绑定资源的架构图实时发起巡检任务，聚焦发现架构图所绑定的资源及其相关的隐患风险和架构风险。

![](https://developer.qcloudimg.com/http-save/yehe-9555918/7821d3a22bf81ae48a05f7d8f5a40e6f.png)

**2.风险详情**

在架构图中可以点按每个图元节点查看详细风险项，更聚焦于各个架构节点和对应的高/中风险。可进一步进入风险项详情，评估受风险项影响资源并评估是否需要进行针对性治理或操作忽略，以及后续相关的治理安排。

风险详情中详细展示各风险项定义、判定条件、和相关的优化建议，并详细列出命中风险判定条件的各个资源实例及其关键信息。

![](https://developer.qcloudimg.com/http-save/yehe-9555918/6968d19929027b3e146f334774ccfa24.png)

**3.巡检设置**

对于架构图中未绑定资源的节点、或者未绘制到架构图中的产品，相关巡检规则将不会生效，仅聚焦当前架构已有绑定资源的对应规则。同时阈值配置类的巡检规则支持客户按业务特性自定义，以贴近实际业务巡检需求。

- **巡检报告**

作为云顾问数字资产的重要组成部分，云巡检生成的巡检报告为客户提供基于架构和资源的详细巡检风险统计、趋势分析、治理指引和详情列表。方便客户及时获取清晰的巡检结果数据进行风险治理安排，并支持在线查阅、在主/子账号范围内分享、归档到云顾问数字资产、下载历史归档报告等多种报告访问方式。

### 4.2云顾问-容量监测

容量管理在 IT 系统和云计算环境中具有重要意义。容量监测应用通过监测和预测系统资源的使用情况，确保系统在高负载情况下仍能正常运行，避免因资源不足导致的系统崩溃或性能下降。同时，用户通过对资源使用情况的持续监控和分析，可以帮助组织更有效地分配和利用资源，避免资源浪费，提高整体资源利用率。

- **容量监测与卓越架构**

### 4.4云顾问-预案管理

预案管理在确保信息系统稳定运行和应对突发事件方面具有不可替代的作用。预案管理通过预先识别潜在的风险和威胁，制定相应的应对措施，有效降低突发事件对系统运行的影响，确保业务连续性和信息安全性。在突发事件发生时，预案管理能够提供明确的操作指南和流程，帮助组织快速响应，减少损失，恢复系统正常运行。

- **预案管理与卓越架构**

预案管理应用在设计阶段，充分汲取了卓越架构框架六大支柱中可靠性和卓越运营的核心理念，旨在通过精细化策略编排和高效策略执行提升故障恢复的恢复时间目标（RTO）和恢复点目标（RPO），从而最大限度地保障业务的连续性和稳定性，助力企业构建卓越架构。

1. 提升系统韧性：通过制定全面的预案，组织能够增强系统的韧性，即使在极端情况下也能保持系统的稳定性和可用性，确保关键业务的连续性；

2. 减少故障影响：预案管理通过预先规划的应对措施，能够在故障发生时迅速采取措施，减少故障对系统的影响，缩短恢复时间。

3. 优化运营流程：预案管理不仅关注突发事件，还涉及日常运营的优化。通过预案的制定和执行，组织能够不断优化运营流程，提升运营效率和质量；

4. 增强决策支持：预案管理为管理层提供了详细的应对策略和操作指南，增强了决策支持能力，帮助组织在面对突发事件时做出更为明智和迅速的决策。

- **指令库**

预案管理提供了全面而丰富的指令库，旨在通过细粒度的操作来实现对资源的精确控制。在预案管理中，指令被定义为对资源产生特定影响的原子动作，是构成预案的基本组成单元。指令库现涵盖三种类型的指令：文本指令、Shell 脚本指令以及云 API 指令。

1. 文本指令：主要用于提供非腾讯云环境的操作指南，或用于指导组织内部成员的行为；

2. Shell 脚本指令：通过TAT自动化助手在服务器端执行预定义的Shell脚本，从而高效地完成复杂的运维任务；

3. 云 API 指令：依托于腾讯云各云产品所提供的API接口，从而实现对云资源的快速管理和自动化控制。

![](https://developer.qcloudimg.com/http-save/yehe-9555918/77dd565fce3be2789996e55b63308d86.png)

指令库不仅集成了腾讯云官方提供的各类指令，还支持用户根据自身需求创建个性化的自定义指令。借助这些多样化的指令，用户能够便捷地执行应用的部署、资源的创建与销毁等关键云上操作，从而实现对云环境的高效运维。

- **预案编排**

预案管理提供基于架构图的可视化预案编排功能，旨在通过直观的图形界面，使用户能够高效地进行预案的设计与编排。在预案编排过程中，用户可以轻松地添加、修改和删除指令，并完成与架构图上节点的关联，实现预案与实际系统架构的紧密结合。

![](https://developer.qcloudimg.com/http-save/yehe-9555918/31af12378ceec61c903b46679001a69d.png)

在预案编排时，为了确保预案的有效执行和责任明确，我们在设计中引入了“负责人”和“处理人”的概念。每个预案都将指定一名明确的负责人，负责预案的整体规划、审核和执行监督。同时，预案中的每个指令也将分配具体的处理人，负责指令的具体执行和结果反馈。这种设计从管理的角度出发，旨在提高预案执行的透明度和可控性。通过明确的责任分工，我们的预案管理工具能够确保在突发事件发生时，各环节人员能够迅速响应，按照既定预案进行操作，从而最大程度地保障系统的稳定性和业务的连续性。

- **预案执行**

在预案执行阶段，我们提供了步进式操作界面，旨在引导用户按照预案的既定步骤，准确且有序地对系统进行恢复。此界面设计充分考虑了用户的操作习惯，确保每一步操作都清晰明了，降低误操作风险。此外，我们还实现了架构图与操作界面的可视化联动，实时显示每个步骤处理对象在架构图中的具体位置，帮助用户更直观地理解系统状态和操作影响。

![](https://developer.qcloudimg.com/http-save/yehe-9555918/acdce4f3abe94dbcf7e36801a1e5fa91.png)

为确保预案执行过程的可追溯性，我们对整个执行过程进行详尽的日志记录。在预案执行结束后，我们提供一个总结输入页面，引导用户对执行过程进行复盘分析。通过分析预案执行后的反馈和总结，企业能够及时调整预案策略，优化资源配置，从而进一步提高恢复时间目标（RTO）和恢复点目标（RPO），确保业务的连续性和稳定性。

2. 架构演进过程梳理：数字资产能够清晰地展示架构的演进过程，帮助运维团队理解架构的变化趋势，从而更好地保证业务运行。

3. 可视化呈现运维工作价值：通过可视化的方式，数字资产能够直观地展示运维工作的成果和价值，帮助运维团队在公司内部提升业务稳定性。
