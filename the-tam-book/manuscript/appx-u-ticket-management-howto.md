# 附录 U+　工单落地执行

> 本附录把[附录 U](appx-u-ticket-management-standard.md)的标准条文转成落地动作。条文定义不在本附录重复。五个动作：受理与定级、记录与更新、升级与协同。关闭与重开、抽检与度量。分类、时限与红线一律以附录 U 为准。

## U+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 分类口径 | TK-F/Q/R/C 到团队 | 先做宣贯 |
| 时限基线 | 对齐合同 SLA 与 B.3.4 | 先校准 |
| 抽检机制 | 责任人与节奏明确 | 先排抽检 |
| 系统字段 | 七要素可填可查 | 先改表单 |

完成标志有五项：定级不挤通道、记录七要素齐、静默零违规。关闭有确认、抽检按周走。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 定级不挤通道 | 非故障不占 P1/P2 | 工单台账 |
| 记录七要素齐 | 一句话工单为零 | 抽检记录 |
| 静默零违规 | 更新频率达标 | 工单时间线 |
| 关闭有确认 | 确认率 ≥ 95% | 关闭记录 |
| 抽检按周走 | 比例 ≥ 10% | 抽检台账 |

## U+.2 操作一：受理与定级

### 操作步骤

1. 受理先分类：故障 TK-F、咨询 TK-Q、请求 TK-R、变更协同 TK-C。
2. 定级沿用 P1–P4（第 19 章）。仅 TK-F 可定 P1/P2。
3. 定级以业务影响为准。不以客户语气为准。
4. 情绪激动但影响有限的单，按实定级、按情沟通。
5. 重保窗口期按模板 05 提级执行时限。

### 预期结果

分类准确。定级有据。通道不挤占。

### 常见错误

- 咨询单挂 P2。真故障没通道。
- 客户嗓门大就升单。定级失真。

## U+.3 操作二：记录与更新

### 操作步骤

1. 建单即写七要素（U.6）。缺一项即不合格。
2. 现象记客户原话加技术描述。报错与复现路径齐。
3. 排查动作逐条记录。含无效动作。
4. 按承诺频率更新。没进展也报"暂无进展、正在做什么"。
5. 首响必须含初步判断或下一步。"转交中"不算首响。

### 预期结果

七要素齐。更新零静默。首响实打实。

### 常见错误

- 一句话工单。结论无处可查。
- 挂单三天不动。客户不知道谁在管。

## U+.4 操作三：升级与协同

### 操作步骤

1. 满足任一升级条件即转事件（U.7.2）。原单留作证据链。
2. 同一症状 24 小时内 ≥ 3 单即按模式性故障处理。
3. 反复出现的模式转风险登记册（模板 09）。
4. 重大工单客户沟通由 TAM 统一口径。多渠道不打架。
5. 内部工单同样按七要素。OLA 承诺匹配 SLA。

### 预期结果

升级不漏。模式入册。口径统一。

### 常见错误

- 该转事件不转。故障淹没在工单堆里。
- 内部承诺小于对客承诺。SLA 裸奔。

## U+.5 操作四：关闭与重开

### 操作步骤

1. 关闭三条件同时满足：方案交付验证、结论根因已填、客户确认。
2. P1/P2 禁止无客户确认关闭。静默确认也不适用。
3. 静默确认期建议 P3/P4 为 3 个工作日。期内有异议即撤关闭。
4. 7 个自然日内同症状复发，重开原单并自动升一级。
5. 重开必答：上次结论为什么错或不彻底。

### 预期结果

关闭零违规。重开有检讨。复发升级。

### 常见错误

- 冲关闭率草草关单。一周后复发。
- 复发开新单。历史结论丢失。

## U+.6 操作五：抽检与度量

### 操作步骤

1. 每周抽检 ≥ 10%。P1/P2 工单 100% 复检。
2. 四维评分各 25 分：完整性、准确性、及时性、闭环性。
3. 不合格单限期整改。同类问题重复升级主管议题。
4. 指标看齐第 26 章口径。MTTR 同时看均值与 P90。
5. 不以关闭率排名考核一线。指标只改进服务。

### 预期结果

抽检按周走。评分有整改。指标不异化。

### 常见错误

- 抽检走过场。评分全优秀。
- 关闭率排名压一线。重开率悄悄涨。

## U+.7 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 分类定级 | 仅 TK-F 占 P1/P2 | 核对工单台账 |
| 七要素 | 缺一即不合格 | 核对抽检结果 |
| 静默规则 | 更新频率达标 | 核对时间线 |
| 升级转事件 | 条件命中即转 | 核对事件关联 |
| 关闭确认 | P1/P2 全确认关闭 | 核对关闭记录 |
| 重开检讨 | 同症状重开有结论 | 核对重开工单 |
| 抽检 | 比例 ≥ 10%、P1/P2 全复检 | 核对抽检台账 |
| 指标健康 | 一次解决率 ≥ 85% | 核对度量报表 |

关键项是七要素、静默规则和关闭确认。任一关键项未通过，工单管理不得视为合格。

## U+.8 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 一句话工单 | 表单没约束 | 七要素设为必填 |
| 超期静默 | 无人盯频率 | 提醒加主管抽查 |
| 关闭率虚高 | 指标压一线 | 停排名、看重开率 |
| 重开率升高 | 草草关单 | P1/P2 全复检 |
| 事件漏转 | 升级条件不清 | 条件贴工位 |
| 内外承诺错位 | OLA 没拉通 | 先对齐 OLA |

反复出现的问题进入复盘流程（[附录 R](appx-r-problem-retrospective-standard.md)）。

## U+.9 执行检查清单

- [ ] 四分类口径宣贯到团队
- [ ] 仅 TK-F 可定 P1/P2
- [ ] 七要素建单即齐
- [ ] 首响含初步判断或下一步
- [ ] 更新频率零静默
- [ ] 升级条件命中即转事件
- [ ] P1/P2 全部客户确认关闭
- [ ] 同症状重开原单并升一级
- [ ] 抽检 ≥ 10%、四维评分
- [ ] 指标不排名、不粉饰

---

**本附录要点回顾**

1. 分类四型，仅故障占 P1/P2。定级看影响不看语气。
2. 七要素缺一不合格。首响要实，更新要勤。
3. 该转事件就转，模式入风险册。口径统一归 TAM。
4. 关闭三条件，P1/P2 必须客户确认。重开检讨结论。
5. 抽检按周、评分四维。指标改进服务，不粉饰服务。
