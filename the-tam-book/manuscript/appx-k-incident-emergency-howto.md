# 附录 K+　应急与演练落地执行

> 本附录把[附录 K](appx-k-incident-emergency-drill-standard.md)的标准条文转成落地动作。条文定义不在本附录重复。五个动作：预案落地、演练组织、评估执行。事后闭环、红线处置。时限与锚点一律以附录 K 为准。

## K+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 预案 | TAM 侧应急预案成文 | 先写预案 |
| 作战室 | 拉通方式与角色清单就绪 | 先定角色 |
| 模板 | 模板 05/06/07 可用 | 先补模板 |
| 认证 | 值班与应急培训就绪 | 回附录 J |

完成标志有五项：预案可执行、演练按频次、评估有判定。闭环零缺口、红线有签收。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 预案可执行 | 黄金 30 分钟序列成卡 | 预案与动作卡 |
| 演练按频次 | 三级演练按期 | 演练计划 |
| 评估有判定 | 五项评分留痕 | 评估表 |
| 闭环零缺口 | RCA 时限与改进入册 | 闭环台账 |
| 红线有签收 | 四条红线到人 | 签收表 |

## K+.2 操作一：预案落地

### 操作步骤

1. 黄金 30 分钟动作卡做成一页。贴作战室与值班台。
2. 角色清单四席：指挥、处置、记录、通报。人名到岗，替补明确。
3. 通报脚本按模板 06 预填三版：首次通报、进展通报、恢复通报。
4. 升级矩阵与值班时限对表（附录 I.6）。两套数字不打架。

### 预期结果

动作卡一页化。四席到人。脚本三版预填。时限对齐。

### 常见错误

- 预案长篇没人读。动作卡才是肌肉记忆的载体。
- 角色挂名不到岗。演练当天才找人。

## K+.3 操作二：演练组织

### 操作步骤

1. 年度演练计划按客户等级排期（附录 K.6.1 频次表）。
2. 重保前专项桌面推演必做（模板 05）。针对当次场景出脚本。
3. 脚本保密。参演人只知道窗口，不知道故障。
4. 实战演练走客户联合审批。未审批不动生产。

### 预期结果

年度计划排期到月。脚本零泄露。审批留痕。

### 常见错误

- 演练扎堆年底。平时没练，年底赶场。
- 脚本提前发。演练变汇报演出。

## K+.4 操作三：演练评估执行

### 操作步骤

1. 五项评分当场做（附录 K.6.2 锚点）。评委独立打分。
2. 合格判定硬执行。不合格视同隐患，30 天内补演。
3. 评估表归档。改进项直入风险登记册（模板 09）。
4. 透题与造假按红线处置（K+.5）。

### 预期结果

评分留痕。判定硬气。改进入册。

### 常见错误

- 评分放水。人人 4 分，评估失真。
- 补演拖过 30 天。隐患躺成常态。

## K+.5 操作四：事后闭环执行

### 操作步骤

1. RCA 时限卡死（附录 K.7）。48 小时初步、5 日正式。
2. 改进项全部入册：责任人、期限、验证方式。
3. 信任重建沟通 P1 后两周内做。TAM 主导，讲清三件事。
4. 案例一月内脱敏进教材（附录 J.8）。

### 预期结果

RCA 按期。改进有主。复盘沟通做了。案例入库。

### 常见错误

- RCA 拖期。证据凉了写不出。
- 只整改不验证。下一次原样再犯。

## K+.6 操作五：红线处置

### 操作步骤

1. 四条红线（附录 K.8）签收到人。年度复训一次。
2. 触线处置三步：事实核实、当期评估否决、追责与再培训。
3. 处置记录进评估档案（附录 G）。不和稀泥。

### 预期结果

签收全覆盖。触线零姑息。记录进档。

## K+.7 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 动作卡 | 黄金 30 分钟一页化 | 核对预案 |
| 角色四席 | 人名到岗有替补 | 核对角色清单 |
| 脚本三版 | 预填就绪 | 核对模板 06 |
| 演练计划 | 三级按频次排期 | 核对年度计划 |
| 评估判定 | 五项评分留痕 | 核对评估表 |
| 补演闭环 | 不合格 30 天内补演 | 核对台账 |
| RCA 时限 | 48h/5 日达标 | 核对复盘记录 |
| 红线签收 | 到人、年训做 | 核对签收表 |

关键项是演练计划、评估判定和红线签收。任一关键项未通过，应急演练落地不得视为合格。

## K+.8 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 预案没人用 | 无动作卡 | 做一页动作卡 |
| 演练变表演 | 脚本泄露 | 脚本保密重跑 |
| 评分虚高 | 评委放水 | 独立打分复核 |
| 补演拖延 | 无台账跟踪 | 30 天硬时限 |
| RCA 超期 | 证据散失 | 时限卡死早动手 |
| 原样再犯 | 改进未验证 | 演练抽查改进项 |

反复出现的问题进入复盘流程（[附录 R](appx-r-problem-retrospective-standard.md)）。

---

**本附录要点回顾**

1. 预案落在一页动作卡。角色四席到人，脚本三版预填。
2. 演练排期到月，脚本保密。实战演练先审批后动生产。
3. 评分独立、判定硬气。不合格 30 天补演，隐患不躺。
4. RCA 时限卡死，改进入册，案例一月进教材。红线触线零姑息。
