# 附录 S+　加班调休落地执行

> 本附录把[附录 S](appx-s-overtime-compoff-standard.md)的标准条文转成落地动作。条文定义不在本附录重复。五个动作：加班认定与补录、审批与上限管控、调休排期与兑现。疲劳红线执行、度量与复盘触发。折算比率与红线一律以附录 S 为准。

## S+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 制度对接 | 与所在地法规、公司 HR 制度对齐 | 冲突处从法规 |
| 系统就绪 | 加班与排班系统可留痕 | 先上系统 |
| 主管培训 | 上限、补录、兑现规则到主管 | 先培训 |
| 预算口径 | 重保人力消耗预算可编 | 先立口径 |

完成标志有五项：认定全走系统、补录不逾期、上限硬执行。调休按期兑现、疲劳红线零破。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 认定全走系统 | OT1/OT2 记录可核 | 系统记录 |
| 补录不逾期 | 24 小时内补录 | 补录台账 |
| 上限硬执行 | 人均月 ≤ 36 小时 | 加班月报 |
| 调休按期兑现 | 季度兑现率 ≥ 90% | 兑现台账 |
| 疲劳红线零破 | 强制休息执行率 100% | 排班记录 |

## S+.2 操作一：加班认定与补录

### 操作步骤

1. OT1 随计划自动认定。重保、上线、变更、演练照单归类。
2. OT2 以系统记录为准：告警时间线、工单、作战室签到。
3. 起止口径统一：确认介入到移交或降级。陪绑留守不计。
4. 事件关闭后 24 小时内补录。逾期由主管代录并说明。
5. 非工作时段的培训、例会按 OT1 认定。不让员工自费时间。

### 预期结果

认定全走系统。补录零逾期。起止口径统一。

### 常见错误

- 加班靠手填。口径各算各的。
- 漏录追员工。责任其实在主管。

## S+.3 操作二：审批与上限管控

### 操作步骤

1. OT1 提前 ≥ 3 个工作日报批。写明时段、人数、轮换方案。
2. 临时追加升一级审批。主管+1 级批准。
3. 月度盯总量：人均 ≤ 36 小时。单人连续跨夜 ≤ 2 晚。
4. 触顶判定：连续 2 个月超八成成员达上限七成即触发组织复盘。
5. 组织复盘走三条路：增编、调值班模式、与客户重谈服务窗口。

### 预期结果

审批留痕。总量不超限。触顶触发复盘。

### 常见错误

- 上限当配额用。顶格排班成常态。
- 触顶发表扬。把失当当勤奋。

## S+.4 操作三：调休排期与兑现

### 操作步骤

1. 按 S.6 比率折算：工作日 1:1、休息日 1:1.5、节假日 1:2。
2. 跨夜值守另计 0.5 天。折算随认定自动入账。
3. 有效期 6 个月。到期前 1 个月系统提醒本人与主管。
4. 到期未休：次月强制排休或折现。不得无声清零。
5. 离职一次性结清。不接受"项目忙"式放弃。

### 预期结果

折算无争议。到期零清零。离职结清。

### 常见错误

- 调休变纸面权益。兑现全靠催。
- 到期清零不提醒。权益无声蒸发。

## S+.5 操作四：疲劳红线执行

### 操作步骤

1. 跨夜值守后强制休息 ≥ 12 小时。不抵扣调休余额。
2. 强制休息时段禁止排工。排班系统硬拦截。
3. 双高识别：值班 ≥ 8 天且加班 ≥ 30 小时即触发。
4. 双高人员次月退出轮换池至少一个周期。
5. 驻场陪同超时段转 OT1/OT2 认定。排班权不交客户。

### 预期结果

强制休息 100% 执行。双高零漏检。排班权在服务组织。

### 常见错误

- 工单挤占强制休息。红线名存实亡。
- 客户单方加陪同。排班权旁落客户。

## S+.6 操作五：度量与复盘触发

### 操作步骤

1. 五指标月度取数（S.9）：人均时长、OT2 占比、兑现率、执行率、OT3 检出。
2. 数据只取系统记录。手工填报不进指标。
3. OT2 占比超五成：联动风险扫描（第 14 章）。
4. 季度兑现率低于 80%：按红线追责到主管。
5. 指标只改进排班与配置。不得压低申报。

### 预期结果

五指标月月有数。红线触发有处置。指标不异化。

### 常见错误

- 指标反向考核个人。催生少申报。
- 数据两套账。系统记录与手填打架。

## S+.7 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 认定留痕 | OT1/OT2 全走系统 | 核对系统记录 |
| 补录时限 | 24 小时内 | 核对补录台账 |
| 总量上限 | 人均月 ≤ 36 小时 | 核对加班月报 |
| 触顶复盘 | 连续 2 个月触顶即复盘 | 核对复盘记录 |
| 调休兑现 | 季度 ≥ 90% | 核对兑现台账 |
| 强制休息 | 执行率 100% | 核对排班记录 |
| 双高处置 | 退出轮换池 | 核对轮换表 |
| 隐性加班 | 检出 0 起 | 核对抽查记录 |

关键项是认定留痕、调休兑现和强制休息。任一关键项未通过，加班管理不得视为合格。

## S+.8 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 加班对不上账 | 手填口径乱 | 认定全走系统 |
| 补录逾期 | 无人盯台账 | 主管代录并说明 |
| 长期顶格 | 上限当配额 | 触顶触发组织复盘 |
| 调休总清零 | 无提醒机制 | 到期前 1 个月双提醒 |
| 强制休息缩水 | 排班不拦截 | 系统硬拦截 |
| 隐性加班冒头 | 秒回文化 | 抽查加主管问责 |

反复出现的问题进入复盘流程（[附录 R](appx-r-problem-retrospective-standard.md)）。

## S+.9 执行检查清单

- [ ] 制度与法规、HR 制度对齐
- [ ] OT1/OT2 认定全走系统
- [ ] 补录 24 小时内、逾期主管代录
- [ ] OT1 提前 3 个工作日报批
- [ ] 人均月 ≤ 36 小时、连续跨夜 ≤ 2 晚
- [ ] 触顶判定与组织复盘触发
- [ ] 调休折算入账、到期双提醒
- [ ] 强制休息 ≥ 12 小时、不抵扣
- [ ] 双高退出轮换池
- [ ] 五指标月度取数、只取系统记录

---

**本附录要点回顾**

1. 认定全走系统。漏录责任在主管，不在员工。
2. 上限是熔断器。触顶触发组织复盘，不是表扬。
3. 调休刚性兑现。到期强制排休或折现，不得清零。
4. 疲劳红线硬执行。强制休息不抵扣，双高退出轮换池。
5. 指标只改进排班。不得反向压低申报。
