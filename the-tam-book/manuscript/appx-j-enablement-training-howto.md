# 附录 J+　培训落地执行

> 本附录把[附录 J](appx-j-enablement-training-standard.md)的标准条文转成落地动作。条文定义不在本附录重复。五个动作：排课、带教、认证执行、度量执行、案例入库。课时与占比一律以附录 J 为准。

## J+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 分级判定 | 学员 T1/T2/T3 定级 | 回附录 J.4 |
| 导师 | T1 学员配 T3 导师 | 先配导师 |
| 仿真环境 | 金融级模块有仿真核心 | 先搭沙箱 |
| 教材 | 六维课程包就绪 | 先建课程包 |

完成标志有五项：排课有实操、带教有记录、认证三段走。度量五指标、案例月月入。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 排课有实操 | 实操占比 ≥ 50% | 课程表 |
| 带教有记录 | 反向跟岗 ≥ 2 次 | 带教台账 |
| 认证三段走 | 笔试、答辩、实战评估齐 | 认证档案 |
| 度量五指标 | 月月可看 | 度量看板 |
| 案例月月入 | 复盘一月内转化 | 案例库 |

## J+.2 操作一：排课

### 操作步骤

1. 按 T 级排课表。T1 九十天倒排，T2 年度循环，T3 按晋级规划。
2. 每模块核实操占比（附录 J.5 建议值）。占比不足的模块重排。
3. 仿真环境先行。金融级模块没仿真核心不开课。
4. 重保窗口期避让。训练不与保障冲突。

### 预期结果

课表三要素齐：模块、实操占比、环境。窗口避让。

### 常见错误

- 排课全是讲座。实操占比纸面达标。
- 仿真缺位。生产环境练兵，红线破口。

## J+.3 操作二：带教

### 操作步骤

1. 导师制落地：T1 配 T3 导师。带教计划写明阶段目标。
2. 跟岗与反向跟岗交替。先跟岗观摩，再反向跟岗实战。
3. 带教记录月度归档。带教质量进导师评估（附录 J.7）。
4. 带教时间入工时。不计入“帮忙”。

### 预期结果

师徒对子齐。反向跟岗 ≥ 2 次。记录归档。

### 常见错误

- 师徒制黑箱。带教全凭师傅心情。
- 带教不算工作量。没人愿意带。

## J+.4 操作三：认证执行

### 操作步骤

1. 三段式走全流程：笔试、实操答辩、实战评估（附录 J.6）。
2. 实操答辩按行为锚点评分。评委双人，分差超一档复议。
3. 实战评估九十天内出。反向跟岗记录附后。
4. 认证结果挂钩客户分配。未认证不上岗，不破例。

### 预期结果

三段齐。评分有锚点。结果已挂钩。

### 常见错误

- 笔试定乾坤。实操答辩走过场。
- 结果不挂钩。认证成走过场。

## J+.5 操作四：度量执行

### 操作步骤

1. 五指标入看板（附录 J.7）。月度更新。
2. 未达锚点的指标进改进。90 天上岗率是硬项。
3. 认证后事故逐案复盘。动作不规范的回教材。
4. 度量取系统记录。手工填报不采信。

### 预期结果

五指标月月可看。未达有改进。事故回教材。

### 常见错误

- 指标报喜不报忧。培训失效无人知。
- 事故不回教材。同样的坑再掉。

## J+.6 操作五：案例入库

### 操作步骤

1. P1/P2 复盘完成后一月内转教学案例。脱敏照 TAM 附录 E 口径。
2. 案例入库三要素：场景、动作、教训。
3. 教材季度迭代。真实案例进课堂滞后 ≤ 一个季度。
4. 案例库共享。个人收藏不算资产。

### 预期结果

案例月月入。教材季季新。库是复利。

### 常见错误

- 复盘不转化。经验留在会议室。
- 案例不脱敏。教学变泄密。

## J+.7 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 课表实操占比 | 各模块达标 | 核对课程表 |
| 仿真环境 | 金融级模块就绪 | 核对环境清单 |
| 师徒对子 | T1 全覆盖 | 核对带教台账 |
| 反向跟岗 | ≥ 2 次 | 核对记录 |
| 三段认证 | 全流程走完 | 核对认证档案 |
| 五指标 | 系统取数月月看 | 核对看板 |
| 案例入库 | 复盘一月内转化 | 核对案例库 |

关键项是课表实操占比、三段认证和案例入库。任一关键项未通过，培训落地不得视为合格。

## J+.8 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 培训变讲座 | 实操占比虚 | 按模块重排课 |
| 生产练兵 | 仿真缺位 | 先搭沙箱再开课 |
| 师徒黑箱 | 无带教计划 | 计划写阶段目标 |
| 认证走过场 | 笔试定乾坤 | 三段全流程硬执行 |
| 上岗率低 | 训练脱离实战 | 加反向跟岗与案例课 |
| 经验流失 | 复盘不转化 | 一月转化硬时限 |

反复出现的问题进入复盘流程（[附录 R](appx-r-problem-retrospective-standard.md)）。

## J+.9 执行检查清单

- [ ] 课表按 T 级排定，实操占比达标
- [ ] 金融级模块仿真环境就绪
- [ ] T1 学员全部配 T3 导师
- [ ] 带教计划与月度记录归档
- [ ] 反向跟岗不少于 2 次
- [ ] 三段认证全流程走完
- [ ] 认证结果已挂钩客户分配
- [ ] 五指标看板月度更新
- [ ] P1/P2 复盘一月内转教学案例
- [ ] 教材季度迭代

---

**本附录要点回顾**

1. 排课三要素：模块、实操占比、仿真环境。生产不练兵。
2. 带教算工时，反向跟岗是实战评估的眼睛。
3. 认证三段硬执行。结果挂钩客户分配，不破例。
4. 案例一月转化，教材季度迭代。培训的复利在案例库。
