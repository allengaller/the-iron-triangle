# 附录 N+　驻场认证落地执行

> 本附录把[附录 N](appx-n-tam-onsite-certification.md)的标准条文转成落地动作。条文定义不在本附录重复。五个动作：认证组织、考核执行、评审与颁证。年审与退出、红线处置。等级与合格线一律以附录 N 为准。

## N+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 等级判定 | C1/C2/C3 目标等级明确 | 回附录 N.1 |
| 申请人资格 | 持证时长与驻场经历达标 | 先攒履历 |
| 评委库 | 评审官与委员会三人就位 | 先建评委库 |
| 题库 | 笔试与情景题就绪 | 先建题库 |

完成标志有五项：组织按半年、考核五方式齐、评审集体表决。年审零缺席、红线有处置。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 组织按半年 | 半年一届不空转 | 认证日历 |
| 考核五方式齐 | 笔试、演练、评审、评价、审计全走 | 考核记录 |
| 评审集体表决 | 三人委员会签认 | 评审纪要 |
| 年审零缺席 | 持证人全员复审 | 年审台账 |
| 红线有处置 | 违规处置有档 | 处置记录 |

## N+.2 操作一：认证组织

### 操作步骤

1. 认证日历半年一届。提前 60 天发通知。
2. 资格审查三查：持证时长、驻场经历、一票否决项排查。
3. 题库分层：C1 基础题、C2 标准题、C3 高压追问。题库每届更新 30%。
4. 情景演练官回避本客户组。防止人情分。

### 预期结果

日历到届。资格三查过。题库分层且更新。回避执行。

### 常见错误

- 认证拖成年度活动。半年节奏丢了。
- 演练官来自本组。人情分难防。

## N+.3 操作二：考核执行

### 操作步骤

1. 五种考核方式按 N.3 组合执行。缺一不可。
2. 实战评审看真实产出物。材料造假按红线（N+.5）。
3. 客户评价走关键人访谈。C3 加高管层反馈。
4. 自检记录审计抽近 6 个月。C3 审计全组记录。
5. 加权算总分。任一维度得分率 < 60% 标记偏科。

### 预期结果

五方式齐。总分与偏科标记在案。

### 常见错误

- 笔试定乾坤。演练与评价走过场。
- 产出物挑好看的送。评审失真。

## N+.4 操作三：评审与颁证

### 操作步骤

1. 评审委员会三人到齐。按权重核算总分，集体表决。
2. 合格线硬执行：总分 ≥ 80、无偏科、演练与评价双达标。
3. 颁证三注：等级、行业方向、有效期。行业纵深单独标注。
4. 授权与排班同步。未持证不排独立驻场。

### 预期结果

表决留痕。颁证三注齐。排班合规。

### 常见错误

- 表决变通报。委员会形同虚设。
- 排班先上岗后补证。隐患埋进现场。

## N+.5 操作四：年审与退出

### 操作步骤

1. 年审每年一轮，全员不缺席。依据：自检记录、客户反馈、事件回溯。
2. 不合格给 3 个月整改期。整改期内授权降一级。
3. 一票否决或连续两年不合格：吊销证书、调离驻场。
4. 重大事故人为责任：即时暂扣，RCA 结论后定降级或吊销。

### 预期结果

年审零缺席。整改有跟踪。退出有依据。

### 常见错误

- 年审变盖章。材料不看就过。
- 退出和稀泥。红线软一次，全软。

## N+.6 操作五：红线处置

### 操作步骤

1. 五条红线（附录 N.3）签收到人。入职即签，年审重签。
2. 触线处置三步：暂停授权、事实核实、按否决项裁定。
3. 处置记录进人事档案。一年内不得重新申请。

### 预期结果

签收全覆盖。触线零姑息。记录进档。

## N+.7 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 认证日历 | 半年一届 | 核对日历 |
| 资格三查 | 持证、履历、否决排查齐 | 核对审查表 |
| 五方式考核 | 缺一不可 | 核对考核记录 |
| 评审表决 | 三人签认 | 核对评审纪要 |
| 合格线 | ≥ 80 且无偏科 | 核对成绩单 |
| 颁证三注 | 等级、行业、有效期齐 | 核对证书 |
| 年审 | 零缺席、有依据 | 核对年审台账 |
| 红线签收 | 到人、年审重签 | 核对签收表 |

关键项是五方式考核、评审表决和红线签收。任一关键项未通过，驻场认证不得视为合格。

## N+.8 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 认证拖期 | 无日历 | 半年节奏入日历 |
| 人情分 | 演练官来自本组 | 强制回避 |
| 偏科过关 | 得分率没卡 | 60% 线硬执行 |
| 排班无证上岗 | 授权未同步 | 证排同步核查 |
| 年审走形式 | 依据不看 | 三依据逐项过 |
| 红线软 | 处置和稀泥 | 否决项硬裁定 |

反复出现的问题进入复盘流程（[附录 R](appx-r-problem-retrospective-standard.md)）。

---

**本附录要点回顾**

1. 认证半年一届。资格三查、题库分层、演练官回避。
2. 五方式考核缺一不可。合格线三条：总分、无偏科、双达标。
3. 评审集体表决，颁证三注，证排同步。无证不排独立驻场。
4. 年审不盖章，红线不和稀泥。信任破产没有补考。
