# 附录 O+　晋升评审落地执行

> 本附录把[附录 O](appx-o-tam-onsite-promotion-standard.md)的标准条文转成落地动作。条文定义不在本附录重复。五个动作：评审组织、证据核验、答辩与表决。观察期管理、破格降级处置。门槛与红线一律以附录 O 为准。

## O+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 通道判定 | 专家或管理通道已定 | 回附录 O.4 |
| 门票 | 评估等级达标（PR3） | 先把服务做好 |
| 认证 | 目标等级认证在手 | 先考认证 |
| 秘书 | 评审秘书与评委库就位 | 先建评委库 |

完成标志有五项：窗口按半年、证据核验过、表决留痕。观察期有复核、破格降级有档。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 窗口按半年 | 一年两届 | 评审日历 |
| 证据核验过 | 来源 100% 可核验 | 核验表 |
| 表决留痕 | 评审团签认 | 评审纪要 |
| 观察期有复核 | 双线复核过 | 复核记录 |
| 破格降级有档 | 处置有据 | 处置档案 |

## O+.2 操作一：评审组织

### 操作步骤

1. 评审窗口一年两届。与附录 G 评估错开一个月。
2. 申请材料清单：O.5 证据清单、模板 12 自评、模板 14 核验表。缺件退回。
3. 资格三查：持证状态、评估门票、五条红线排查。
4. 述辩评审团三人配齐。非同组 C3 以上必须到场。

### 预期结果

窗口到届。材料齐。资格三查过。评审团配齐。

### 常见错误

- 窗口随意改。申请人打乱节奏。
- 材料缺件照收。评审现场补材料。

## O+.3 操作二：证据核验

### 操作步骤

1. 核验三性：来源真实、时间在窗、内容可回溯。事后补记无效。
2. 客户证据第三方访谈。候选人回避。
3. 四块证据逐项对照 O.5 表。缺块不进答辩。
4. 核验记录留痕。核验人签字。

### 预期结果

四块齐。来源可核验。核验留痕。

### 常见错误

- 述职当证据。PPT 不算数。
- 客户评价自己收集。公信力归零。

## O+.4 操作三：答辩与表决

### 操作步骤

1. 述辩 30 分钟。陈述加问答。
2. C3 及以上加高压情景追问。题库复用附录 N。
3. 表决按四块标准。集体讨论后无记名投票。
4. 结果公示 5 个工作日。异议期内受理实名异议。

### 预期结果

答辩有记录。表决留痕。公示走过场。

### 常见错误

- 表决变一言堂。主任委员定调。
- 公示无人看。异议期形同虚设。

## O+.5 操作四：观察期管理

### 操作步骤

1. 授权先小后大。观察期任务清单随文下发。
2. C2 观察期不接重保负责人岗。C3 首次重保配资深副手。
3. 期末双线复核：直属主管加客户关键人。
4. 未通过退回原等级。一年内可再申请，不记处分。

### 预期结果

任务清单在。双线复核过。退出通道畅通。

### 常见错误

- 观察期放羊。到期默认通过。
- 退回当处分。当事人抬不起头，通道变死路。

## O+.6 操作五：破格与降级处置

### 操作步骤

1. 破格走提名制。服务总监提名，加试情景演练。比例 ≤ 10%。
2. 降级四触发逐条核（附录 O.7）。命中即降，6 个月后可再申请。
3. 红线命中直接退出。吊销认证、调离驻场。
4. 处置记录进人事档案。年度复盘看破格与降级分布。

### 预期结果

破格有度。降级有据。红线零缓冲。

### 常见错误

- 破格开闸。例外变成第二通道。
- 降级和稀泥。能上能下成空话。

## O+.7 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 评审窗口 | 一年两届 | 核对日历 |
| 材料清单 | 三件齐 | 核对申请包 |
| 证据核验 | 三性过、来源可核 | 核对核验表 |
| 述辩表决 | 三人评审、留痕 | 核对纪要 |
| 公示 | 5 个工作日 | 核对公示记录 |
| 观察期 | 任务清单与双线复核 | 核对复核记录 |
| 破格比例 | ≤ 10% | 核对晋升名单 |
| 红线处置 | 直接退出有档 | 核对处置档案 |

关键项是证据核验、观察期复核和红线处置。任一关键项未通过，晋升评审不得视为合格。

## O+.8 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 材料临时补 | 清单未前置 | 清单随文下发 |
| 述职当证据 | 核验走过场 | 三性核验硬执行 |
| 表决一言堂 | 主任委员定调 | 无记名投票 |
| 观察期放羊 | 无任务清单 | 清单随文下发 |
| 破格变常态 | 提名无度 | 10% 比例硬执行 |
| 降级空转 | 处置和稀泥 | 四触发硬核 |

反复出现的问题进入复盘流程（[附录 R](appx-r-problem-retrospective-standard.md)）。

## O+.9 执行检查清单

- [ ] 评审窗口一年两届，与评估错峰
- [ ] 申请材料三件齐
- [ ] 资格三查完成
- [ ] 证据三性核验、第三方访谈客户
- [ ] 述辩三人评审、高压追问（C3+）
- [ ] 无记名表决、公示 5 个工作日
- [ ] 观察期任务清单下发
- [ ] 双线复核到位
- [ ] 破格 ≤ 10%、加试情景演练
- [ ] 降级四触发硬核、红线直接退出

---

**本附录要点回顾**

1. 评审窗口固定，材料清单前置。缺件退回，不现场补。
2. 证据三性核验，客户评价第三方做。述职 PPT 不是证据。
3. 表决无记名、公示五天。观察期先小后大，双线复核。
4. 破格有比例、降级有触发、红线无缓冲。能上能下才是通道。
