# 附录 I+　值班落地执行

> 本附录把[附录 I](appx-i-on-duty-standard.md)的标准条文转成落地动作。条文定义不在本附录重复。五个动作：模式落地、排班执行、交接执行。日志与度量执行、红线处置。时限与锚点一律以附录 I 为准。

## I+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 模式判定 | 客户等级与值班模式已定 | 回附录 I.4 |
| 升级矩阵 | 模板 06 就位 | 先补模板 |
| 认证 | 值班人过附录 J 专项认证 | 先送认证 |
| 平台 | 工单与告警系统可取数 | 回附录 H |

完成标志有五项：模式进计划、排班可执行、交接到签字。日志当班清、红线有处置。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 模式进计划 | 服务计划写明并公示 | 服务计划 |
| 排班可执行 | 主备双岗、持证上岗 | 排班表 |
| 交接到签字 | 三件事零遗漏 | 交接清单 |
| 日志当班清 | 当班结束前完成 | 值班日志 |
| 红线有处置 | 违规处置有记录 | 处置记录 |

## I+.2 操作一：模式落地

### 操作步骤

1. 按客户等级定模式（附录 I.4 三档）。判定结果书面化。
2. 模式写入服务计划（模板 01）。向客户公示。
3. 重保期升档预案写进重保手册（模板 05）。升档触发条件明确。
4. 模式变更走服务计划刷新。不口头调整。

### 预期结果

模式书面化、入计划、已公示。升档预案在手册里。

### 常见错误

- 模式口头约定。出了事各执一词。
- 重保不升档。临时抱佛脚。

## I+.3 操作二：排班执行

### 操作步骤

1. 排班表四要素：窗口、主值、备值、联系方式。提前 ≥ 14 天公布。
2. 主备双岗核验。备值知情且可用，空挂的备值等于没有。
3. 轮换与疲劳管理照附录 I.5 执行。连续值班、间隔、单班时长、强制休息四项不破。
4. 临时换班走审批。主管批、接口人同步，台账留痕。
5. 持证上岗核对。未过认证不排 M2/M3 班。

### 预期结果

排班四要素齐。双岗核验过。疲劳四限达标。换班留痕。

### 常见错误

- 备值空挂。主值失联就断档。
- 疲劳四限口头执行。连续值班超限无人管。

## I+.4 操作三：交接执行

### 操作步骤

1. 交接清单按“三件事”逐条填。未闭环事件、进行中变更与冻结窗口、客户敏感事项。。
2. 当面或通话确认。书面清单加口头过一遍。
3. 双方签字（电子）留痕。签字前不离岗。
4. 遗留事项转跟踪。责任到人、时间到日。

### 预期结果

三件事零遗漏。签字留痕。遗留有跟踪。

### 常见错误

- 交接一句“没啥事”。次日踩雷。
- 签字走形式。清单不看就签。

## I+.5 操作四：日志与度量执行

### 操作步骤

1. 日志四必项当班写：事件、处置、升级通报、交接遗留。当班结束前完成。
2. 月度抽查交接与日志。抽查比例建议 10%，按业务校准。
3. 度量看板五指标（附录 I.8）。数据全部系统取数。
4. 未达标项进改进。响应达标率与告警接通率是硬项。

### 预期结果

日志零补记。五指标月月可看。未达标有改进。

### 常见错误

- 日志事后补。证据链失真。
- 手工填报凑指标。度量失真。

## I+.6 操作五：红线处置

### 操作步骤

1. 四条红线（附录 I.7）张贴到人。签收留痕。
2. 违规处置三步：暂停值班资格、事实核实、追责与再培训。
3. 处置记录进人事与评估档案。接附录 G 否决条款。
4. 每年复训红线案例。用真实脱敏案例讲。

### 预期结果

红线签收全覆盖。违规处置有档。复训年年做。

### 常见错误

- 红线贴墙不签收。追责时说没看过。
- 处置和稀泥。红线就软了。

## I+.7 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 模式入计划 | 书面化并公示 | 核对服务计划 |
| 排班四要素 | 提前 14 天公布 | 核对排班表 |
| 双岗核验 | 备值知情可用 | 抽查核验记录 |
| 疲劳四限 | 无破限 | 核对排班台账 |
| 交接签字 | 三件事零遗漏 | 抽查交接清单 |
| 日志及时 | 当班结束前完成 | 抽查日志时间戳 |
| 五指标 | 系统取数、月月可看 | 核对看板 |
| 红线签收 | 覆盖到人 | 核对签收表 |

关键项是排班四要素、交接签字和红线签收。任一关键项未通过，值班落地不得视为合格。

## I+.8 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 电话没人接 | 备值空挂 | 双岗核验重跑 |
| 交接踩雷 | 三件事没过 | 强制清单签字 |
| 日志补记 | 未当班写 | 当班结束前卡点 |
| 指标失真 | 手工填报 | 全量改系统取数 |
| 疲劳破限 | 排班无人管 | 疲劳四限进台账 |
| 红线虚设 | 未签收 | 补签收与年训 |

反复出现的问题进入复盘流程（[附录 R](appx-r-problem-retrospective-standard.md)）。

## I+.9 执行检查清单

- [ ] 值班模式已写入服务计划并公示
- [ ] 重保升档预案在手册里
- [ ] 排班表四要素齐，提前 14 天公布
- [ ] 备值知情且可用
- [ ] 疲劳四限无破限
- [ ] 临时换班审批留痕
- [ ] 值班人全部持证上岗
- [ ] 交接三件事签字留痕
- [ ] 日志当班完成，零补记
- [ ] 五指标系统取数月月可看
- [ ] 红线签收到人，年训已做

---

**本附录要点回顾**

1. 模式进计划才算落地。口头约定出事就散。
2. 排班四要素加双岗核验。疲劳四限是响应质量的一部分。
3. 交接三件事签字留痕。“没啥事”不构成交接。
4. 日志当班清、指标系统取、红线签收到人。落地的验收看证据，不看墙。
