# SA-05　讲标检查表

> 用途：讲标与方案汇报的全流程检查，讲前、讲中、讲后三段。
> 用法：按清单逐项勾选；答疑分工表讲前必填；讲后 24 小时内出纪要。
> 时点：v0.1，2026-11-02 随书拟稿。

---

## 一、讲前（T-3 日内完成）

- □ 叙事主线一句话（客户买的是什么价值）
- □ 三层图就位：业务层先行，框框过四问（第 9 章）
- □ 六十秒口头版背熟（开头即价值，不铺垫）
- □ Demo 环境双备份（录屏兜底）
- □ 答疑分工表填好：

| 问题域 | 应答人 | 兜底人 |
| --- | --- | --- |
| 技术架构 | | |
| 商务报价 | | |
| 交付与运营 | | |
| 合规与风险 | | |

- □ 竞争对比口径过一遍（SA-04 第四节）
- □ 承诺边界自查：现场不新增承诺（第 9 章四问）

## 二、讲中

- □ 开场 60 秒讲清价值
- □ 业务层 → 逻辑层 → 部署层，顺序不乱
- □ 竞品问题按对比叙事答，不贬损
- □ 拿不准的标准话术：“我记下来，核实后今天内回复”
- □ 会后承诺立即记入清单，不留在口头

## 三、讲后（24 小时内）

- □ 书面纪要（决定事项、行动项、遗留问题）
- □ 新增承诺过四问后入清单
- □ 答疑遗留逐条分派，责任到人、时间到日
- □ 复盘一句：下次讲图顺序要不要调
