# 第 16 章　报价与谈判

> 流程篇第六步。报价与让步的打法在[第 8+ 章](ch08-practical.md)，本章管这一步在流程里怎么跑。核心纪律两条：**让步要交换，底线不能让**。谈判主责在 BTE（技术销售），SA 守技术与承诺底线（分工见[第 2 章](ch02-triangle-boundary.md)）。下游是第 17 章签单交接。

## 16.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 方案基线 | 已冻结 | 回第 13 章 |
| TCO 口径 | 与 SA-03 一致 | 补第 8+ 章 |
| 内部审批 | 报价权限与折扣档已批 | 先走审批 |
| 底线清单 | 非价格底线书面化 | 先做 16.3 |

完成标志有四项：报价有分段、底线有清单、让步有交换、成交有归档。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 报价有分段 | 三段映射方案结构 | 报价单 |
| 底线有清单 | 非价格底线书面化 | 底线清单 |
| 让步有交换 | 成对记录 | 谈判记录 |
| 成交有归档 | 价格与承诺对照 | 归档记录 |

## 16.2 操作一：报价编制

### 操作步骤

1. 按三段出报价：平台段、服务段、弹性段（口径见[第 8+ 章](ch08-practical.md)）。
2. 每段映射方案结构。钱花在哪，方案说得清。
3. TCO 摘要随报价附上。假设显式（SA-03）。
4. 内部审批走完才出门。折扣权限越级即停。

### 预期结果

三段报价与方案对得上。审批留痕。

### 常见错误

- 一口价。客户没得谈，只能压总价。
- 报价与方案脱节。客户逐项砍，砍到骨头。
- 先出门后补审批。越权承诺找上门。

## 16.3 操作二：谈判准备

### 底线清单

| 类 | 底线项 | 破线后果 |
| --- | --- | --- |
| 承诺 | 五维门槛、四问不过的承诺 | 交付翻车 |
| 口径 | SLA 分子分母、Credit 规则 | 争议地雷 |
| 范围 | 明确不覆盖的范围 | 范围蔓延 |

### 操作步骤

1. 底线清单书面化。逐项写破线后果。
2. 让步阶梯排练（8+ 章三阶梯）。每档换什么，事前想好。
3. 谈判分工：BTE 主谈，SA 答技术与承诺，法务把合同。
4. 沙盘一轮。最坏问题先答一遍。

### 预期结果

底线书面。阶梯排练过。分工到人。

### 常见错误

- 底线口头。现场一松就破。
- 交换没预想。让了价换不回条件。
- 分工不清。价格问题抛给 SA。

## 16.4 操作三：谈判执行

### 操作步骤

1. 让步逐级走阶梯。每让一步，当场记下换回的条件。
2. 非价格底线死守。底线问题回承诺四问（[第 9 章](ch09-commitment-engineering.md)）。
3. 当场不新增承诺。口头答复不构成承诺，一律入清单走四问。
4. 僵局不硬扛。休会请示，不现场发明方案。

### 预期结果

让步成对。底线零破。现场零新增承诺。

### 常见错误

- 单向让步。教客户继续压。
- 底线破口。承诺让出去，交付收不回。
- 现场顺口承诺。会后清单对不上账。

## 16.5 操作四：成交归档

### 操作步骤

1. 价格与承诺对照。报价每一段对应回承诺清单。
2. 谈判记录归档。让步成对记录进档。
3. 启动签单交接预告。第 17 章三件套备料。
4. 未成交同样归档。进第 11 章复盘。

### 预期结果

价格承诺对得上。记录归档。交接无缝启动。

### 常见错误

- 只归档成交单。丢单教训流失。
- 承诺对不上价格。交接会现场扯皮。
- 交接没预告。签完单团队才开始找材料。

## 16.6 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 报价三段 | 映射方案结构 | 核对报价单 |
| 审批留痕 | 折扣权限合规 | 核对审批 |
| 底线清单 | 书面化、破线后果明确 | 核对清单 |
| 让步记录 | 成对、当场记录 | 核对谈判记录 |
| 现场承诺 | 零新增 | 核对承诺清单 |
| 成交归档 | 价格承诺对照 | 核对归档 |

关键项是底线清单、让步记录和现场承诺零新增。任一关键项未通过，报价谈判不得视为合格。

## 16.7 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 客户逐项砍价 | 报价一口价 | 改三段报价 |
| 让步越让越多 | 无交换原则 | 回阶梯逐级走 |
| 底线破口 | 底线口头 | 书面化破线后果 |
| 承诺对不上账 | 现场顺口答 | 走四问入清单 |
| 谈判僵局升级 | 硬扛不请示 | 休会请示 |
| 交接扯皮 | 成交没对照 | 补价格承诺对照 |

反复出现的问题进入复盘流程（[《The TAM Book》附录 R](../the-tam-book/appx-r-problem-retrospective-standard.md)）。

- [ ] 交接预告启动，三件套备料

---

**本章要点回顾**

1. 报价三段映射方案结构。一口价只会招来压价。
2. 底线清单书面化。破线后果写出来，现场才守得住。
3. 让步逐级走阶梯，步步换条件。现场零新增承诺。
4. 成交归档做对照，未成交同样归档。交接从预告开始。
