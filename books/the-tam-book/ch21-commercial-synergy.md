# 第 21 章　商业化协同

> TAM 不背续约金额。TAM 负责让续约与增购的技术判断更早、更准、更可核验。本章解决四类操作。运行信号单。盘点续约风险。判读用量与增购。交付 QBR/EBR 与 VBR。本章为 How-to。岗位边界见[第 2 章](ch02-role-boundary-map.md)，价值证据来源见[第 3 章](ch03-value-proposition.md)，生命周期入口见[第 17 章](ch17-customer-lifecycle.md)。

## 21.1 前置条件与目标

商业化协同不是从到期前一个月开始。先确认以下条件，再进入例行操作。

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 商务接口 | 销售或续费负责人、替班与授权范围 | 与服务负责人确认 |
| 信号台账 | 信号单模板与移交记录 | 用[模板 19](tpl-19-commitment-handover-kit.md)建立 |
| 健康分数据 | 用量、质量、风险与关系维度 | 按[第 34 章](ch34-measurement-system.md)核对口径 |
| 关键人地图 | 决策链、影响链与接班人 | 用[模板 11](tpl-11-key-person-map-canvas.md)刷新 |
| 价值锚点台账 | 可核验的价值事件与前后对比 | 从月报与 QBR 补录 |
| 业务日历 | 续约、预算、峰值与冻结节点 | 按[第 7 章](ch07-business-insight.md)补建 |
| 服务承诺基线 | 服务计划目标与交付记录 | 用[模板 01](tpl-01-service-plan.md)核对 |
| QBR 节奏 | 季度会议与客户出席层级 | 与客户接口人确认 |

完成标志有五项。信号有书面移交。续约风险有分级。用量有归因。QBR 有决策跟踪。VBR 有客户签收。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 边界清晰 | TAM 不报价、不谈判、不背金额 | 角色约定与会议记录 |
| 信号可信 | 事实、证据、建议与时限齐全 | 信号单 |
| 续约可控 | T-180 启动并有风险初判 | 盘点记录 |
| 会议有效 | 决策项有 Owner 和期限 | QBR/EBR 纪要 |
| 价值可证 | VBR 四段齐全并签收 | 签收记录 |

### 21.1.1 分工边界

商务结果归销售。TAM 对技术信号与技术口径负责。评价口径见[附录 G](appx-g-tam-work-evaluation-standard.md)的 L3.6 与 L3.7。

| 事项 | TAM 负责 | 销售负责 |
| --- | --- | --- |
| 续约 | 识别风险、提供证据、支持口径 | 报价、谈判与合同 |
| 增购 | 识别机会、验证技术可行性 | 商机推进与归属管理 |
| QBR/EBR | 讲清价值、风险与技术计划 | 安排商务与客户高层 |
| VBR | 编制、讲解、交付与签收 | 把价值叙事接入续约策略 |
| POC | 技术守门与结论如实 | 商务目标与资源安排 |

客户问价格、折扣或合同条款时，TAM 引导回销售。客户问技术能力、风险和运行证据时，TAM 直接回答。

## 21.2 操作一：运行信号单机制

### 21.2.1 信号单四字段

信号单是商业化协同的书面接口。口头信号无追溯，不能作为协同依据。

| 字段 | 要求 | 不合格写法 |
| --- | --- | --- |
| 事实 | 时间、对象与可观察变化 | 客户好像要走 |
| 证据 | 数据、记录或会议佐证 | 听说预算收缩 |
| 建议动作 | 给销售的可选动作与时点 | 请关注一下 |
| 时间敏感度 | 建议响应窗口与升级条件 | 尽快 |

### 21.2.2 操作步骤

1. 识别续约风险或增购机会。
2. 核对健康分、用量、工单、关键人与业务日历。
3. 判断信号类型和敏感度。
4. 撰写信号单。四字段齐备后发出。
5. 通过书面方式移交销售，记录接收人和时间。
6. 约定反馈时点，跟踪信号处置。
7. 信号升级或降级时补录一版，不覆盖原记录。
8. 季度回看信号命中与偏差。

信号移交后，三角协同规则见[附录 V](appx-v-tam-bte-sa-triangle.md)。台账使用模板 19。

### 21.2.3 三条边界纪律

1. **不当传声筒**：客户问价格，引导回销售。
2. **不夹带催促**：技术场合不替销售催单。
3. **不隐瞒风险**：风险信号要及时书面共享。不要因为担心影响气氛而压住。

信号用于施压时，TAM 应当场澄清边界。必要时通过服务经理升级。

## 21.3 操作二：盘点续约风险与执行 180 天节奏

### 21.3.1 续约信号清单

五类信号按预警期排序。单点信号先核实，多维共振再升级。

| 信号 | 预警期 | 判读要点 |
| --- | --- | --- |
| 健康分连续下滑 | 6 个月以上 | 用量、工单与关系共振才可信。单维抖动先核实 |
| 关键人变动 | 3–6 个月 | 支持者离任是风险。新官上任兼有风险与机会 |
| 服务互动降温 | 3–6 个月 | 例会取消、QBR 降级，说明参与意愿下降 |
| 竞对进场 | 1–3 个月 | 调研问卷、迁移数据请求与 POC 邀请 |
| 预算收缩征兆 | 1–3 个月 | 扩容搁置、维持现状提问增多 |

### 21.3.2 操作步骤

1. 列出续约时间、预算周期和客户决策链。
2. T-180 完成首轮风险盘点，形成初判记录。
3. 将信号按高、中、低分级，写明依据与不确定度。
4. 与销售召开信号同步会，确认分工与时点。
5. 核对价值锚点台账，标记缺失证据。
6. 按节奏推进价值汇报、谈判支持与决策跟踪。
7. 到期后回看预测与实际结果。
8. 偏差较大时复盘信号权重和触发机制。

### 21.3.3 180 天节奏

| 时点 | 动作 | 交付物 |
| --- | --- | --- |
| T-180 | 续约风险初判与首轮信号单 | 风险初判 |
| T-150 | 与销售信号同步，确认商务动作 | 同步纪要 |
| T-120 | 核对价值锚点，启动 VBR 素材 | 证据清单 |
| T-90 | EBR 或专项价值汇报 | 汇报材料与纪要 |
| T-60 | 谈判技术支持 | 用量、SLA 与服务记录 |
| T-30 | 即时响应技术问询 | 响应记录 |

T-30 才发现客户动摇，说明信号系统失效。事件应进入复盘，复盘要求见[附录 R](appx-r-problem-retrospective-standard.md)。

预测准确率按季度回看。记录预测、实际和偏差原因。口径跟随[第 34 章](ch34-measurement-system.md)。连续偏离时调整信号权重，不做直觉汇报。

## 21.4 操作三：判读用量与识别增购

### 21.4.1 用量三判读

用量是订阅服务的重要健康信号。判读先归因，再动作。

| 判读线 | 观察重点 | 处理方向 |
| --- | --- | --- |
| 趋势 | 环比变化与持续时间 | 先归因业务、季节、迁移或摩擦 |
| 结构 | 单产品依赖或多产品铺开 | 单产品依赖会降低替换阻力 |
| 水位 | 容量水位与增长曲线 | 先优化成本，再谈扩容 |

下行伴随工单上升和抱怨增多时，优先判断为使用摩擦。动作是排障、赋能与流程适配，而不是直接拉响续约警报。赋能入口见[附录 J](appx-j-enablement-training-standard.md)。

### 21.4.2 增购机会信号

典型触发源包括五类。容量接近水位线。客户新业务上线。AI 项目立项。组织扩张带来新场景。监管新规提出新要求。

识别后移交销售，不自行跟进商务。信号单写清触发证据、影响范围和建议切入点。机会归属在移交记录中一次说清。AI 项目立项的技术准备见[第 27 章](ch27-ai-workload-assurance.md)，监管背景见[第 22 章](ch22-financial-industry.md)。

### 21.4.3 操作步骤

1. 每月读取用量趋势、结构和水位。
2. 为异常变化写归因假设和验证方式。
3. 与业务日历、工单和项目计划交叉核对。
4. 判断是否构成增购机会或续约风险。
5. 机会信号移交销售，留痕并确认归属。
6. 进入验证阶段后，TAM 转任技术守门人。
7. 验证结束输出结论、证据和遗留条件。

### 21.4.4 POC 三纪律

1. **标准事前量化**：成功标准双方确认，不事后解释。
2. **环境对齐生产**：验证环境要反映生产特征。实验室数据不直接代表生产。
3. **结论如实**：不达标就写不达标。技术信誉比单笔订单更重要。

## 21.5 操作四：设计与交付 QBR/EBR

### 21.5.1 两种会议的分工

| 会议 | 主要对象 | 目标 | 频次 |
| --- | --- | --- | --- |
| QBR | 客户管理层与接口团队 | 对齐节奏、透明问题、确认计划 | 季度 |
| EBR | CIO、CTO 等高层 | 价值确认、战略对齐、风险决策 | 一到两次 |

模板见[模板 08](tpl-08-qbr-ebr-template.md)。高层时间有限，EBR 材料要更短、决策更明确。

### 21.5.2 会前步骤

1. 确认客户议题和出席层级。
2. 核对数据口径，确保与月报一致。
3. 会前两日发送数据底稿。
4. 整理上季度行动项闭环情况。
5. 准备风险 Top 项、计划与请求决策项。
6. 对 EBR 预演高层问题和答案。

### 21.5.3 QBR 议程骨架

90 分钟议程可按客户情况裁剪。

| 议程 | 时长 | 要求 |
| --- | --- | --- |
| 承诺回顾 | 10 分钟 | 先讲行动项闭环率 |
| 服务数据 | 20 分钟 | 指标带业务影响 |
| 价值亮点 | 20 分钟 | 量化并注明出处 |
| 风险与计划 | 25 分钟 | 会议主体，包含请求 |
| 客户议题 | 15 分钟 | 保留给客户 |

### 21.5.4 交付红线

1. **不念指标**：数据会前发。会上讲含义、动作和请求。
2. **问题透明**：未闭环问题主动上墙。隐瞒一旦暴露，会损害会议信用。
3. **决策落地**：高层拍板事项写入纪要，指定 Owner 和期限。
4. **口径一致**：同一指标只允许一个数字。AI 辅助材料经人工复核后上会。

### 21.5.5 会后步骤

1. 24 小时内发出纪要。
2. 行动项进入月度评审跟踪。
3. 记录客户出席层级和议题变化。
4. 价值锚点回填台账。
5. 下次会议先核对上次决策闭环。

## 21.6 操作五：编制与交付 VBR

### 21.6.1 定位

VBR 回答客户高层的一个问题。这一年的投入是否得到可验证回报。它是续约对话的开场材料，不是年终表扬稿。

VBR 原料来自价值锚点台账。平时不积累，续约前就难以补齐。价值证据来源见[第 17 章](ch17-customer-lifecycle.md)。

### 21.6.2 四段结构

| 段落 | 内容 | 证据要求 |
| --- | --- | --- |
| 承诺 | 对照服务计划目标 | 目标、口径与时间窗 |
| 交付 | 可用性、SLA、事件与重保结果 | 系统取数 |
| 价值 | 技术、业务与财务影响 | 出处、假设与对照基线 |
| 下一步 | 下年度建议与风险计划 | 与业务日历连接 |

### 21.6.3 量化纪律

量化必须有出处。讲不清财务影响时，讲风险影响和业务影响。不要为了好看编造金额。

避免损失要有对照基线。例如往年同期损失、隐患可能造成的业务影响。基线可比时才使用。未兑现项也要写入，并附改进计划。

VBR 的读者包括客户对口人。续约预算需要对口人向内部解释。报告中的每个证据，都是支持对方完成内部沟通的材料。

### 21.6.4 操作步骤

1. 核对服务计划承诺与年度实际交付。
2. 从价值锚点台账筛选可核验事件。
3. 按四段结构形成初稿。
4. 每个数字标注出处、口径和假设。
5. 请销售确认续约策略与详略。
6. 向客户当面讲解，并回答追问。
7. 取得客户高层签收。
8. 将高层反馈记入关键人地图。

## 21.7 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 信号移交 | 本季信号均有信号单和接收记录 | 抽查信号台账 |
| 续约盘点 | T-180 完成且风险有分级 | 核对初判记录 |
| 用量判读 | 每月有趋势、结构、水位归因 | 核对月度记录 |
| 增购移交 | 机会有证据、建议和归属 | 抽查信号单 |
| QBR 质量 | 议程完整，决策项有跟踪 | 抽查纪要 |
| EBR 质量 | 决策事项明确，高层出席有记录 | 核对会议档案 |
| VBR 交付 | 四段齐全，量化有出处，客户签收 | 核对报告与签收 |
| 边界合规 | 无越界报价和商务催促 | 访谈销售与客户 |

验收失败时先修机制。信号口头化与 VBR 临时编造属于关键项。未修复前不得视为合格。

## 21.8 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 信号无人跟进 | 移交无记录或对象不清 | 补信号单并确认接收人 |
| 销售不信任信号 | 证据弱或历史准确率低 | 补证据，季度回看准确率 |
| 续约发现过晚 | T-180 未启动或信号未书面化 | 立即补盘点并进入复盘 |
| 用量下降误判 | 只看趋势，未做归因 | 补业务、技术与摩擦三类归因 |
| QBR 出席降级 | 会议变成数据汇报 | 改为风险、计划和决策议程 |
| 决策反复不落地 | 纪要无 Owner 或期限 | 补跟踪表并纳入月度评审 |
| 客户质疑 VBR | 数字无出处或夸大归因 | 改为保守口径并注明假设 |
| 组织要求 TAM 背金额 | 角色边界未约定 | 重申[附录 G](appx-g-tam-work-evaluation-standard.md)的 L3.6/L3.7 口径 |

反复出现的协同问题进入复盘流程。

## 21.9 常见误区

1. **直接背续约金额**：角色错位会导致动作变形。讨好客户、隐瞒风险、替销售压价，都是常见表现。
2. **信号口头化**：没有书面记录，续约失败后无法复盘。
3. **QBR 念 PPT**：客户出席层级会逐步下降。
4. **VBR 临时拼凑**：数字经不起追问，价值证据失去信用。
5. **只讲过去**：缺少下一步建议，客户找不到续约理由。
6. **把 POC 当推销**：标准不量化或结论美化，会透支技术信誉。

## 21.10 执行检查清单

- [ ] 本季度信号均有信号单、接收人和反馈记录
- [ ] 续约客户 T-180 盘点完成，风险有分级
- [ ] 用量趋势、结构和水位每月有归因
- [ ] 增购机会已移交销售，归属有记录
- [ ] 最近一次 QBR 有行动项闭环和客户议题
- [ ] EBR 决策事项已写入纪要并跟踪
- [ ] 最近一份 VBR 四段齐全并获客户签收
- [ ] 价值锚点台账本季度有新增
- [ ] 我未越界报价、催款或替销售承诺
- [ ] 续约预测已按季度回看并记录偏差

---

**本章要点回顾**

1. TAM 对技术信号负责，不对金额负责。书面信号单是协同接口。
2. 续约信号有五类。T-180 启动盘点，T-90 价值汇报，T-60 谈判支持。
3. 用量按趋势、结构和水位判读。先归因，再动作，不把使用摩擦误判成流失。
4. QBR 主体是风险与计划。EBR 聚焦高层决策。决策项必须跟踪闭环。
5. VBR 分承诺、交付、价值和下一步。量化有出处，不足也要写。
6. POC 三纪律是标准量化、环境对齐生产、结论如实。

## 外延篇小结

外延篇五章至此齐备。生命周期给出时间轴。升级与危机处理断点。内部协同与生态协同管两条协作面。商业化把服务结果兑现为商业价值。内涵六维决定 TAM 能做什么。外延五章决定这些能力在什么范围、什么节奏、为谁兑现。两者相乘，才构成完整的 TAM 服务能力。
