# 第 38 章　团队建设动作

> 本章把[第 37 章](ch37-career-team-building.md)的职业框架转成团队建设动作。目标是把六件事做成可执行流程。矩阵、招聘、培养、配置、绩效、沉淀。框架与原理见[第 37 章](ch37-career-team-building.md)，本章不重复。

## 38.1 前置条件与目标

开始前确认以下输入。缺项先补齐，或登记为风险。

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 成熟度标尺 | [第 36 章](ch36-maturity-model.md) M1–M5 主管层已掌握 | 先做标尺对齐 |
| 评估口径 | [附录 G](appx-g-tam-work-evaluation-standard.md) 三层评估可用 | 先统一口径 |
| 培训标准 | [附录 J](appx-j-enablement-training-standard.md) T1–T3 出口明确 | 补培训映射 |
| 带教资源 | 每个新人有指定带教人 | 缓招，先补带教人 |
| 编制与预算 | 招聘名额与培训预算获批 | 登记缺口 |

完成标志有六项：矩阵成型、招聘有章、培养有节奏。配置有备份、绩效有配对、沉淀有入库。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 矩阵成型 | 全员逐格打分，热力图出图 | 技能矩阵表 |
| 招聘有章 | 场景题与反向信号核查执行 | 面试记录 |
| 培养有节奏 | 90 天三阶段按表推进 | 带教台账 |
| 配置有备份 | 关键客户均有第二接口人 | 备份清单 |
| 绩效有配对 | 每个效率指标有配对质量指标 | 绩效方案 |
| 沉淀有入库 | 方法论入案例库与模板 | 案例库记录 |

## 38.2 操作一：搭建技能矩阵

### 操作步骤

1. 逐人逐格打分（1–5 分）。列是六维加 AI 杠杆，行是 M1–M5 锚点。
2. 叠全员矩阵找三样：断层、扎堆、备份真空。
3. 每个关键客户、关键技能域写下第二人。写不出的格子进风险登记册。
4. 每半年随[附录 G](appx-g-tam-work-evaluation-standard.md) 中期校准刷新一次。
5. 热力图作为招聘与培训预算的分配依据。

### 预期结果

矩阵每半年新。断层有补位计划。备份真空有台账。

### 常见错误

填完锁抽屉。只打分不看图。第二人常年空着。

## 38.3 操作二：执行招聘

### 操作步骤

1. 场景题考判断力：给信息不全的场景，看推理链与风险意识。
2. 翻译题考沟通：让候选人向业务角色解释一次故障。限时五分钟。
3. 锚点领域深挖：网络、数据库、云原生任选其一，考到评审深度。
4. 全程观察反向信号：抱怨型叙事、过度承诺型表达。
5. 来源按策略走：内部转岗优先，外招看跨行业同岗位。

### 预期结果

录用判断有证据记录。反向信号有观察笔记。

### 常见错误

照简历提问。看证书定级。反向信号只靠感觉。

## 38.4 操作三：运行新人 90 天培养

### 操作步骤

1. 0–30 天看懂：读服务计划、风险登记册、近一年故障史。跟班例会、值班、评审，只观察不动手。建个人知识库（[第 28 章](ch28-ai-for-tam.md)）。出口检查：能复述拓扑与决策链，通过产品与环境笔试。
2. 31–60 天上手：带教人复核下处理工单、写月报、执行自检。完成一次健康检查（模板 03 精简版）。出口检查：工单抽检合格（[附录 U](appx-u-ticket-management-standard.md) 口径），值班认证（[附录 J](appx-j-enablement-training-standard.md) 三段式）。
3. 61–90 天独立：独立承担长尾客户或子系统。主导一次例会。出口检查：T1 认证通过，带教评价与 90 天复盘入档。
4. 带教工作量计入带教人绩效。执行[附录 O](appx-o-tam-onsite-promotion-standard.md) 的带教硬门槛口径。
5. 认证不过延长培养期。延期两次启动岗位匹配复评。

### 预期结果

90 天出认证结论。带教有投入记录。未过认证无人独立上岗。

### 常见错误

缺人倒逼放水。带教算帮忙不算工作。放羊式培养。

## 38.5 操作四：配置团队结构

### 操作步骤

1. 客户分配按 M 级别授权（[第 36 章](ch36-maturity-model.md) 27.5）。AA 级/金融核心客户须 M3 以上加[附录 N](appx-n-tam-onsite-certification.md) 驻场认证。
2. 控制客户组合复杂度。三个重点客户加长尾若干是可持续结构。五个重点客户是职业倦怠（burnout）配方。队员出现倦怠时的分层处置见[附录 AD](appx-ad-career-lifecycle-guide.md)（AD.9 主题三）。
3. 梯队保持正态分布。M2–M3 为主力。
4. 每个客户指定知情的第二接口人（与[附录 I](appx-i-on-duty-standard.md) 主备双岗同源）。
5. 驻场组长排班权不接受客户单方支配（[附录 S](appx-s-overtime-compoff-standard.md) 已有约定）。远程团队按[附录 P](appx-p-tam-service-quality-standard-public-cloud.md)/[附录 Q](appx-q-tam-service-quality-standard-dedicated-cloud.md) 质量框架度量。

### 预期结果

授权合规。备份无真空。排班权在组织手里。

### 常见错误

五个重点客户硬扛。第二接口人有名无实。客户随意抽调驻场组长。

## 38.6 操作五：落地绩效与激励

### 操作步骤

1. 绩效方案只考核技术信号。续约与增购金额不进 TAM 指标。
2. 三类团队健康指标进主管绩效。加班结构、调休兑现率、强制休息执行率，口径见[附录 S](appx-s-overtime-compoff-standard.md)。
3. 逐个检查指标配对：效率配质量、个人配团队（[第 34 章](ch34-measurement-system.md) 26.8）。
4. 非物质激励落地：M4/M5 方法论署名、重保与旗舰客户优先指派。

### 预期结果

指标方案无金额项。配对齐备。署名与指派有记录。

### 常见错误

背金额换激励。健康指标考核员工。单指标硬压。

## 38.7 操作六：经营出口与沉淀

### 操作步骤

1. 每年与骨干做一次发展方向对话。对齐[附录 O](appx-o-tam-onsite-promotion-standard.md) 双通道。
2. 任期内沉淀进案例库与模板（[附录 J](appx-j-enablement-training-standard.md) 资产沉淀要求）。
3. 流向客户方的旧部保持联系。那是关系资产。
4. 流向产品与研发的同事建立反馈回路（[第 19 章](ch19-internal-collaboration.md)）。
5. 离职与转岗交接用[模板 19](tpl-19-commitment-handover-kit.md)。

### 预期结果

骨干有发展方向。方法论入了库。旧部网络在维护。

### 常见错误

出口对话拖到提离职。沉淀靠自觉。把离职当背叛。

## 38.8 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 技能矩阵 | 全员打分，热力图半年一新 | 抽查矩阵与刷新记录 |
| 招聘 | 场景题与反向信号核查有记录 | 抽查面试记录 |
| 培养 | 90 天按阶段推进，认证率达标 | 核对带教台账 |
| 配置 | 关键客户有第二接口人 | 核对备份清单 |
| 绩效 | 无金额指标，配对齐备 | 审查绩效方案 |
| 激励 | 署名与指派有记录 | 核对激励台账 |
| 沉淀 | 方法论入案例库 | 核对案例库 |
| 出口 | 骨干有发展方向对话记录 | 抽查对话纪要 |

关键项是培养、配置和绩效。任一关键项未通过，团队建设不得视为合格。

## 38.9 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 矩阵常年不刷新 | 无半年节奏 | 排入附录 G 中期校准 |
| 招聘流失率高 | 画像执行偏差 | 回放面试记录复核 |
| 新人 90 天不出认证 | 带教投入不足 | 补带教人或减负 |
| 关键人休假质量塌方 | 备份真空 | 启动备份人培养 |
| 团队疲劳蔓延 | 排班失衡 | 主管绩效挂钩整改 |
| 客户质疑绩效方案 | 混入金额指标 | 移除并复核口径 |
| 骨干集体观望 | 出口不清晰 | 启动方向对话 |
| 方法论随人走 | 沉淀未入库 | 补案例库归档 |

反复出现的问题进入复盘流程。

## 38.10 执行检查清单

- [ ] 技能矩阵全员打分且热力图半年一新
- [ ] 断层有补位计划，备份真空有台账
- [ ] 招聘场景题、翻译题、反向信号核查成体系
- [ ] 新人 90 天按看懂、上手、独立推进
- [ ] 带教工作量计入带教人绩效
- [ ] 未过认证无人独立上岗
- [ ] 关键客户均有知情的第二接口人
- [ ] 客户组合复杂度在上限内
- [ ] 绩效无金额指标，指标配对齐备
- [ ] 团队健康三指标进主管绩效
- [ ] 署名权与优先指派有记录
- [ ] 方法论沉淀入案例库与模板

---

**本章要点回顾**

1. 团队建设从矩阵开始。不看图的矩阵是档案。
2. 招聘考推理链，不考证书。反向信号命中即慎录。
3. 培养 90 天三阶段，带教是硬投入。缺人不倒逼放水。
4. 配置守三条：授权按级别、备份到人、排班权在组织。
5. 绩效不背金额，指标成对，健康归主管。
6. 出口当生态：方向对话年年做，方法论入了库才算数。
