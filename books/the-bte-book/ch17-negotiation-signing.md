# 第 17 章　谈判与签约

> 签约不是谈判的结束，是承诺兑现的开始。本章把谈判、条款、承诺、评审、交接串成一条线，给六个动作：定目标、排让步、谈条款、管例外、过评审、做交接。

## 17.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 商业结构 | 价格、条款、风险分配已定 | 先回第 9 章 |
| 谈判授权 | 目标价、底线价、审批人 | 先拿授权 |
| 承诺清单 | 全部承诺已入账 | 先补台账 |
| 合同模板 | 标准模板与例外条款 | 先找法务 |
| 交付确认 | 交付与 TAM 已知承诺 | 先开预沟通 |

完成标志有五项：目标与底线清楚；让步有交换；条款有归属；承诺可执行；签约交接完成。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 目标清楚 | 三档价格与议题优先级 | 谈判简报 |
| 让步有交换 | 每次让步有换回条件 | 谈判日志 |
| 条款可控 | 风险条款有承担方 | 条款清单 |
| 承诺可执行 | 承诺有依据、代价、接单人 | 承诺台账 |
| 交接完成 | 三件套逐条过 | 交接纪要 |

## 17.2 操作一：定谈判目标

### 步骤

1. 写目标：价格、期限、范围、付款、风险；
2. 写保留价：低于什么条件不签；
3. 写退出价：什么情况下离桌；
4. 三档与授权表对齐；
5. 团队口径一致，不现场即兴。

### 预期结果

团队知道谈到哪里算赢，到哪里该停。

### 常见错误

- 只有目标，没有底线；
- 底线只有主谈知道；
- 客户一压就破线。

## 17.3 操作二：排议题与让步

### 步骤

1. 列议题：价格、期限、范围、付款、风险、服务、参考；
2. 分必须拿、可以让、不可谈；
3. 为每个可以让的议题写换回条件；
4. 设计三套组合：保守、基准、进取；
5. 每次让步写进谈判日志。

### 预期结果

让步有边界、有交换、有记录。

### 常见错误

- 单向让步；
- 一次让到底；
- 让步不记录，客户下次当新起点。

## 17.4 操作三：谈合同条款

### 步骤

1. 先谈风险分配，再谈价格；
2. 八类风险逐个过：技术、交付、用量、成本、合规、数据、模型、汇率；
3. 每类写承担方与条款；
4. 重点看：SLA Credit、责任上限、终止权、价格保护、数据出口；
5. 法务全程参与，不最后进场。

### 预期结果

条款能执行，风险有归属。

### 常见错误

- 条款留到最后；
- 责任上限不写例外；
- 价格保护没有触发条件。

## 17.5 操作四：管承诺与例外

### 步骤

1. 合同里的每条承诺与承诺清单对账；
2. 口头承诺折算成书面，否则不认；
3. 例外项写清条件、期限、责任人；
4. 不可交付的承诺，价格再高也不签；
5. 三方会签：BTE 商务、SA 技术、TAM 可运营。

### 预期结果

合同与承诺清单一致，例外有人管。

### 常见错误

- 合同与清单两套说法；
- 例外只口头说；
- 三方会签走过场。

## 17.6 操作五：过签约评审

### 步骤

1. 开签约评审：商务、技术、交付、法务、财务；
2. 每方只看自己的红线；
3. 评审结论三选一：通过、带条件、不签；
4. 带条件项写 Owner 与期限；
5. 评审记录签字，不口头通过。

### 预期结果

签约不是 BTE 一个人的决定。红线有人守。

### 常见错误

- 评审走过场；
- 为签单绕过红线；
- 带条件项没人跟踪。

## 17.7 操作六：签约与交接

### 步骤

1. 签约前核对最终版本与承诺清单；
2. 签约后 5 个工作日内开交接会；
3. 三件套逐条过：方案基线、承诺清单、风险清单；
4. 交付与 TAM 签收；
5. 30 天伴随期，BTE 保持每周一次同步。

### 预期结果

签单即交接，承诺有人接。

### 常见错误

- 签约后失联；
- 交接靠邮件；
- 伴随期不投入。

## 17.8 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 三档清楚 | 目标、保留、退出明确 | 核对谈判简报 |
| 让步有交换 | 每次让步有换回条件 | 抽查谈判日志 |
| 条款有归属 | 八类风险有承担方 | 核对条款清单 |
| 承诺一致 | 合同与清单逐条对账 | 核对承诺台账 |
| 三方会签 | BTE、SA、TAM 签字 | 核对会签页 |
| 交接完成 | 三件套逐条过 | 核对交接纪要 |

关键项是承诺一致、三方会签、交接完成。任一未过，签约不算闭环。

## 17.9 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 谈判停不下来 | 没有底线 | 先定三档价格 |
| 条款吵架 | 风险分配没前置 | 先谈条款再谈价 |
| 合同与承诺不一致 | 没对账 | 逐条核对清单 |
| 交付不认账 | 交接走过场 | 重开交接会 |
| 签约后客户后悔 | 期望没管理 | 补例外与边界说明 |
| 伴随期断档 | BTE 失联 | 定周会与 Owner |

## 17.10 执行检查清单

- [ ] 目标、保留价、退出价三档明确
- [ ] 议题分必须拿、可以让、不可谈
- [ ] 每次让步有换回条件并记录
- [ ] 八类风险有承担方与条款
- [ ] 合同与承诺清单逐条对账
- [ ] BTE、SA、TAM 三方会签
- [ ] 签约评审有结论
- [ ] 5 个工作日内完成交接
- [ ] 30 天伴随期已安排

---

**本章要点回顾**

1. 签约不是结束，是承诺兑现的开始。
2. 三档价格：目标、保留、退出。团队口径一致。
3. 让步要交换，要记录，不一次让到底。
4. 先谈风险条款，再谈价格。
5. 合同与承诺清单逐条对账，三方会签。
6. 签约后 5 个工作日内交接，30 天伴随期。
