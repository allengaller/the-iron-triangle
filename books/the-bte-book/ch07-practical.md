# 第 7+ 章　价值案例与 ROI 实战

> 本章把第 7 章的价值工程落成七步操作：定假设、建基线、算收益、算成本、做情景、写案例、设跟踪。配套 [BTE-03 价值案例与 ROI 模型](tpl-03-value-case-roi.md)。

## 7+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 业务问题 | 客户确认的问题与代价 | 先做需求访谈 |
| 基线数据 | 现有指标、口径、年份 | 先向客户取数 |
| 方案轮廓 | 能力范围与边界 | 先与 SA 对齐 |
| 成本输入 | 交付、服务、资源估算 | 先找交付与 TAM |
| 决策场景 | 客户拿这份案例做什么决定 | 先问清用途 |

完成标志有四项：假设有依据；基线有来源；收益与成本可追溯；客户确认关键假设。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 假设清楚 | 问题、能力、后果、价值四段齐全 | 价值假设表 |
| 基线可信 | 指标、口径、年份客户确认 | 基线确认记录 |
| 账算得平 | 收益、成本、ROI 三表对齐 | ROI 模型 |
| 可跟踪 | 承诺值与实际值有取数方式 | 跟踪表 |

## 7+.2 操作一：定义价值假设

### 步骤

1. 用一句话写问题：谁，在什么场景，损失什么；
2. 用一句话写能力：我们做什么，不做什么；
3. 用一句话写后果：客户哪个指标会变；
4. 用一句话写价值：这个变化值多少钱或降多少风险；
5. 四句话连起来读，读不通就重写。

### 预期结果

团队能用四句话讲清价值假设，不需要 PPT。

### 常见错误

- 问题写成“客户需要数字化转型”；
- 能力写成“提供领先方案”；
- 后果写成“提升效率”；
- 价值写成“意义重大”。

## 7+.3 操作二：建基线

### 步骤

1. 选 1–3 个关键指标，不要贪多；
2. 每个指标写口径：分子、分母、时间窗、取数系统；
3. 取最近 12 个月数据，标出季节性与异常；
4. 请客户对口人确认基线；
5. 基线不确定的，给区间，不给点值。

### 预期结果

基线可复核。客户认可“现在是什么样”。

### 常见错误

- 用行业平均值代替客户基线；
- 口径不清，客户与厂商各算一套；
- 只取最好月份，忽略季节性。

## 7+.4 操作三：量化收益

### 步骤

1. 按四类列收益：收入、成本、风险、合规与体验；
2. 每类写清计算逻辑与假设；
3. 每项标证据层级：事实、估算、判断；
4. 收益给区间，不给单点；
5. 请客户业务与财务分别确认。

### 预期结果

收益表能回答：钱从哪里来，为什么成立，假设是什么。

### 常见错误

- 只算降本，漏掉增收与风险；
- 把判断写成事实；
- 收益重复计算，例如既算人力节省又算效率提升。

## 7+.5 操作四：量化成本

### 步骤

1. 按五类列成本：采购、实施、运营、变更、退出；
2. 三年或五年视角，不做单年比较；
3. 运营成本要含 TAM、支持、值班、重保；
4. 变更成本要含升级、扩容、合规改造；
5. 退出成本要含数据迁移与替换。

### 预期结果

TCO 覆盖全生命周期。客户能看到“一共要花多少钱”。

### 常见错误

- 只算首年采购价；
- 漏掉实施与迁移；
- 运营成本按零算；
- 不写退出成本，制造锁定。

## 7+.6 操作五：算 ROI 与情景

### 步骤

1. 算 ROI = 收益 ÷ 成本；
2. 算回收期 = 累计收益超过累计成本的月份；
3. 算 NPV，折现率用客户财务口径；
4. 做三档情景：保守、基准、乐观；
5. 每档写触发条件与关键假设。

### 预期结果

客户能看到三种未来，不是一张乐观表。

### 常见错误

- 只给一个数，不给区间；
- 折现率自己拍；
- 情景只改收益，不改成本；
- 用 ROI 替代回收期与 NPV。

## 7+.7 操作六：写一页纸案例

### 步骤

1. 按八段写：问题、基线、方案、收益、成本、回报、风险、下一步；
2. 每段不超过 5 行；
3. 每个数字标来源或假设；
4. 风险段写失败模式与缓解动作；
5. 下一步写客户要做的决定与时间。

### 预期结果

客户能在一页纸内看懂，并拿去内部立项。

### 常见错误

- 写成产品介绍；
- 数字没有来源；
- 只写收益，不写风险；
- 下一步写“期待合作”，没有具体决定。

## 7+.8 操作七：设价值实现跟踪

### 步骤

1. 把案例中的承诺值写进跟踪表；
2. 每个指标写取数方式、频率、责任人；
3. 上线后按月或按季取数；
4. 偏差超过 20% 写归因；
5. 季度复盘，更新 VBR 素材。

### 预期结果

价值可验证。续约时拿得出证据，不靠回忆。

### 常见错误

- 签单后不跟踪；
- 只跟踪技术指标，不跟踪业务指标；
- 偏差不归因，续约时无法解释。

## 7+.9 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 假设完整 | 四段齐全，读得通 | 抽查假设表 |
| 基线可信 | 指标口径与数据来源明确 | 核对基线记录 |
| 收益分层 | 事实、估算、判断分开 | 抽查收益表 |
| 成本完整 | 五类成本齐全 | 核对 TCO 表 |
| 情景合理 | 三档情景有触发条件 | 核对模型 |
| 客户确认 | 关键假设客户签字 | 核对确认记录 |
| 跟踪可执行 | 指标有取数方式与责任人 | 核对跟踪表 |

关键项是基线可信、收益分层、客户确认。任一未过，价值案例不算合格。

## 7+.10 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 客户不信 ROI | 基线不清或假设太多 | 先补基线，再减假设 |
| 收益越算越大 | 重复计算或乐观偏差 | 做保守情景，请财务复核 |
| 成本算不拢 | 漏运营与退出成本 | 补五类成本 |
| 案例没人看 | 写成产品介绍 | 改成一页纸八段 |
| 上线后价值对不上 | 没设跟踪 | 补跟踪表与季度复盘 |
| AI 价值讲不清 | 只讲能力，不讲指标 | 拆成可观察指标与爬坡曲线 |

## 7+.11 执行检查清单

- [ ] 价值假设四段齐全
- [ ] 基线指标有口径、来源、年份
- [ ] 收益按四类列，证据分三层
- [ ] 成本按五类列，覆盖三年
- [ ] ROI、回收期、NPV 三数齐全
- [ ] 三档情景有触发条件
- [ ] 一页纸案例八段齐全
- [ ] 关键假设客户确认
- [ ] 价值实现跟踪表已建立

---

**本章要点回顾**

1. 七步：定假设、建基线、算收益、算成本、做情景、写案例、设跟踪。
2. 价值假设四句话：问题、能力、后果、价值。
3. 基线是价值案例的地基，口径与来源要客户确认。
4. 收益四类、成本五类，TCO 覆盖三年。
5. ROI、回收期、NPV 三数一起看，三档情景一起给。
6. 价值案例是价值实现的基线，签单后要跟踪。
