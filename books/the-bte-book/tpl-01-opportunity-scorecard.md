> 用途：商机立项、bid/no-bid、资源投入与止损的统一判断工具，配套[第 5 章](ch05-opportunity-judgment.md)与[第 11 章](ch11-lead-qualification.md)。
> 用法：商机立项时填第 0–3 节；里程碑复核时更新第 3–4 节；三方会签后生效。评分用于比较与分配资源，不用于预测赢单。
> 时点：v0.1，2026-11-02 随书拟稿。权重与分档为建议值，按行业与公司校准。

## 1. 硬门槛（一票否决）

任一项为“否”，本商机不得进入 A/B 级资源池。要么补条件，要么转 no-bid。

| # | 硬门槛 | 判定问题 | 是 / 否 | 证据或补条件动作 |
| --- | --- | --- | --- | --- |
| G1 | 合规与准入 | 客户可采购、无腐败与制裁风险、数据合规路径可行？ | □ 是　□ 否 | |
| G2 | 预算与立项 | 有预算，或有明确的立项与审批路径？ | □ 是　□ 否 | |
| G3 | 决策人可及 | 能接触到有决策权的人，或已有可靠引荐路径？ | □ 是　□ 否 | |
| G4 | 交付能力 | 公司能交付，或能在签约前补齐能力？ | □ 是　□ 否 | |
| G5 | 承诺边界 | 客户核心要求没有触碰不可交付红线？ | □ 是　□ 否 | |

> G5 的判定口径见[第 9 章](ch09-commercial-architecture.md)与[SA 第 9 章](../the-sa-book/ch09-commitment-engineering.md)。价格再高，不可交付的承诺也不能签。

## 3. 分级与资源档位

| 级别 | 分数区间 | 判定 | 资源档位 |
| --- | --- | --- | --- |
| A | 85–100 | 战略商机，值得重投入 | 三角全员、方案定制、POC 资源优先 |
| B | 70–84 | 重点商机，按标准投入 | BTE + SA + 交付支持 |
| C | 55–69 | 观察商机，证明优先 | BTE 主导，SA 按需，先做低成本证明 |
| D | 0–54 | 不投入或列入观察 | 标准材料，不定制，不定制 POC |

分档不是预测。A 级也会丢，D 级也可能翻盘。分档解决的是资源分配，不是命运判断。

跨档调整要写理由。客户战略价值、监管节点、生态联动可以作为上调依据。上调需销售负责人签字。

## 4. 止损与退出条件

以下任一情况出现，48 小时内复核，决定继续、降级或退出：

- [ ] 支持者离职或调岗，且无替代接口人；
- [ ] 预算削减或立项未通过；
- [ ] 连续两周无法触达决策人；
- [ ] 合规或准入出现硬伤；
- [ ] 交付成本超过目标价可覆盖范围；
- [ ] 客户明确锁定竞争对手，且无翻盘证据；
- [ ] 关键时间节点连续两次错过；
- [ ] 客户要求触碰不可交付红线，且拒绝调整。

复核结论：□ 继续　□ 降级　□ 退出　□ 升级裁决
