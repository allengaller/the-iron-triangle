# 第 16 章　投标与建议书

> 标书不是材料堆。标书是一次限定时间、限定规则、限定评委的证明。BTE 要在标书里做三件事：对准评分点、讲清价值、守住承诺。本章给六个动作：读文件、拆评分、定叙事、分应答、管承诺、过评审。

## 16.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| Bid 决策 | 已过机会判断与 bid/no-bid | 先回第 5 章 |
| 招标文件 | 完整版、答疑、评分办法 | 先读全 |
| 方案基线 | 技术方案已冻结 | 先回第 14 章 |
| 报价授权 | 目标价、底线价、审批人 | 先拿授权 |
| 承诺清单 | 历史承诺与红线 | 先建台账 |

完成标志有五项：评分点全覆盖；叙事线清楚；应答分工明确；承诺入清单；标前评审通过。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 评分对齐 | 评分点逐条有应答 | 评分点对照表 |
| 叙事清楚 | 一句话差异加三条支撑 | 叙事线 |
| 分工明确 | 每章有 Owner 与截止 | 应答分工表 |
| 承诺可控 | 所有承诺入清单 | 承诺台账 |
| 评审通过 | 技术、商务、法务有结论 | 标前评审记录 |

## 16.2 操作一：读招标文件

### 步骤

1. 读三遍：第一遍看资格，第二遍看评分，第三遍看合同；
2. 标出硬性资格：资质、案例、人员、财务；
3. 标出评分办法：维度、权重、判据；
4. 标出合同条款：付款、责任、验收、退出；
5. 列出必须澄清的问题，按答疑截止时间提交。

### 预期结果

知道能不能投、靠什么赢、签什么合同。

### 常见错误

- 只读技术部分，漏掉合同；
- 资格不符还投；
- 答疑问题提太晚。

## 16.3 操作二：拆评分点

### 步骤

1. 把评分点逐条拆成“评委要看到什么”；
2. 每条标：必须响应、加分项、无关项；
3. 给每条分配篇幅与证据；
4. 与方案基线对照，找出缺口；
5. 缺口不能补的，写清偏离与替代。

### 预期结果

标书结构跟着评分点走，不跟着产品目录走。

### 常见错误

- 按产品目录写标书；
- 加分项没写；
- 偏离不说明，评委扣分。

## 16.4 操作三：定叙事线

### 步骤

1. 写一句话差异：为什么选我们；
2. 写三条支撑：能力、证据、案例；
3. 写一条边界：什么场景我们不最适合；
4. 叙事线与评分点对齐；
5. 全书统一口径，不各章各说。

### 预期结果

评委看完能记住一句话，而不是一堆功能。

### 常见错误

- 叙事线写成口号；
- 支撑没有证据；
- 不写边界，显得不可信。

## 16.5 操作四：定应答分工

### 步骤

1. 按章节分 Owner：商务、技术、交付、法务、财务；
2. 每章写截止时间与评审人；
3. 技术章节 SA 主笔，BTE 审商业口径；
4. 商务章节 BTE 主笔，财务审毛利；
5. 设一个总控，负责版本与一致性。

### 预期结果

标书有人写、有人审、有人总控。

### 常见错误

- 一个人写全书，质量失控；
- 章节之间口径打架；
- 截止前才合稿。

## 16.6 操作五：管承诺清单

### 步骤

1. 所有超出标准产品口径的承诺，48 小时内进清单；
2. 每条写内容、依据、代价、接单人；
3. TAM 对不可运营项行使一票关注；
4. 承诺随合同或标书留痕；
5. 标前评审逐条过承诺清单。

### 预期结果

标书里的每句话，交付期都能对上账。

### 常见错误

- 为得分写满承诺；
- 口头承诺不入清单；
- 承诺与合同不一致。

## 16.7 操作六：过标前评审

### 步骤

1. 开标前评审：技术、商务、法务、交付四方；
2. 每方只看自己的红线；
3. 评审结论三选一：通过、带条件、放弃；
4. 带条件项写 Owner 与期限；
5. 评审记录签字，不口头通过。

### 预期结果

投标不是 BTE 一个人的赌博。红线有人守。

### 常见错误

- 评审走过场；
- 为中标绕过红线；
- 带条件项没人跟踪。

## 16.8 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 评分覆盖 | 评分点逐条有应答 | 核对对照表 |
| 叙事清楚 | 一句话差异加三条支撑 | 核对叙事线 |
| 分工明确 | 每章有 Owner 与截止 | 核对分工表 |
| 承诺入账 | 所有承诺进清单 | 抽查台账 |
| 口径一致 | 各章数字与口径统一 | 合稿复核 |
| 评审通过 | 四方评审有结论 | 核对评审记录 |

关键项是评分覆盖、承诺入账、评审通过。任一未过，标书不算合格。

## 16.9 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 标书得分低 | 没按评分点写 | 重排章节，逐条响应 |
| 评委记不住 | 叙事线不清 | 一句话差异加三条支撑 |
| 合稿打架 | 没有总控 | 设总控与统一口径 |
| 交付喊亏 | 承诺没入账 | 补承诺清单与成本 |
| 法务退回 | 条款没预审 | 法务提前进场 |
| 截止前崩盘 | 分工不清 | 倒排时间，设里程碑 |

## 16.10 执行检查清单

- [ ] 招标文件三遍读完
- [ ] 评分点逐条拆解并分配篇幅
- [ ] 叙事线一句话加三条支撑
- [ ] 应答分工有 Owner 与截止
- [ ] 所有承诺进清单并有接单人
- [ ] TAM 一票关注项已处理
- [ ] 四方标前评审完成
- [ ] 合稿口径与数字一致

---

**本章要点回顾**

1. 标书跟着评分点走，不跟着产品目录走。
2. 读三遍：资格、评分、合同。
3. 叙事线：一句话差异，三条支撑，一条边界。
4. 应答分工要有 Owner、截止、总控。
5. 承诺 48 小时入账，TAM 一票关注。
6. 标前评审四方过红线，不把投标变成赌博。
