# 第 9+ 章　报价与合同实战

> 本章把第 9 章的商业结构落成八步操作：建成本底座、选定价锚、设价格结构、定让步阶梯、写风险条款、过内部评审、出报价简报、留痕更新。配套 [BTE-06 商业结构与让步阶梯](tpl-06-commercial-structure.md)。

## 9+.1 前置条件与目标

| 前置条件 | 检查内容 | 缺项处理 |
| --- | --- | --- |
| 方案基线 | 范围、配置、交付边界清楚 | 先冻结基线 |
| 成本输入 | 交付、服务、风险准备金 | 先找交付与 TAM 签字 |
| 定价授权 | 目标价、授权价、底线价 | 先拿授权表 |
| 法务模板 | 合同模板与例外条款 | 先找法务 |
| 客户预算 | 预算区间与采购阶段 | 先问采购 |

完成标志有五项：成本算全；价格有依据；让步有阶梯；风险有归属；评审有签字。

| 目标 | 完成标志 | 主要证据 |
| --- | --- | --- |
| 成本可信 | 四类成本有签字 | 成本表 |
| 价格有据 | 三种锚都有依据 | 定价说明 |
| 结构匹配 | 价格结构与方案结构一致 | 报价单 |
| 风险有主 | 每类风险有承担方 | 条款清单 |
| 评审闭环 | 四方评审有意见与结论 | 评审记录 |

## 9+.2 操作一：建成本底座

### 步骤

1. 列交付成本：实施、迁移、集成、培训；
2. 列服务成本：TAM、支持、值班、重保；
3. 列风险准备金：非标承诺、SLA Credit、合规改造；
4. 列资金成本：账期、分期、预付折扣；
5. 请交付、TAM、财务分别签字。

### 预期结果

成本表能回答：这笔单最少要花多少钱，风险留了多少余量。

### 常见错误

- 只算实施人天，不算服务成本；
- 风险准备金按零算；
- 签单后才发现成本漏项。

## 9+.3 操作二：选定价锚与模式

### 步骤

1. 用价值锚定上限，写清价值证据；
2. 用成本锚定底线，写清毛利要求；
3. 用竞争锚定参照，写清对手价格依据；
4. 选商业模式：订阅、许可、消费、成果、混合；
5. 写清模式与客户用量特征的匹配理由。

### 预期结果

价格有上限、有底线、有参照，不是拍脑袋。

### 常见错误

- 只按成本加成，产品同质化；
- 只跟对手价格，打成消耗战；
- 价值锚没有证据，客户不认。

## 9+.4 操作三：设计价格结构与打包

### 步骤

1. 让报价结构映射方案结构：平台、服务、弹性；
2. 分层或打包，客户能看懂钱花在哪；
3. 设计保底、超量、阶梯价；
4. 写清包含项与不包含项；
5. 检查价格结构与合同条款是否一致。

### 预期结果

客户能逐层比较，谈判有得谈，不逐项砍价。

### 常见错误

- 一价全包，客户不知道买什么；
- 报价与方案脱节；
- 包含项写得太满，交付期扯皮。

## 9+.5 操作四：设让步阶梯与审批

### 步骤

1. 定四档价格：目标价、授权价、底线价、退出价；
2. 每档写审批人；
3. 列可交换筹码：期限、量、付款、范围、案例、续约；
4. 每次让步写换回什么；
5. 让步记录进谈判日志。

### 预期结果

让步有边界、有交换、有记录。

### 常见错误

- 一次性让到底；
- 无条件折扣；
- 让价不记录，客户下次会当新起点。

## 9+.6 操作五：写风险分配条款

### 步骤

1. 列八类风险：技术、交付、用量、成本、合规、数据、模型、汇率；
2. 每类写承担方与理由；
3. 写对应条款：SLA Credit、责任上限、终止权、价格保护、用量承诺、数据出口；
4. 检查条款之间是否冲突；
5. 请法务复核。

### 预期结果

风险有归属，条款能执行，不把不可控风险全留给一方。

### 常见错误

- 风险条款留到最后；
- 责任上限不写例外；
- 价格保护没有触发条件。

## 9+.7 操作六：过内部评审

### 步骤

1. 开四方评审：SA、TAM/交付、法务、财务；
2. 每方只看自己的红线：技术可达、可运营、条款合规、毛利达标；
3. 评审结论三选一：通过、带条件通过、退回；
4. 带条件通过的，条件进风险清单；
5. 评审记录签字。

### 预期结果

报价不是 BTE 一个人的决定。红线有人守。

### 常见错误

- 评审走过场；
- 为赢单绕过评审；
- 带条件通过的条件没人跟踪。

## 9+.8 操作七：出报价与谈判简报

### 步骤

1. 报价单写清：范围、价格、期限、付款、假设、例外；
2. 谈判简报写清：目标、底线、筹码、对手可能动作；
3. 给客户前，内部再过一次口径；
4. 报价版本编号，旧版本作废；
5. 客户提问口径统一，不现场新增承诺。

### 预期结果

报价可解释，谈判有准备，口径一致。

### 常见错误

- 报价单没有假设与例外；
- 谈判没有底线；
- 现场回答超出授权。

## 9+.9 操作八：留痕与更新

### 步骤

1. 每次报价、让步、条款变更都留版本；
2. 记录谁批准、为什么；
3. 签约前核对最终版本与承诺清单；
4. 签约后把商业结构移交交付与 TAM；
5. 复盘时回看报价与实际成本偏差。

### 预期结果

报价可追溯，承诺可对账，成本可复盘。

### 常见错误

- 最终版本散落在邮件里；
- 承诺清单与合同不一致；
- 签约后不向交付交底。

## 9+.10 验收标准

| 验收项 | 通过标准 | 验证方式 |
| --- | --- | --- |
| 成本完整 | 四类成本有签字 | 核对成本表 |
| 定价有据 | 三种锚都有依据 | 核对定价说明 |
| 结构匹配 | 报价与方案结构一致 | 核对报价单 |
| 让步有阶梯 | 四档价格与审批人明确 | 核对授权表 |
| 风险有归属 | 八类风险有承担方 | 核对条款清单 |
| 评审闭环 | 四方评审有结论 | 核对评审记录 |
| 留痕完整 | 版本、批准、变更可追溯 | 抽查报价档案 |

关键项是成本完整、风险有归属、评审闭环。任一未过，报价不算合格。

## 9+.11 执行故障排查

| 症状 | 常见原因 | 处理动作 |
| --- | --- | --- |
| 毛利越算越低 | 成本漏项 | 补服务与风险准备金 |
| 客户逐项砍价 | 报价结构不清 | 改分层报价 |
| 让步停不下来 | 没有阶梯与底线 | 先定四档价格 |
| 合同条款吵架 | 风险分配没前置 | 报价前先写条款清单 |
| 评审总退回 | 材料不全 | 按四方红线补证据 |
| 签约后交付喊亏 | 没向交付交底 | 签约即移交商业结构 |

---

**本章要点回顾**

1. 八步：成本底座、定价锚、价格结构、让步阶梯、风险条款、内部评审、报价简报、留痕更新。
2. 成本四类：交付、服务、风险准备金、资金成本。四类都要签字。
3. 定价三锚：价值定上限，成本定底线，竞争定参照。
4. 报价映射方案结构，客户才能分层比较。
5. 让步有阶梯、有交换、有记录。
6. 风险分配看控制力，条款要能执行。
7. 四方评审守四条红线：技术、可运营、合规、毛利。
